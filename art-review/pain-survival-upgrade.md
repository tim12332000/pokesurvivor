# 六道支援生存與站位更新

本輪依使用者確認，全面處理五道出生、復歸後快速倒下的問題。範圍只限沛恩六道，保留既有自動出招、技能欄、顯示尺寸與原生敵人傷害。

天道倒下後的行為已另外更新為 [地獄道救回玩家](pain-player-revival.md)：不再因本體剛倒下就清除整個家族。

天道本體新增等級耐久成長，處理 5–10 分鐘怪物傷害提高、主角仍停在開局血防的問題：每級（從升到 2 級開始）最大生命 +12、補回新增容量，額外減傷 +1 個百分點，成長減傷最多 +20%。只適用操控的天道，不占選擇卡；生命成長、倍化與減傷卡保留原效果，總減傷仍最多 80%。預設永久強化全滿時，1／15／21／25 級為 200／368／440／488 血、16／30／36／36% 減傷。屬性面板顯示成長血量與實際減傷。

同步只補新舊容量差額，不反覆補滿；清場、換世界不重複加血，死亡時升級只提高生命上限、不復活，換角色移除成長，新局重新計算。五道生命仍按天道目前上限兩倍同步，但不額外繼承天道這份固有減傷。

## 生存規則

| 項目 | 現行規則 |
| --- | --- |
| 支援生命 | 修羅、畜生、人間、餓鬼、地獄五道最大生命皆為天道的 2 倍，隨天道最大生命成長同步。生命卡只同步新舊容量差額，不每幀補滿。 |
| 吸血 | 五道的實際攻擊傷害依天道當下吸血比例，同時回復攻擊的那一道與天道，各自獲得完整回血量、不分攤。兩者各自封頂，天道滿血不影響支援道回血；其他四道不分到。天道本人的攻擊維持只補天道。 |
| 安全現身 | 初始與復歸位置須是可達合法地面，避開敵人、尚未爆發的危險區、本體與其他演員；每次最多檢查 128 點，失敗後最多每 .25 秒重試。 |
| 無安全落點 | 尚未現身的道保留唯一身分並顯示待命；倒下者保持倒下，不在危險中硬復活或重建第二具身體。 |
| 整備保護 | 安全現身後 1.5 秒不可受傷、不被敵人鎖定，也不攻擊、攔彈或修復。地面傷害不能清除這段保護；結束後照常會受傷、倒下。 |
| 角色站位 | 修羅、畜生、地獄在本體後方分散；餓鬼近身護衛；人間只有抓取技能準備好且目標安全時才接近，結束後回隊。普通短擊限於已在身邊的敵人，不主動追逐。 |
| 低血撤退 | 低於 35% 進入撤退；人間停止近身追擊，後排遠攻與支援仍可執行。達 50% 才解除撤退，避免門檻附近來回切換。 |
| 安全恢復 | 撤退中、距本體 120 內、3 秒未受傷，且附近 120 內無敵人、腳下無危險區，才每秒恢復自身最大生命的 4%，最多到 50%。不在戰鬥中常駐回血，不重設保護，不替玩家回血。 |
| 危險區避讓 | 對原生圓形與直線預警評估最近出口，避免在大型預警內原地轉圈。人間不抓取預警內目標，追擊中出現危險會取消接近。 |
| 遠程射程 | 修羅與畜生依自己所在位置檢查射程與視線；不因本體看得到敵人就隔牆或超出自己射程施放。 |

保留自然復歸的 16 秒、閻王的等待與演出、暫停凍結、死亡／換世界／新局清理，以及共享五道的分身規則。沒有增加全隊永久無敵或通用範圍減傷；先以站位、受擊保護與耐久解決送頭。

吸血適用五道的近身普攻、修羅飛彈（含原生爆炸）、畜生通靈、人間道攻擊及原生生命剝奪附傷；傷害擴散的追加濺射沿用不觸發吸血的規則。天道倒下等待地獄道救援時，存活支援道仍可吸血補自己，不會補活天道；死亡、未現身、舊家族或舊世界的身體不會被補活。原生傷害歸屬、戰績、護盾、回血上限與地獄道復活流程保留。

## 驗證

- `python tools/test_pain_durability.py`：桌機／手機原生升級、重複同步、卡片疊加、角色隔離、死亡、新局及 5／8／10 分鐘承傷。以未選生命／防禦卡的基準比較，10 分鐘普通怪弱點傷害原可一擊擊倒 200 血天道；15 級成長後每下 182.784，368 血可承受兩下，第三下死亡。這是受控原生承傷案例，不代表能站著承受所有敵人或純粹傷害。

- `python tools/test_pain_survival.py`：桌機／手機的真實受傷、出生禁戰、保護結束可被擊倒、角色站位、低血撤退、恢復的敵人／危險區／近期受傷阻擋與 50% 上限、生命卡差額、避開大圓預警、安全落點不足時延後現身與復歸、實際射程與視線。
- 同一測試的壓力案例執行 14,400 次原生敵人更新、288 發原生飛彈、24 次地面傷害，敵人確實移動；記錄五道存活與實際承傷。這是受控密集壓力案例，不代表任意後期強度下五道永遠不倒。
- `python tools/test_pain_auto.py`：原內測網址的桌機／手機自動技能、並行群傷、冷卻、技能欄、輸入、正常升級與生命週期回歸。
- `.omx/state/pain-survival/entry-report.json`：正常網址桌機直式外框與手機直入遊戲、初始／整備後狀態及畫面。
- `.omx/state/pain-survival/late-wave-report.json`：900 秒原生敵人縮放的額外極端近距離包圍觀察；本體仍可能先倒下，不能把這份觀察當成六秒存活保證。

本機預覽伺服器已換成 `tools/serve_animation_lab.py --port 8004`，使用較大的並行請求佇列，避免多張角色圖同時載入時出現連線失敗。
