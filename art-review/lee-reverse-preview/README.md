## 本次調整

- 空中追擊在左下、右上、左上、右下、正上與下方六個落點間切換；既有踢擊影格隨攻擊方向轉向，手部繃帶錨點一起旋轉。
- 敵人受到連擊時有空中位移，角色、繃帶、命中閃光、血條與傷害數字使用相同演出位置；地面碰撞座標與最後落地爆心保持原本規則。
- 第三版將受擊落點拉大至左右約 380 單位的跨度，敵人先飛出、小李延後追上；增加高低落差與飛行速度線。正式遊戲鏡頭保留角色的上下左右空間，結束或取消時還原。
- 群踢版基礎綁定五名一般敵人，整群挑空、每人承受完整連踢與 30% 基傷的落地重摔。數量卡最多增至十二名；群內不再重複承受 35% 周圍震擊，未綁定者仍只受一次震擊。弱敵延遲到落地一起擊倒，逐一只結算一次獎勵；取消也會清除整組浮空與綁定。表蓮華仍是基礎三名。
- 每個真實連踢命中產生短殘影、接觸閃光與速度線；每位施術者最多保留六筆演出紀錄。
- 下降階段先短暫停在高點，再加速落地；保留原有各段時間、傷害事件、命中次數與 3.3 秒上限。
- 落地裂紋、碎石與擴散震波使用實際技能半徑，取消或清場後隨連段移除。
- 首領保持接地，沒有普通敵人的左右浮空追擊；表蓮華保留原本演出。

沿用現有 `lee-skills-v1.png` 與八門專用圖集，沒有新增角色影格。
預覽頁只建立開放地形與測試敵人，使用正式遊戲的戰鬥、動畫與傷害路徑。
此預覽頁不加入正式網站打包清單。
