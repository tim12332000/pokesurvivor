本輪把另外兩位角色提升到與石流巨砲相同的誇張成長方向：乙骨成為常駐里香與完全顯現的雙人壓制；烏鷺形成大幅連續碎面、真正反射後的獨立反擊，以及離手後仍持續的殘響。新增技能與數值皆為本作改編，沒有新增領域或借用其他角色能力。既有火影調整與已發布石流巨砲不變。

## 乙骨：從陪伴到真正雙人壓制

Lv.3 學會里香協擊後，同一個里香演員會待命、跟隨、追擊、連打，再返回身旁，不再每次打一拳就消失。普通形態高度依階數為 88–100；完全顯現為 156–180，拳擊半徑再乘 1.3。待命與出擊重用同一演員，沒有用額外裝飾里香冒充協戰。

| 成長 | 實際行為 |
| --- | --- |
| 普通協擊一至五階 | 基礎 4／5／6／7／8 拳；索敵 440→600、拳擊半徑 160→250、接近速度 640→880。一般拳每次 0.65 倍基傷，終拳為 1 倍。 |
| 數量卡 | 原生每張 ×1.25 後取整，普通最多 16 拳。第一張即 4→5，三張到 7；顯現基數先加倍，最多 24 拳。 |
| Lv.9 完全顯現 | 持續 8 秒，里香每拳配乙骨自身位置的一記真刀斬；刀斬距離依刀術階數 180→260、扇角 2.6。拳與刀分別結算，兩個來源不混成遠端假刀光。 |
| 顯現中的節奏 | 里香基礎出擊 CD 從普通 4 秒變 2.4 秒；傷害加成依顯現階數 +50→100%。顯現結束後基礎恢復 8→6 秒，冷卻卡只縮恢復。正在進行的身體動作先完成，再進雙人節拍。 |
| Lv.12 協戰共鳴 | 里香終拳真正命中，才排入一次乙骨自身位置的範圍終擊；基傷 80→168、半徑 240→360。等待既有身體／雙人動作結束，短準備後真實命中；有獨立技能歸屬，不遞迴觸發。 |

顯現連段的每拳間隔至少 0.09 秒，24 拳不會硬擠在一秒內。拳、刀、共鳴都有獨立事件與姿勢時序。顯現中途到期會結束強化出擊並返回，不補送剩餘強化刀斬；單學顯現但未學里香協擊時，不免費產生出擊傷害。自然成長從持刀近戰、學會里香的中遠距協戰，進入顯現雙人連打，最後再接共鳴終擊。

## 烏鷺：大幅裂波、反擊鏈與離手殘響

普通掌擊射程由一階 180 成長到五階 260；Lv.3 宇守羅彈開始連續抓裂大片空面。每波都真實結算，而不是一筆傷害配多張碎裂圖。薄冰破依施術者當下位置逐波出手，天空震落則保留鎖定的固定群聚爆點，兩者不是同一個圓形傷害模板。

| 成長 | 實際行為 |
| --- | --- |
| 宇守羅彈一至五階 | 4／5／6／7／8 波，射程 340→540、扇角 2.5→3.3。首波 1.2 倍基傷、中間波 0.55、末波 1 倍。 |
| Lv.9 空面震落 | 射程 600，固定區域半徑 210→340，基礎 4→8 波；首波 1.3 倍、中間波 0.6、末波 1.1 倍。身體手勢結束後，固定裂區仍繼續。 |
| 裂波數量成長 | 每張 ×1.25 取整，最多 16 波；一階第一張 4→5，三張到 7。首末波施加相應控制，強敵效果較弱，不讓每個中間傷害波額外疊出永久控制。 |
| Lv.6 天空幕 | 半徑 110→150，持續 3.5→4.5 秒；反射容量 12→28，數量卡可到 64。首次真正反射才發動一次獨立反擊鏈，不打斷身體攻擊。 |
| 反擊鏈 | 基礎 4→8 波、數量最多 16 波；每波優先射程 600 內可達的原射手，否則選有效敵人。反擊半徑 130→210，由手前折面連向命中區域，使用獨立 reaction 事件；不是只刷新普通招式。 |
| Lv.12 裂面殘響 | 掌擊／宇守羅彈／震落的最後一波真正命中，才在當次固定幾何追加 2／2／3／3／4 次殘響。首發延遲 0.20 秒、其後間隔 0.18 秒，數量最多 8 次；每次基傷 40→84。 |

反擊鏈不再觸發殘響，殘響也不再觸發自己或反擊。只要學會第五技能，起始掌擊的末次真命中就可產生殘響，不強迫先學齊其他招式。普通攻擊、大片扇形、固定巨裂、反射後追擊與固定殘響各有不同來源、位置與觸發條件。
