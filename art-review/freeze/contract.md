# Freeze 經典版首發合約

使用者指定舊版 LF2，首發先還原原味，後續再依實玩調整。身份為經典 LF2 2.0a Freeze，不使用 Remaster 美術，不新增碎冰爆炸／自創連鎖。

- 角色 ID `30018`，選角 slug `freeze`，正常 Lv1 起始冰波。
- `lf2-iceball` Lv1：直線飛行冰波，接觸凍結；牆阻擋。未持劍時，出招空檔用原版普通拳擊迎擊近敵，沿用冰波歸屬，不另占選卡。
- `lf2-sword` Lv3：第一次先召劍，原版動作釋放點0.367秒、總動作0.467秒，召劍不造成近戰傷害。之後近身揮砍；同一身體接連揮動，不隔空打人。揮劍凍結普通敵人1.2秒、強敵0.28秒。冰劍持續保留至退學／死亡／換世界／本局結束。
- `lf2-column` Lv5：沿前方依序升起三根冰柱，獨立柱位接觸。
- `lf2-whirlwind` Lv8：放出前進旋風，持續多段接觸，放出後不占身體。
- 自動施放、學習等級、冷卻與成長是 PokéSurvivor 改編；原版造型、動作與招式概念保持。
- 成長由 `.omx/lf2.js` 的 `G.LF2.power` 及原生 move 階數修改提供，戰鬥及數量卡預覽共用 `G.LF2Freeze.profile`，不以不同公式誇大數量收益。數量 ×1.25 累積取整，基數一要第四張才增為二。
- 冰波的射程是實際飛行航程，冰劍的劍程是實際命中距離；冰柱最後柱位加半徑、旋風前進後的外緣必須達到其階數射程，升階另列實際命中半徑，不把只有索敵的距離冒稱攻擊覆蓋。出招時序由戰鬥模組的原版動作資料決定，註冊 profile 不另行覆寫。

接線：`.omx/lf2-art.js` 提供 `load/loaded/draw`；`.omx/lf2.js` 註冊資料、卡池、來源、HUD；`.omx/lf2-freeze-combat.js` 提供 `profile/pose/stateFor/stats` 與原生更新／繪製。只新增 Freeze，不調整既有角色。
