## 必須成立的動作鏈

1. **影捕捉**：雙手結印、重心下沉 → 黑影從鹿丸腳底沿地面延展 → 黑影端點觸及敵方腳底／影 → 目標對應拘束狀態出現 → 影收回、手臂回到行動姿勢。不可從頭頂發黑色飛彈，也不能無接觸先中。
2. **影縫**：保留接地來源 → 黑影尖端抬升／多向挑刺 → 每一段真接觸在敵身附近形成刺擊 → 回落／收束。與捕捉的區別是立體穿刺和真多段，而非同一條線換色。
3. **札陷阱**：手部投擲／佈置意圖 → 紙札在世界地面固定 → 引信或連線提示 → 爆破於札位置發生 → 紙片／煙短暫消散。鹿丸移動不能把已佈札帶著走；爆破不是影子黑火，必須看得出是忍具戰術。
4. **完整循環**：玩家繞行誘敵進影帶與札區 → 影拘束創造命中窗口 → 影縫接力 → 爆破收束。保留玩家撤退，不強迫本體站定全程或傳送進敵群。成長擴大分枝、真穿刺與爆破鏈皆可，但不得聲稱這些數量為原作固定設定。

控制文案逐項對照實作。僅停止移動就寫「束縛移動」，沒有阻斷施法／接觸傷害／在途敵彈就不得寫「完全封鎖敵人」或「無敵」。
