# 烏路繞身反射：獨立戰鬥驗證

本次使用正常選角入口啟動烏路，測試場景只固定地形與時間；攔截、投射物建立、飛行、碰撞與傷害使用正式程式。

## 已驗證

- 桌機 1280×900、手機視窗 390×844 各跑 high／low 畫質：被捕獲敵彈先退出敵彈列表，0.8 秒轉滿 2π 才產生一顆 friendly `uroReturned` 投射物。測得半徑 116，角度累積 6.283185307179586。
- 返回彈保留原屬性、傷害、烏路 owner 與屏障技能歸屬，朝仍有效的原射手飛行並透過正式碰撞造成傷害。期間不偷射真彈；連續再次攔截不會重捕獲返回彈。
- 烏路位移時圓周跟隨本體；暫停、凍結停止計時與位置，恢復後能完成反射。
- 死亡、清場、退學、換世界、換局 epoch、回 UI 取消捕獲彈。屏障容量耗盡不取消已捕獲彈。
- 分身與本體持有不同捕獲狀態；清本體不清分身，分身反射維持分身歸屬。
- 攔截僅扣一次容量、計一次攔截並觸發一次原有反擊鏈。

原 fracture 的數量斷言將現在會瞄回原射手的返回彈算進反擊段數，故依傷害區分原有 counter 波與額外的一顆返回彈，分別要求預期波數與一擊。首次重跑遇一次啟動載入逾時，第二次完整測試與另一次雙視窗 combat-only 檢查均通過。
