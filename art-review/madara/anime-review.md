# 宇智波斑：獨立動漫複核

2026-11-06。此檔由動漫考據 agent 獨立觀看當次證據後記錄；不以美術自評代替。角色身份及來源見 `anime-design.md`。

## 第一輪：初稿與來源交叉檢查

戰鬥作者提出穢土斑30016、體術→豪火Lv3→須佐Lv6→雙隕石Lv9→木分身Lv12。動漫回覆採用穢土版本，提醒軍配裝備時序未核對，建議起始命名體術／戰場演舞；豪火必為嘴部寬幅火幕；須佐具身刀臂；雙隕石每顆獨立結算。

對美術交接已明定黑長髮、紅板甲、深衣、藍須佐，禁止混入六道白袍／求道玉／輪墓。美術回覆採用，並要求交叉核對64px素材。

## 第二輪：實看素材，不等於正常入口驗收

已用圖像工具實際觀看 `game-size-contact.png`，並對照 `official-edo-reference.jpg`、`official-meteor-reference.jpg`。

| 具體觀察 | 結論與限制 |

| idle與step的黑髮尖束、單側遮臉、紅甲及深衣 | 符合穢土斑身份；64px不用眼睛細節作唯一辨識 |

| basic分派為arm-back→command→finish | 素材支持收臂→掌擊／手勢；未畫獨立拳肘踢，已提醒作者不得宣稱三種專有體術動畫 |
| 上下沿用側面、左右鏡射 | 可接受的明示製作限制；未宣稱八方向原創圖格 |

## 待正常入口證據

已獨立實看 `verification/desktop-selection.png`、`desktop-normal-entry.png` 及 `mobile360-normal-entry.png`：選角實際出現宇智波斑、五招等級列與穢土斑說明；正常開局使用黑髮紅甲角色，桌機與360手機均在草地場景可辨，未見混入六道白袍或其他角色。手機開局圖只證明身體／HUD入口，尚無施術畫面。

第二輪程式交叉檢查已向戰鬥作者提出四項具體修正：拳肘踢文案超過掌擊素材、遠距體術欠真掌風、須佐單臂與雙臂說明不符、火幕先旋轉再偏移造成左向源點落腳邊。作者已將基礎文案改短距掌擊，初距160改105；其餘以新程式／畫面再確認。

第三輪已獨立實看正常入口受控相位圖 `art-verification/fire-1-0.36.png` 與 `susanoo-2-0.70.png`：火從斑的口前出發，人物前傾；須佐在本體上方，藍色角頭、肋、雙臂、武器可辨，斑保持可見。圖中是Lv30受控靶場，不是自然成長影片。

本輪提出兩項尚待修正的具體造型問題：火幕平直三角像探照燈，需不規則火舌與流動火尾；須佐圓筒胸與五邊頭偏機器人，至少加分離下顎／面罩、中央胸骨與肋端、肩鎧折線。已向美術與戰鬥作者互傳，保留半透明與敵彈辨識，不要求臨時重畫所有素材。

豪火首末波、須佐第一刀及末刀、兩顆隕石各自落地與消散、分身連續位置仍待整合證據。未宣稱全戰鬥畫面、命中、清理或玩家樂趣已通過。
