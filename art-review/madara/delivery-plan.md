# 宇智波斑交付與驗收

使用者授權新增完整角色、多 agent 分工、多輪修正，並直接發布目前個人 GitHub Pages 沙盒。

## 範圍與分工

- 動漫／企劃：以官方來源核對穢土轉生斑的能力、完整循環與成長；獨立看正常入口動作。
- 戰鬥：獨立角色 ID 30016，體術、豪火滅卻、須佐能乎、天礙震星、木分身的實際命中與學招／成長接線。
- 美術：長髮紅甲識別、動作圖集、腳底錨點、正常尺寸和小螢幕畫面。
- 測試：獨立真多目標、卡成長、生命週期與正常入口驗證。
- 審查：獨立讀碼、指出具體問題並追查修正。
- 主代理：整合生成／打包，檢查共同回歸，提交推送及核對公開版本。

## 迭代與完成條件

第一輪建立可玩的完整循環；第二輪用獨立測試、美術與動漫觀察找問題並修正。任何未解失敗持續修正；凍結後不因湊輪數添加新機制。

1. 正常入口可選角、開局、學招／選卡與原生自動施放，保留其他角色及存檔 ID。
2. 少量卡的收益落在真攻擊段數／範圍／來源，預覽與實際能力一致，上限後不出無效數量卡。
3. 至少三個分散有效目標與一個範圍外目標；確認障礙、移動、首末段、同波回呼取消。
4. 暫停、死亡、換場／重開及分身歸屬隔離；繪製不產生傷害。
5. 桌機及手機正常入口畫面、美術／動漫各自實看；高配受控測試與自然成長分開記錄。
6. 現有 CI 回歸、新角色檢查、JavaScript 語法檢查、完整產生與打包通過。
7. Lore 提交只包含本次工作；推送現發布分支，GitHub Pages 成功，公開入口及關鍵腳本／素材雜湊核對。

## 驗證限制

瀏覽器手機 viewport 驗證不代表實機長局，受控高配短片不代表自然完整成長，程式命中與畫面審閱不代表玩家已認可樂趣。交付時按實際證據記錄。
