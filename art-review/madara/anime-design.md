- [BANDAI NAMCO《忍者新世代》斑DLC官方頁](https://naruto-action.bn-ent.net/special/dlc_09.php)：44–56行支持「火遁・豪火滅卻」「天礙震星」名稱及斑的軍配武器。這是授權遊戲命名／裝備資料，不單獨證明對五影戰的動畫裝備時序。
- [BANDAI SPIRITS穢土斑商品頁](https://bsp-prize.jp/item/2715044/)：43–44行明確將穢土斑造型與豪火滅卻起手連結，可給美術核對結印姿勢。

## 完整循環與成長建議

移動接近敵潮外緣 → 體術接住近身壓力 → 寬火幕橫掃正面 → 須佐在本體周圍斬開接近敵人 → 巨岩固定落點讓玩家繞場誘敵 → 分身從獨立源點續攻，接回下一輪本體體術。撤退仍由玩家控制，不靠強制瞬移把玩家送入怪群。

| 階段 | 可見場面差異 | 真實收益要求 |
| --- | --- | --- |
| 起始 | 斑以快速體術打開近身空間 | 真連擊接觸，不用遠處敵人隔空掉血代替近戰 |
| 第一張／少量投資 | 火幕變寬或多一波；須佐多一次斬擊；巨岩多一個實際落點 | 當張立即改變受益端；若某技能顆數上限已到，不得繼續顯示假數量收益 |
| 中期成套 | 火幕清前方，須佐負責近身大扇面；雙隕石形成先後高潮 | 不把所有招塞同一姿勢排隊導致豪火／須佐互相停火；允許已釋放效果延續 |
| 成形 | 大須佐終斬、真多顆岩石、分身在側翼接續 | 擴大實際清怪覆蓋和有效攻次；保留敵彈、角色位置及撤退路徑辨識 |

戰鬥作者初步門檻為體術起始、豪火Lv3、須佐Lv6、隕石Lv9、木分身Lv12。這些是待實測的遊戲節奏，不是動漫設定，也不是固定五招模板。若學招成本使招牌太晚可調低門檻；不能用測試強設20級冒充正常養成。

兩個自然方向可沿既有卡牌形成，無需另造養成系統：火幕／須佐的持續壓場，或範圍／數量推高隕石與分身的廣域殲滅。實際卡牌預覽必與戰鬥profile共用公式；這是設計建議，尚未宣稱兩流派平衡或玩家覺得好玩。

## 動作鏈契約

| 招式 | 起手 → 發力／接觸 → 結果 → 收勢 | 不可省略 |
| --- | --- | --- |
| 體術 | 面朝敵人踏步／架勢 → 手腳或苦無到目標接觸距離 → 分段受傷 → 回架勢 | 每擊有獨立接觸；玩家撤退不被追身奪權 |
| 豪火 | 手在胸前／口前結印 → 由口前向外展成寬火幕 → 逐波敵群受傷 → 吐息止、火尾消散 | 正常尺寸看得出火由斑吹出；身體移動與火源點時序一致 |
| 須佐 | 藍色肋／軀幹及手臂在本體周圍顯現 → 刀臂蓄勢再掃過真幾何 → 命中痕與敵傷 → 手臂回收 | 不只是藍圓圈／激光；完整相位能辨識手、刀與斑的相對位置 |
| 雙隕石 | 結印／向上示意 → 地面陰影和巨岩下降 → 第一顆落地、第二顆獨立落地 → 碎岩散去 | 傷害在接觸落地時，不在預告；固定落點不逐幀追蹤敵人；第二顆不只是同一筆傷害多畫一張圖 |
| 木分身 | 木質顯現／分裂 → 實體在側翼有自己位置和目標 → 自己嘴部火幕或自己須佐刀臂命中 → 有限期退場 | 不畫透明殘影冒充實體；同一分身位置、pose與攻擊源點連續 |

上述段數、CD、火幕多波、分身施放隊列、隕石數量成長均屬本作改編。須佐現身本身不保證無敵；如果程式未處理接觸傷害／飛彈／敵方施法，說明不得聲稱絕對防禦。

## 驗收交接與目前狀態

來源已核對；動作鏈已交戰鬥與美術。正常入口畫面與動作尚待本輪整合，本文不以靜態考據宣稱完成動漫驗收。

整合後須獨立看：正常桌機及360/390手機的黑髮紅甲輪廓；豪火嘴部第一波、後續波、收勢；須佐第一刀、末刀、回收；隕石預告、第一顆落地、第二顆落地、消散；分身在移動中自己的攻擊源點。低畫質保留攻擊真寬度及段數，減紋理即可。

驗真命中由戰鬥作者負責：至少三個分散範圍內目標及一個範圍外，牆後、移動敵、每段HP；同波第一目標回呼取消後第二個與後續波不再命中；暫停、死亡、換場、重新開始清理。原生短片必包含末段，受控高配和自然選卡證據分開。這些是待交付條件，不能用此文件當已通過的證明。
