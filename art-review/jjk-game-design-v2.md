# 仙台三人：第二版遊戲設計審查

狀態：提案，尚未把下列建議全部實作。目標是讓同樣四招的可玩版呈現三種角色，而不是加技能數量或提高傷害。角色與素材來源以 `jjk-research-v2/sources.json` 為準。

## 查看的現況與限制

已讀 `.omx/jujutsu.js`、三人技能設計文件、三人戰鬥模組、美術分派；查看 build 證據中的烏鷺手機實景、三人技能單格與里香單獨畫面；對照官方烏鷺立繪與既有 v2 baseline verdict。這些證據足以指出動作與定位缺口，不能證明完整實戰體感或量化美術達標。

目前正常手機畫面角色約40多像素高。高解析圖集中的手指、眼妝不能替代此尺寸下的髮型、姿態、武器與出手源點。現有 isolated cast 圖只有黑底單格，不能證明連段、前搖、命中與收勢正常。

## 學習節奏與連動

共同等級 1／3／6／9 已足夠，且每級新增功能。保留所有技能學會後自動施放，避免這次同時改觸控操作模式。

- 乙骨：Lv1近戰基本功；Lv3第一次離身觸及遠處、補近戰射程；Lv6咒言爭取近身與里香命中時間；Lv9把已有兩位演員放大成可見的爆發窗口。短板仍是刀短、爆發有空窗。
- 石流：Lv1穿線；Lv3增加方向覆蓋；Lv6對聚集位置爆破；Lv9長準備高威力砲。短板應來自方向鎖定、長準備與貼身被包圍，不靠降低基礎命中精度製造挫折。現有爆破與全力只是同一咒力輸出的改編用途，UI應說清楚。
- 烏鷺：Lv1窄扇形引導朝向；Lv3更寬薄冰破提供清怪；Lv6短幕反遠程而不能抗接觸；Lv9固定目標區域碎面＋短減速。減速有利接續薄冰破，但本次不新增保證連擊或吸怪。短板仍是幕空窗、近戰壓迫、固定爆點可被走出。

## 烏鷺本次有界動作規格（待主代理核准）

保留四個 IDs／模式、傷害、射程、扇形弧度、半徑與 CD；不把空面震落改成原作未證實的新招。保留所有場景／死亡／暫停／局次隔離及破壞物命中規則。

1. 每位施術者同時一個身體動作。記錄招式就緒時刻，最早就緒優先，避免基礎招一直插隊。只計算已學且當前有合法目標的招式。
2. 天空幕開啟身體動作約0.42秒，幕本體仍獨立存在2.3秒；不能為畫幕而鎖定人物2.3秒。幕仍允許部署後施放其他招式。
3. `poseFor` 提供 `phase: windup / pull / shatter / recovery`、`mode`、`age`、`release`、`duration`、`aim`。薄冰破在0.34秒實際命中前顯示裂紋、命中時碎開，不能提前給強烈爆炸暗示。
4. 空面打擊為較小抓空面／推折，薄冰破為雙手拉開、裂面重擊、碎片散開；空面震落為目標圓盤邊緣折疊，不用岩石、魔法陣或真實吸怪。
5. 天空幕現有碰撞是半徑82的全周圓。美術以多片連續彎折空面包圍有效邊界，保留淡而準確的接觸邊；不能只畫前方一片牆卻仍全周擋彈。反射發生的接觸處亮起局部折角，反射前後方向需看得清。
6. 天空幕顯示剩餘反射次數，圖面用稀疏邊角與縫線，避免大不透明圓蓋過敵人。碎片只在短時間出現，不持續滿屏飄。

烏鷺官方辨識要素：浮起的淡紫／粉紫粗髮束、金色圓柱耳環、眼部黑色標記、胸腰間的天空布面；布面不能畫成有縫線的連身裙。官方立繪只支持輪廓與造型，不支持特定毫秒級動作時序，時序屬本遊戲設計。

## UI／共用層建議（由主代理處理）

- 選角卡用一行分工：「乙骨：刀術與里香協同」「石流：蓄力貫穿砲」「烏鷺：空面群傷與限時反射」。
- 學習卡顯示新增用途，不只寫「傷害提高」。技能圖示區分刀、里香輪廓、咒言、指環；頭砲、三道砲、爆心、寬砲；折面、碎面、反射折角、摺疊空面。
- 已學自動技能放在明確「自動」欄。現況手機底欄圖示和長冷卻數字不說明技能節奏，不能靠更多內部術語修補。
- 烏鷺描述「首領效果較短」與實作同0.65秒、減速幅度降低不符；改為「首領減速較弱」。

## 本次驗收

必須從正常入口、實際角色尺寸看每人：站立、移動、完整施術前中後段、受傷及死亡；乙骨與里香同框，石流頭頂出砲，烏鷺手部抓面與命中時碎裂。手機檢查敵人／觸控仍可見。

戰鬥驗收保留三個範圍內與一個範圍外敵人的真實HP、牆壁、寶箱、單次命中、暫停、死亡與換局。新增三招同時就緒仍先後施放、無招式飢餓、幕存在期間仍可攻擊、幕超時與耗盡均消失、姿勢時序與真正命中相符。美術判斷應列具體差異，不以任意高分替代證據。
