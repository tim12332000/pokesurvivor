# 烏鷺亨子：仙台結界可玩初版

版本：動畫第三季仙台結界；角色 30015。定位為中距離扇形清怪與短時間飛彈反制。技能學會後自動施放，人物仍可移動。沒有領域展開、永久無敵或全傷害免疫。

## 原作依據與改編界線

- [動畫官方角色頁](https://jujutsukaisen.jp/character/)：烏鷺將天空視為「面」的術式。
- [動畫官方第59話](https://jujutsukaisen.jp/episodes/59.php)：仙台結界、乙骨、石流與烏鷺的動畫版本背景。
- 天空扭曲、空面打擊、空面偏轉與薄冰破的視覺方向依仙台戰鬥改編。此頁不將遊戲數值、額外範圍傷害或自動施放規則宣稱為原作設定。
- 「空面打擊」「天空幕」「空面震落」是本作功能名稱；空面震落的圓形群傷與短減速是生存遊戲改編，不是新增領域或原作招式考據。

## 命中、動畫與狀態

扇形與圓形的畫面邊界對應實際傷害查詢。每招只有一次傷害結算，出手延遲期間允許敵人離開；範圍以施放時位置固定，避免角色移動後傷害與畫面不符。目標及命中都檢查牆壁路徑。

空面幕以原生 Combat.resolve 前的飛彈線段與保護圓相交點攔截，避免高速飛彈穿過角色才被判定。返還飛彈沿原入射方向反向飛行，傷害歸屬原施術者。

G.JjkUro.poseFor(owner) 提供 mode、age、duration、aim 與 windup／strike；美術另由共用角色素材模組提供。暫停凍結時間，死亡、失去本地控制、換世界與 clearFields 清除狀態。忘記技能後在下一次更新取消其效果。狀態分別保存到角色，支援本地受控分身；網路遠端不建立第二份有傷害施術者。

- node --check .omx/jjk-uro.js 通過。
- Node 原生 API mock：三個分散扇形內目標各命中一次，扇形外及射程外不受傷。
- 暫停不推進效果時間。
- 高速敵方飛彈線段進入幕時反射，保留施術者歸屬。

## 第二版：施術節奏與空面演出

已依主代理核准的 `.omx/plans/jujutsu-refinement-v2.md` 實作，詳細跨角色規劃見 `jjk-game-design-v2.md`。保留原有四招ID、傷害、CD、命中形狀、實際釋放時刻及反射容量／持續時間。

- 同時只執行一個身體動作，以最早冷卻完成的招式優先。不是把四招同影格施放後只顯示最後姿勢。此改變會調整實際施術時刻與持續輸出節奏，未暗加傷害補償。
- 普攻／薄冰破／震落身體動作各0.48／0.8／1.05秒，仍於0.18／0.34／0.55秒結算一次命中。幕的部署動作0.42秒，2.3秒反射效果獨立存在，部署後可繼續攻擊。
- poseFor 提供 windup／pull／shatter／recovery 與同名 frameName；傷害招在實際命中時才進入 shatter，前0.13秒後轉 recovery。原文中的 windup／strike 二階接口由四階語意替代。
- 前方空面使用扭折梯形條帶、收折脊線與準備末期裂紋；命中後才分離與出現短命碎片。震落是固定目標區域的折面，不新增吸怪。
- 幕顯示為完整環繞的八片彎折天空面，淡接觸輪廓仍對應半徑82。每次反射在實際接觸點顯示局部折角，保留剩餘次數標記。不是只畫一片前牆卻全周阻擋。
- 所有圖形條帶／碎片數量固定，反射折角數量受每幕最多9次容量限制；沒有逐影格新增canvas或無界粒子。
