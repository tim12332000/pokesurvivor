# 小李繃帶：素材查核與製作決策

本次先查素材，再製作原創動作與布條材質。原版遊戲畫格只供研究，不是本專案現役素材；既有綁定數量、命中、傷害、冷卻與敵人控制規則維持原樣。

## 素材證據

- [指定素材庫：Ninja Council 3](https://spritedatabase.net/game/55)列有 Rock Lee；對應[來源頁](https://spritedatabase.net/file/1295)與[完整圖檔](https://spritedatabase.net/files/ds/55/Sprite/RockLee.png)。研究副本為 [lee-nc3-research.png](references/lee-nc3-research.png)，1054×3056，SHA256 `852c6f31117b3115ce02b97e5f2791d43755e67abcaacd5d2fbff46d9c1992d5`。保留 Neimad 原始擷取署名；不接入遊戲，也不當作生成圖像的像素輸入。
- 實際看圖：`SPECIAL ATTACK 1 (OMOTE RENGE)` 有手腕散出的長布尾、逐步捲住目標的繃帶、纏繞後旋轉的形體及鬆脫布旋；`SPECIAL ATTACK 2 (URA RENGE)` 有開門與高速連擊。這支持「鬆布、伸出、收緊、釋放」的動作語法，沒有可以直接套在任意敵人上的通用多人繃帶網。
- `.omx/naruto/pixel/rock-lee.png` 在目前工作樹中**不存在**。現有 `team-guy.png` 是 **Path of the Ninja 2** 場景角色圖，不是 NC3 戰鬥圖；`sprites.json` 的 Rock Lee 也指向它。
- 現役角色是本專案原創 `lee-common-v1.png`（887×1774、32格）、`lee-skills-v1.png`（1271×1238、16格）與開門對應圖。舊技能圖有蓄勢、上踢、蜷身、落地，**沒有獨立鬆布／拋布／收布連續動作**。
- [官方第49集摘要](https://naruto-official.com/en/anime/naruto1/list/01_273)支持表／裏蓮華的招式身分。查核時直開官方頁回維護畫面，官方搜尋快取仍列第49集與兩招；不據此杜撰繃帶細節。「多人地面拉近、Boss抗拉、數量卡、AOE」都是本遊戲改編。

## 我愛羅自然的原因

查讀 `naruto-sand-vfx.js` 並看原生砂縛柩、砂護衛截圖：砂有前緣生長、不同寬度的材質片、明暗脊線、顆粒與缺口；出現、收緊、崩散跟著技能階段走。舊繃帶是等粗白線與相同橢圓，全疊在人物前方，像指示線與貼紙。

繃帶借用的是**材質與動作的因果**：有寬度的連續布片、扭轉的亮暗面、鬆弛垂弧、收緊張力、身體前後遮擋、不對稱短尾。不複製砂粒，不靠發光掩蓋材質不足。

## 演出與機制邊界

| 既有階段 | 新畫面 | 保留規則 |
| --- | --- | --- |
| approach 0–0.05s / extend | 真正鬆腕姿態，短布在手邊展開 | 不新增等待或提前控制敵人 |
| approach 0.05–0.10s / extend | 前拋姿態，布沿不同弧線伸出 | 接觸仍在原本0.10s |
| approach / pull | 收布姿態，垂弧與布面逐漸繃緊 | 420速率、4px採樣、個別釋放 |
| windup / wrap | 布繞到背面，再從身前壓回，臉部保持可讀 | 原本主／側目標權限 |
| lift／combo | 手腕連接段漸淡；主目標的布隨高度、側目標留在地面 | 不假造側目標空中連擊 |
| descent末段 → slam | 布圈剝離，落點少量短布卷快速淡出 | 布不是傷害或碰撞物 |
| Boss／抗性目標 | 布伸到身前後鬆落，不出現假綁緊外殼 | 小李靠近，Boss不被拉動或抬升 |

## 實作與生命週期

- 手腕優先使用 `G.AnimationLab.handForLee(owner)`，包含鏡像與視覺高度；既有空中姿態缺手部資料時才用身體錨點。不扭曲閒置圖、不拼接第二隻手、不旋轉整張圖冒充動作。
- Lee runtime 產生 CPU polygon ribbon：雙側輪廓、反面陰影、局部折痕，取代等粗描線與完整橢圓。
- `Enemy.draw` wrapper 在原生身體前畫背面、身體後畫正面；連接布與鬆脫短尾走 `drawAirFields`。不重畫整個敵人，不遮臉假造遮擋。
- 外觀快取掛在原 actor chain：伸出階段60Hz、其餘24Hz維持布形；真實手腕或敵人位置改變仍立即跟隨。每人最多12條，每條固定取樣上限。
- 清除、死亡、切換、換場即失效。不新增傷害、碰撞或控制計時器；純視覺終段只保存少量座標，不重新認領敵人。
- `boundTargets`／`bindings`／claims 維持原規則；Boss只畫鬆布，不畫身體包覆。
