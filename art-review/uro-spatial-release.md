# 烏鷺空間折射版本 v7

版本 `sendai-20261105-space-refraction-v7`。使用者要求先更新 agent，讓烏鷺以扭曲空間使視線偏折來遮蔽身體重點，完成後直接發布。

## 改動

- 更新動漫／美術 agent 與共同品質規範，並同步專案、全域 skill reference：對照實際圖格與遊戲畫面，驗證視線偏折、所有動作持續非露骨遮蔽、手足髮臉可辨，不能以普通衣物或固定藍片代替。
- `.omx/jujutsu-art.js`：保留既有安全底圖，不產生新身體細節。依現用圖格建立分離遮罩，先移除舊衣物區，再用乾淨場景快照作反向位移與局部折光；保護原有手／前臂，避免整列消失。受傷白閃、半透明分身也不透回青色布料。快照有尺寸上限與暫停／世界／鏡頭失效條件，靜態遮罩與折光資料快取。
- `.omx/naruto.js`：烏鷺選角不再直接使用舊青衣全身PNG；改走相同角色繪製與專屬天空背景，遮蔽取同一張預覽背景的位移，髮頂／腳底完整納入。
- `.omx/jujutsu-vfx.js`：去除全範圍輪廓、徑向網、長反擊連線與反射箭頭；保留真場景取樣與網格扭曲運算，呈現局部拉扯、破裂與短折光。戰鬥、命中範圍與反擊事件未因這輪造型更動而改變。
- 新增 `tools/test_uro_spatial_veil.py`、`tools/test_uro_space_vfx.py`，更新既有程序特效測試，保留真正機制、預算及清理驗證。

來源PNG原封，沒有新生成的角色圖集。此版本也整合本聊天前輪已完成的三角色成長／追擊、別動、雙源放出與羈絆HUD崩潰修正，詳見 [角色重設計記錄](jjk-felt-redesign-release.md)。

## 範圍限制

本作的光學覆蓋比參考圖更寬；沒有重建原衣物下的身體或複製腹部負空間。均勻背景上可能呈較大的局部隱去區，UI使用專屬簡化天空背景。這是保留既有非露骨底圖的空間折射版本，不宣稱完整重畫原作造型。

已看正常尺寸及短影片；實體手機熱降頻、長局、真人連線和玩家主觀滿意仍待實玩。視覺分數不代表真人認可。
