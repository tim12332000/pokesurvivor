# 石流龍：仙台結界可玩版

角色 ID `30014`，起始招式 `jjk-ryu`。本版以第三季仙台結界的高輸出咒力砲手為主題。

## 原作依據與改編界線

- [動畫官方角色資料](https://jujutsukaisen.jp/character/)確認石流為仙台結界四方勢力之一、受肉的過去術師，以及泳者中最高的咒力輸出。
- [官方仙台結界 PV 公告](https://jujutsukaisen.jp/news/20260322_01.php)及其嵌入影片提供乙骨與石流交戰、髮型與砲擊動作的視覺參考。
- [官方第59話介紹](https://jujutsukaisen.jp/episodes/59.php)確認本版的時期與交戰組合。
- 基礎 Granite Blast／咒力放出是角色能力；散射、爆破、全力四種技能的分工、中文副標、等級、半徑、傷害與冷卻皆為本遊戲改編，不宣稱是四個原作命名術式。不補寫未揭露的領域效果。

## 技能表

所有已學會招式自動輪流施放，使用自己的冷卻；身體同時只準備一招，以就緒時間排序，避免基礎砲一直插隊。蓄力期間仍可走位，方向於起手鎖定，釋放位置取當時角色腳底平面位置。視覺由頭部高度發射。

## 戰鬥與清理

- 每條砲線按真實半寬取樣牆體與阻擋物，截斷後不傷害牆後敵人。範圍爆破同樣檢查爆心與敵人之間的阻擋。
- 爆破準備期間只顯示提示，釋放才傷害一次。若移動後固定爆點超出射程或被遮擋，取消此次命中。
- 敵人、可破壞場景物共用既有傷害入口；每名敵人每次砲擊最多一次，沒有每影格重複扣血。
- 狀態依施術者、世界與遊戲局物件持有。只由本機受控制玩家／分身模擬傷害，不替遠端傀儡重複結算。
- 暫停凍結；死亡、離場、換角、換世界、新局及 `Combat.clearFields(owner)` 清除準備與特效。未改動角色永久能力、外部減速或敵人跳躍高度。

## 驗證與接點

- `.omx/jjk-ryu.js` 用 `node --check` 通過語法檢查。
- 獨立 Node VM 行為驗證：爆破三個範圍內目標皆扣100、一個範圍外目標不扣血；準備 .40 秒尚未傷害；暫停九秒不推進；釋放後不重複扣血；施術者死亡取消在途傷害並清狀態。
- 暴露 `G.JjkRyu.cast/canCast/update/clear/pose/stateFor/stats` 供整合瀏覽器驗收，角色素材與選單／技能登記由平行工作接入。此文件不把尚未完成的整合驗收寫成已通過。

靜態資料能支持發射位置、角色服裝與發射口色調；不能證明散射與最大輸出的每格節奏。下列時間分段、鋸齒外殼、壓縮環與碎屑屬於本遊戲的演出設計，未宣稱逐格重現動畫。

### 演出分段

1. 準備：發射口維持小型白熱核心，青藍環向內收縮、少量光點朝核心聚集；不再畫一條長棕色瞄準線。爆破保留精確的地面半徑90真圓提示。
2. 釋放：頭部發射口局部閃光；當幀亮芯已抵達實際碰撞長度，外層鋸齒殼在約35毫秒內展開，避免傷害已命中但光束仍在半途。撞牆時光束與撞擊反應共用裁切長度。
3. 後座：55毫秒後進入約125毫秒的局部後座，提供身體繪製用位移幅度。最大輸出的後座較明顯，不修改真實角色位置、全局時間或攝影機。
4. 消散：普通砲快速消失、散射各砲道有較細的青白雙層、全力砲有較厚的亮芯與兩道壓力波紋。牆面命中與地面爆破有有界碎屑和局部波紋；不以整頁閃白代替命中。

`pose()` 新增 `phase`（`windup/fire/recoil`）、`phaseAge`、`progress`、`chargeProgress`、`recoil` 與語意圖格 `frameName`，對應 `lightCharge/lightRelease/lightRecoil` 或 `maxCharge/maxRelease/maxRecoil`。原本 `age/charge/released/mode` 保留供既有測試與動畫相容。

### 效能與機制界線

- 每名施術者同時最多32個裝飾特效；上限只移除舊裝飾，不移除待命中的招式。
- 光束最多29個外殼頂點、每個特效最多12組碎屑方向，僅在釋放時建立。繪製期間不抽隨機形狀、不建立 canvas、不使用模糊陰影。
- 保留 ID、學習等級、傷害、CD、準備時間、射程、半寬、牆體碰撞、散射命中去重與單次爆破傷害。視覺後座不改座標及碰撞。
- 退出、死亡、換世界、重開清理沿用初版；暫停不推進準備、後座或碎屑。
- 第二版語法與獨立機制回歸通過；整合新圖格、正常畫面比較及效能採樣由主工作與 QA 驗證，不能只由本文件推定畫面達標。

### 實玩評分82後的發射口對齊

依 `.omx/state/jujutsu-v2/ralph-progress.json` 的原生畫面比較，固定頭頂高度仍與新繪圖的短光束不相接。準備環現在取 `G.JujutsuArt.pointFor(owner, pose, 'muzzle')` 的實際世界座標，已畫有白亮發射口時只畫周圍環／光點，不再疊第二顆實心光球。

釋放時用明確的 `lightRelease/maxRelease` 姿勢快照取得 `beamEnd`，從已繪短光束的末端接出長砲線；偏上下的瞄準（`abs(sin(aim)) > .55`）改接 `muzzle`，避免把斜砲線接在水平短光束的側緣。長砲線的另一端仍為既有碰撞裁切長度投影，因此不會因為發射口前移而伸過牆。真實碰撞起點、傷害與射程保持原值。缺少圖格點資料時，獨立測試與舊素材仍退回原本固定發射口；此退回不影響命中判斷。
