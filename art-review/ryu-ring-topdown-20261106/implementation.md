# 圓環砲俯視與材質重作

依玩家「圓環改俯視角、不自然、用 art agent 重作」的回饋，只調整石流龍圓環。獨立美術 agent 負責砲束材質與實際畫面複核，主代理負責共享幾何、測試與發布。

## 玩家可見的差異

- 改成腳底錨定的地面橢圓，縱向為橫向的55%；不再把整圈上抬48像素。朝向只決定出砲位置與沿環起點，不會把地面橢圓轉成立環。
- 初始砲道從額前彎向環帶；成環後移除穿過內側的接入段，保留中空。
- 美術退回第一版「壓扁的橡膠圈」，第二版去掉均勻青色內帶與整圈白硬邊，改為柔邊、窄熱芯、隨流動起伏的密度與少量細束；末段降亮後結束。
- 傷害、輪次、冷卻、升階及數量卡收益沿用。實際命中與牆體裁切讀取同一份投影後線段；前後可命中的區域同步縮短，舊正圓上下區域沒有隱形傷害。

## 變更檔案與沿用

| 檔案 | 修改 |

| `.omx/jjk-ryu.js` | 地面投影、額前接入、腳底錨定與縱向觸發範圍 |

沿用現有碰撞、CombatPulse、角色動畫、卡牌與打包器；沒有新依賴、圖集、傷害時鐘或額外命中圈。

## 驗證與界線

桌機／手機390的圓環戰鬥合約通過，涵蓋4／5／8／16輪、四方向、中空、舊區域不命中、移動、牆、回呼取消、局次／死亡／分身及高低畫質1／2／3線段裁切繪製。九項標準Node檢查、JS語法與diff檢查通過。

第二版正常入口桌機1280／手機360及390共45張相位畫面、三支原生RAF短片、鍵盤／觸控移動及來源雜湊驗證通過，報告位於 `qa/presentation-v2/report.json`；原生短片與完整畫面保留本機，不混入遊戲發布包。美術實看與退回原因見 [美術記錄](art-review.md)，判定不代表玩家主觀樂趣。

這是單招受控遭遇與選卡驗證；未重跑自然XP完整養成、手機實機長局或音效聽評。
