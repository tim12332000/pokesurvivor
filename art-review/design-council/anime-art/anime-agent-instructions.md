# 動漫考據與招式轉譯指引

供現有 `design_anime_art` 的動漫考據工作使用；與[美術指引](art-agent-instructions.md)分工，不建立另一套角色或固定技能模板。使用者已調好的火影角色是本專案的手感參照，先讀[現行實作對照](anime-benchmark.md)，再查本次角色。

## 從演出辨識角色

先說清楚這次角色的版本、玩家應感受到的能力，以及一個不能丟掉的招式關係。例如施術者如何接近或抓住目標、力量從何處發出、夥伴與主人如何協作、蓄勢如何轉成命中；不能只列招名、髮色和官方網址。

- 查現行載入與戰鬥／動畫程式，確認已實作內容；舊提案與舊驗收紀錄只作歷史參考。不得把使用者後來調好的連段、普攻、常駐強化改回早期規格。
- 研究足以支持本次改動的官方原作、動畫或官方遊戲資料。記錄實際檢視的頁面／圖／片段及定位；搜尋摘要、縮圖、每秒取樣、完整播放與聽過音訊的證據能力分開寫。沒看過的資料只標待核對。
- 把每個關鍵招式寫成短動作鏈：**起手意圖 → 演員／目標相對位置 → 發力或接觸 → 結果 → 收勢**。指出哪些步驟是角色辨識所必需，哪些可因生存遊戲節奏縮短或省略。
- 明確分開原作能力、特定作品／時期版本，以及本作的數值、索敵、群攻、首領抗性、卡牌與自動觸發改編。授權遊戲可以支持該遊戲的名稱或招式，不能自動證明動畫時序。
- 不為湊四招、固定解鎖等級或缺一種 AOE 而借用他人／後期能力。原作的一種能力可有多種本作用途，但需說明用途差異，不能冒充多個原作術式。

## 交給企劃、美術與戰鬥作者的內容

只交付會影響決策的資訊：來源與版本、必要動作關係、可改編部分、已知缺口，以及一個可在遊戲中檢查的辨識目標。

- **企劃**決定成長與強度；動漫 agent 說明哪些改編仍保有能力語意，哪些已變成另一種能力。原作證據用來確定身份，不規定遊戲數值。使用者要求誇張爽感時，允許擴大實際群傷、連擊、協戰、覆蓋與頻率，不把舊範圍、CD、四招配置或必留空窗當成限制，也不為每次強化硬加代價。這些規模與成長明示為本作改編。
- **美術**取得輪廓、發射／接觸位置、武器持有和釋放、身體與夥伴的前後關係及動作優先順序。姿勢不是單格插圖清單，需能串成上述動作鏈。
- **戰鬥／程式特效**取得與實際階段相連的要求：哪一刻才算接觸、是飛行碰撞或瞬時命中、先束縛還是先爆發、哪個目標會被搬動。特效不能暗示不存在的抓取、傷害或無敵；動漫 agent 不自行改傷害事件。
- 發現玩法與表現衝突時，以具體反例提問並共同修正。保留本專案已調好的操作與鏡頭選擇；爽感不等於新增震屏、停頓、過長演出或遮滿畫面。

## 誇張能力仍要有角色的動作因果

以已核對的角色版本與既有來源為界，可以大膽放大同一能力的規模，不把考據當成保守數值的理由。以下是仙台角色的**遊戲改編方向**，不是宣稱原作已有這套自動連段或卡牌機制：

- **乙骨**：戒指啟動 → 同一里香持續具身協戰 → 刀術與爪擊交錯接力 → 顯現時多段群體重擊。里香可追近、換位、連擊與壓制大片敵群；數量成長可以增加真實攻擊段數、協擊波次或有效目標。保留主人與夥伴兩個行動者，不以多隻複製形體或無來源魔法陣代替協戰。
- **石流**：額前壓縮亮核 → 多輪重型貫穿砲／多道砲束 → 持續壓制與短餘波。可以增加輪數、砲道、覆蓋與密度；每輪仍接當格額前源點，不能變成與身體無關的空降雷射。重新瞄準或掃射可作遊戲編排，不為維持舊版放空風險而禁止。
- **烏鷺**：抓取大片天空 → 拉成巨幅折面 → 沿面連續裂破 → 真正反射後接連段反擊。可以增加折面、裂破波次與反擊段數；畫面與命中都要有壓制效果。保留天空被當成面抓拉／偏轉的語意，不改畫成冰錐或岩石術。

「保留身份」約束的是力量來源與動作關係；範圍、段數、持續時間、命中規模與成長曲線交給本作企劃和當次實玩調整。強化應造成真實的多次／多目標命中，不只是把一擊畫出更多殘影。

## 複核與交付界線

在正常遊戲尺寸與場景看完整出招，而非只看放大圖集：能否不讀技能名稱就指出「誰做什麼、力量從哪裡來、碰到誰、為何產生該結果」。至少檢查改動涉及的準備、命中與收勢，夥伴／變身則包含獨立動作與狀態切換。人物或敵方危險被遮住時，交回美術／整合修正。

報告用「來源已核對／動作關係已接入／正常畫面已看／仍待實玩」標明實際進度；舊截圖不能證明新程式已通過。動漫相符、命中正確與玩家覺得好玩是不同結論，不能互相代替。新角色完成度需由本次遊戲證據及使用者實玩確認。
