# 動漫考據與招式轉譯指引

供現有 `design_anime_art` 的動漫考據工作使用；與[美術指引](art-agent-instructions.md)分工，不建立另一套角色或固定技能模板。先讀[角色共同品質標準](../character-quality.md)，再按任務讀[現行實作對照](anime-benchmark.md)與本次角色。使用者已調好的火影角色是手感參照，不是所有新角色的招式模板。

## 從演出辨識角色

### 烏鷺造型與空間遮蔽（使用者明確要求）

使用者進一步指定：她扭曲空間，使看向重點部位的視線偏折。參考圖上的淺藍形狀是視覺結果，不代表兩塊實體藍布；必須以背景／天空的取樣與折移表達光學遮蔽，換環境時自然呼應背景。不可只把衣服換成固定藍色貼片。

2026-11-06追加驗收：腹部必須正常可見，胸前與腰胯的遮蔽保持分離。v7把胸腹整片隱去，使用者已明確否定，不能再以「覆蓋較寬」註記成通過。底圖若沒有腹部像素，先取得合格的非露骨素材，不能靠縮遮罩露回舊衣服或用光學空洞假裝有腹部。

烏鷺以操控天空／空間遮住身體重點，這是角色造型與能力的同一件事。不可自行改成普通衣服、泳裝、貼身衣或把幾何線當遮蔽。動漫 agent 必須對照當次實際素材、正常遊戲畫面與連續動作，確認遮蔽是天空平面／背景被折移的結果，且任何方向、鏡射、走路、起手、接觸、收勢、受傷、倒下都持續遮妥，不展示明確私密部位。保留頭髮、臉、四肢及施術手勢可辨性。

交付要指出哪一張圖格、哪一段畫面符合或不符合，不能用來源網址或「原作沒穿衣服」代替實際造型驗收。美術與動漫分別看過當次遊戲證據後才可判定完成；玩家指出造型錯誤時，撤回受影響的舊通過結論。

先建立指定時期的能力盤點，再與遊戲逐項對照；必列已實作、確定遺漏、已存在但語意／用途不足、未確認及後期能力。舊報告的「不新增」是當次範圍決定，不能當成原作沒有該能力的證據。官方已證明某招發動時，分開記錄「存在已證」與「名稱、具體效果未明」，不因效果不明刪掉發動事實，也不憑空補必中效果。

收到玩家「無感」回饋後，核對動作所承諾的效果是否真的發生。例如別動應逐項核對移動、攻擊、施法及在途攻擊；不要把圈、文字或短暫減速直接驗收為敵人被喝停。交付來源與可見結果，再交企劃決定遊戲強度。

先說清楚這次角色的版本、玩家應感受到的能力，以及一個不能丟掉的招式關係。例如施術者如何接近或抓住目標、力量從何處發出、夥伴與主人如何協作、蓄勢如何轉成命中；不能只列招名、髮色和官方網址。

- 查現行載入與戰鬥／動畫程式，確認已實作內容；舊提案與舊驗收紀錄只作歷史參考。不得把使用者後來調好的連段、普攻、常駐強化改回早期規格。
- 研究足以支持本次改動的官方原作、動畫或官方遊戲資料。記錄實際檢視的頁面／圖／片段及定位；搜尋摘要、縮圖、每秒取樣、完整播放與聽過音訊的證據能力分開寫。沒看過的資料只標待核對。
- 把每個關鍵招式寫成短動作鏈：**起手意圖 → 演員／目標相對位置 → 發力或接觸 → 結果 → 收勢**。指出哪些步驟是角色辨識所必需，哪些可因生存遊戲節奏縮短或省略。
- 明確分開原作能力、特定作品／時期版本，以及本作的數值、索敵、群攻、首領抗性、卡牌與自動觸發改編。授權遊戲可以支持該遊戲的名稱或招式，不能自動證明動畫時序。
- 不為湊四招、固定解鎖等級或缺一種 AOE 而借用他人／後期能力。原作的一種能力可有多種本作用途，但需說明用途差異，不能冒充多個原作術式。
- 可以新增服務既有能力循環的技能或被動，並用清楚的遊戲效果命名、標示「本作改編」。例如協戰後的追加攻擊、場域命中後的殘響不需要偽造原作同名招式；也不能藉改編標籤偷渡未核對的領域、角色時期或他人能力。

## 交給企劃、美術與戰鬥作者的內容

只交付會影響決策的資訊：來源與版本、必要動作關係、可改編部分、已知缺口，以及一個可在遊戲中檢查的辨識目標。

- **企劃**決定成長與強度；動漫 agent 說明哪些改編仍保有能力語意，哪些已變成另一種能力。原作證據用來確定身份，不規定遊戲數值。使用者要求誇張爽感時，允許擴大實際群傷、連擊、協戰、覆蓋與頻率，不把舊範圍、CD、四招配置或必留空窗當成限制，也不為每次強化硬加代價。這些規模與成長明示為本作改編。
- **美術**取得輪廓、發射／接觸位置、武器持有和釋放、身體與夥伴的前後關係及動作優先順序。姿勢不是單格插圖清單，需能串成上述動作鏈。
- **戰鬥／程式特效**取得與實際階段相連的要求：哪一刻才算接觸、是飛行碰撞或瞬時命中、先束縛還是先爆發、哪個目標會被搬動。特效不能暗示不存在的抓取、傷害或無敵；動漫 agent 不自行改傷害事件。
- 發現玩法與表現衝突時，以具體反例提問並共同修正。保留本專案已調好的操作與鏡頭選擇；爽感不等於新增震屏、停頓、過長演出或遮滿畫面。

## 誇張能力仍要有角色的動作因果

原作約束演員、力量來源與招式動作的身份，不是遊戲強度的上限。可以大膽放大已核對能力的規模；依角色選適用的關係，不要求每人都有夥伴、連砲、場域或反射：

- **具身夥伴／變身**：若設定是同一個夥伴，就由同一實體完成跟隨、追擊、接觸、收勢與形態變化；形態強化要看得到量級與協作差異。真連擊、波次或有效目標可隨成長增加，不以裝飾複製形體冒充；原本就是多體召喚的角色則依自身設定處理。
- **連續發射**：每輪從對應姿勢的真源點釋放，發力、接觸與回彈有對應事件。可以擴大砲道、輪數與掃射覆蓋，不把身體發出的招式畫成無來源天降攻擊。
- **多波場域／反射反擊**：先交代抓取、展開或施術如何形成場域，再把每波真實命中接到破裂或壓制。反射要能追溯來襲、接觸點、返向及後續反擊；殘響、反擊是否可再觸發由企劃明定，不讓裝飾動畫自行產生連鎖。材質語意保留本角色能力，不能只因碎片方便就把天空術改成冰術。

範圍、段數、持續時間、命中規模與成長曲線交給本作企劃和當次實玩調整，明示本作改編。強化應造成真實的多次／多目標命中，不只是把一擊畫出更多殘影。

## 複核與交付界線

在正常遊戲尺寸與場景看完整出招，而非只看放大圖集：能否不讀技能名稱就指出「誰做什麼、力量從哪裡來、碰到誰、為何產生該結果」。至少檢查改動涉及的準備、命中與收勢，夥伴／變身則包含獨立動作與狀態切換。人物或敵方危險被遮住時，交回美術／整合修正。

用當次狀態紀錄核對截圖確實處於所標階段，連續招式要核對輪次、每輪源點與真實接觸；不要把接觸格當收勢，或把較早的普通招截圖當成新大招。用實際錄製的正常自動施放片段檢查動作鏈與相關高成長配裝；取樣圖只證明所取時刻，不稱完整播放、逐幀或音訊體感驗收。手機及低品質也要保留角色身份與危險辨識。

獨立複核發現命中／清理問題時，交給戰鬥作者具體觸發步驟與應有結果，再以測試確認修正。例如首名目標的受傷回呼清場或移除技能時，要測同波下一名目標及未來波次都不再受傷；只有單一目標的取消案例不足。這類程式契約不能靠美術評分或多人投票判定通過。

報告用「來源已核對／動作關係已接入／正常畫面已看／仍待實玩」標明實際進度；舊截圖不能證明新程式已通過。動漫相符、命中正確與玩家覺得好玩是不同結論，不能互相代替。新角色完成度需由本次遊戲證據及使用者實玩確認。
