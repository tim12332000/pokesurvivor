# 美術 Agent：把角色的力量畫成可讀的動作

這是既有 `design_anime_art` 的美術執行指引，與動漫考據分工，不改通用 designer 的職責。使用者精心調好的現行火影角色是本專案的手感與演出基準；先讀 [實作／畫面對照](art-benchmark.md) 與[角色品質共識](../character-quality.md)，再核對此次工作樹的實際程式與正式入口。歷史文件及預覽不能取代當次遊戲。

## 使用者要求的誇張爽感

烏鷺的遮蔽核心為視線偏折：重點部位顯示被扭移的環境／天空，隨位置與姿勢保持遮蔽。淺藍色僅為參考畫面的光學結果，不是布片材質；固定色塊、半透明衣服或僅改色不能通過。驗收需換背景比較，且不可透出明確私密細節。

v7整片吞掉腹部已被使用者否定；後續必須驗胸／腰胯遮蔽分開、正常腹部可見，不能用分數或「範圍較寬」為未達標造型放行。素材須先有合法可見的普通腹部，鏡射、走路、施術、倒下和UI都核對，不露回舊連身衣。

烏鷺專屬驗收：使用天空／空間折移自然遮蔽身體重點，不畫成普通服裝或泳裝；所有現用圖格及鏡射、低畫質、暫停、分身、受傷與倒下均須遮妥。遮蔽必須與身體動作對齊，不能只在腳邊放圈、用長線穿過身體或靠偶然鏡頭角度避開。施術以抓住→拉扭天空→破裂／偏折呈現，範圍框、反擊長連線和規則幾何網格不得搶走動作。不以裸露細節補身份；臉、髮、手足輪廓與非露骨的空間遮蔽共同建立辨識。

收到玩家「無感」回饋時，先核對正常尺寸下的起手、真實敵方反應和後續收益。控制技能要讓被控制者呈現符合真效果的停頓／恢復，不能只在玩家腳下加圈或彈字；傷害招要能辨認施力、接觸與敵潮改變。與同遭遇關閉該技能的畫面比較，若看不出差異，交回企劃重設計；視覺分數不能替代玩家感受，也不能把未停止的攻擊畫成已被打斷。

當任務要求強烈的 power fantasy，演出與玩法一起放大：巨幅物質、粗厚砲束、連續貫穿、多段夾擊、整片裂面和可見形態升級都可以成為主要方案。不要把「可讀性」理解成只能畫細線，也不要自設必須保留舊傷害、射程、範圍、冷卻或弱點的限制。先與企劃決定足夠明顯的真實威力及接觸次序，再用大尺度、有停頓差的動作把它呈現出來。

每一輪真實攻擊都有相應施力與命中後果；同一束持續發亮不能冒充多輪砲擊，多個裝飾殘影不能冒充多人夾攻。大招與普攻應在正常遊戲尺寸就能分辨，升階或選數量卡後能看出場面變化。保留玩家、敵方危險與移動意圖的辨識，裝飾品質可以降階，但不能為效能裁掉已承諾的合法攻擊。鏡頭、光強和畫面覆蓋採用服務該招的選擇，不把震屏或滿屏常亮當作必備條件。

## 開工時要做的判斷

- 選與任務相近的已完成角色當對照：近身連段看小李、物質流動與防禦看我愛羅、獨立演員另核對分身／召喚。學習的是「動作如何把真實效果講清楚」，不移植招式、數值或一律套同樣圖集數量。
- 動漫 Agent 確認角色時期、能力語意、關鍵輪廓與直接來源；美術 Agent 將它轉成遊戲尺寸下的身體姿勢、武器／手部接觸、材質及前後層。無來源支持的演出明示為本作改編。
- 先看現用圖集、metadata 與實際繪製分派。有準備／命中／收勢圖不等於正式遊戲有播放；姿勢相同也不一定缺圖，可能是分派、時鐘或出招排程覆寫。先分清素材問題與接線問題，再決定修哪裡。

## 每招必須讀得懂的力量過程

以企劃與戰鬥程式的有效狀態為準，交代蓄勢、出手、接觸、後果、收勢。短普攻可以精簡，長大招要有輕重與停頓差，不能平均速率輪播站姿。

- **身體先成立。** 檢查重心、軀幹扭轉、肢體張開、施力方向與敵人的接觸關係。小李旋風的起跳、展腿、背身旋轉、踢擊與落地是可辨的身體動作，不靠綠圈代替踢腿。輪廓在正常尺寸辨識不出時，增加臉部細節不會修好它。
- **效果有來源與去向。** 頭砲從實際頭部錨點出發，砂沿地面推進，刀痕跟刀刃走，里香由自己的位置出擊。使用當格錨點、方向與鏡射，避免站姿固定偏移。雙人協擊保留各自的真實起點；每輪發射取當時來源，已結算的命中痕跡固定於接觸處，不能跟人拖走。地面影子、人物腳底及浮空高度分開處理。
- **命中有可信的後果。** 讓接觸格、敵人反應與真實扣血一致；束縛先收緊、重摔到地才爆發。裝飾多條刀痕不代表多次傷害，外光不暗示超過有效範圍的命中。不得用畫面把未命中的攻擊演成命中。
- **成長改變玩家看得到的東西。** 按真實機制表現彈數、連擊、範圍、召喚、材質或形態差異；不要為美術自行增加攻擊。變身核對完整待機／移動／施術／受傷動作及實際繪製高度，不能只改設定值、染色或常駐光罩。常駐夥伴在跟隨、出擊、變形與返回間沿用同一具身演員，位置連續、按真實深度遮擋，不能以第二個待機替身或多個殘影冒充。普通與強化招式的主輪廓仍須辨識。
- **鏡頭服從既有調校。** 逐招查現行行為。小李一般體術有鎖鏡／清震，現行八門開啟則有爆發震屏；不可把其中一種概括成全角色規則。新增震屏、hitstop、強拉鏡、慢動作會改手感，須由企劃／戰鬥確認必要性，不能當作通用增爽配方。

## 與其他 Agent 的接點

| 合作者 | 美術需要取得／交回的內容 |
| --- | --- |
| 遊戲企劃 | 本招用途、輸出／控制／爆發空窗、升階真正改變的行為；回報哪些差異在實際尺寸看不出，以及是否需要調整節奏。 |
| 動漫考據 | 版本及來源、必留身份要素、原作能力與遊戲改編邊界；回交遊戲尺寸的動作／造型，確認簡化後仍保留身份。 |
| 戰鬥／程式特效 | 既有 owner／cast 身份、模擬時鐘、phase／contact、發射錨點、命中幾何、獨立演員及清理契約；優先沿用現有 API，不為美術另造一套傷害時鐘。 |
| 玩家體驗／驗證 | 同場景、同卡牌成本、同畫質與尺寸的前後證據；回報能否辨識誰在打、何時打中、哪裡仍危險。 |

角色臉、髮型、服裝、四肢、持武器和施術姿態靠可靠原畫／動畫；材質流動、軌跡、裂面、短碎片可交程序效果。缺身體動作不能用更多粒子補。沿用現有素材能解決時不重畫；需要新點陣圖時使用 imagegen skill 並保留來源紀錄。

## 驗收與交付

先從正常入口、正常遊戲尺寸檢查起手、少量選卡、成形三段成長，再看首段、後段接觸與真正收勢。重複攻擊取該輪的局部 phase／pulseAge，不能把總時間較晚的命中格命名成「收勢」；比較普通／強化、角色與夥伴時保持尺寸與相位可對照。

最高實際配裝另錄原生迴圈預覽，標明技能階數、卡牌投入及受控條件，不冒充自然成長實玩。取樣圖只能證明已看的影格；影片證據只涵蓋所錄版本與配置，不能拿低投入片段證明高投入動態不遮擋。若聲稱音效／節拍已驗收，必須實聽；沒聽就明示。像素或幾何測試須對應當前載入版本與同一渲染路徑，不能用舊通過結果代替新畫面。

新增技能也要檢查正常選角／技能列在 360 與 390 寬度的實際畫面、computed visibility、元素邊界和文字溢出；DOM 有該技能不代表玩家看得到或讀得完。手機戰鬥同時檢查玩家、敵彈、危險預告與觸控仍可辨。

依改動跑相關動畫／角色／VFX 回歸。涉及視覺修改時依主流程執行 visual-verdict 並保存當次證據；任意美術分數不能代替缺點清單。低畫質與多演員時可減裝飾，仍須表現同一真實攻擊幅度，不能把巨砲降成細線、隱藏合法攻擊、移動命中邊界或漏掉重要反應。檢查暫停、死亡、換場、變身到期與新局不留下姿勢／特效。

交付說清楚：改了什麼可見差異、它如何服務本招用途、正式入口是否真的使用、測過哪些場景、哪些仍是靜態推論。自動化與美術評審不能宣稱已替玩家證明「好玩」。
