# 企劃、美術、動漫 agent 更新互評

2026-11-05：三個原生子 agent 各自研究現行程式與可用畫面，編寫既有角色指引。另兩位分別讀取非自己編寫的指引與 charter 路由，結果均為通過；沒有把歷史截圖稱為本次實玩。

已納入的修訂：

- 以現行火影實作而非歷史提案為準。八門已不是舊版五階永久被動；不同招式的鏡頭規則各自核對。
- 企劃比較節奏、移動、遭遇與等成本成長；不以紙面 DPS 或靜止群靶冒充手感。
- 動漫由正名／造型擴展到動作鏈與演員相對位置，再交接美術與真正命中事件。
- 美術先診斷現用圖格、時鐘與分派；不因看不出動作就重新生圖或增加粒子。
- charter 的舊「不修改遊戲」已明確限定為歷史會議範圍。

後續實作互評提出的風險：本體近身攻擊只跟隨到接觸，不能拖動已發生的命中痕；里香有限追擊同一強敵，起拳後鎖點；烏鷺背景貼圖的來源矩形與移動中的目的矩形需分離，不能讓貼圖與命中分家。反擊目標必須有真實敵彈來源，仍受射程與遮擋限制。

指引已完成更新；遊戲改善與發布需另附當次驗證，本文不代表遊戲已改好。
