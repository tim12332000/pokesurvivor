# 遊戲企劃 Agent：以現有完成角色校準

這是既有 `design_gameplay` 的後續任務指引，與[角色品質共同指引](../character-quality.md)配合使用。服從主代理當次範圍；只要求改善 agent 時，交付指引與分析，不改遊戲、不發布。

## 先理解玩家已經調出的成果

使用者親自調好的火影角色是本專案的手感參考。開始新角色設計或改善前，先讀[現用程式基準](naruto-benchmark.md)，沿正常入口的載入順序確認目前實作與覆寫，再選與任務相關的角色實玩。舊企劃、提案、既有測試通過紀錄只是線索；與目前執行程式衝突時，重新查證，不把舊值抄回去。

分析的是設計關係：普攻如何接住空檔、重招如何形成高潮、成長如何改變場面、移動如何保有玩家意圖。不要讓新角色複製火影招式、數值或操作模式，也不要為了統一模板改掉使用者已調好的角色。

實作前一次規劃完整招牌循環：進入條件、主體／獨立演員分工、真實連段、收束及下一輪銜接，並把第一張、幾張與成形投資接進這條循環。乙骨／烏鷺案例見[雙人連打與連續裂面](../../jjk-duet-fracture.md)。技能數量依角色需要；有明確觸發、獨立用途與合法學習成本的第五招／被動可以補完循環，不受四招模板限制，也不為湊數新增同質輸出。

## 本專案的爽感目標

使用者已明確要求**誇張的力量幻想**：幾張成長卡就能看出規模增加，成形後能壓住整波敵人；招牌大招應在真實命中範圍、攻擊輪次與角色演出上形成高潮。設計要回答「從起始、初步連動到配裝成形，玩家會看到什麼越變越誇張」。石流巨砲案例見[當次設計與驗收交接](../../jjk-ryu-barrage.md)；數值屬該次實作，不是其他角色的固定模板。

命中跟身、索敵修正與冷卻調整是可靠性改善，不能單獨當作已完成上述目標。不要預設保存舊傷害、寬度、射程、CD 或每人必須有明顯弱點，也不要以平衡之名把使用者要求的強化改回去。需要代價或限制時，應來自當次玩法目標、實測問題或使用者要求；既有火影角色維持原調整。

誇張要落在真正的多輪命中、群體覆蓋、持續協戰與可感受的卡牌連動，不能用裝飾粒子、假分身或加長閃光冒充。效能與辨識問題先控制同時存在的裝飾、重用幾何與合併查詢；不能為保住裝飾而漏算合法傷害。停止、死亡與換場仍須結束在途效果，不能用殘留狀態製造假強度。

## 每項方案都要回答玩家能感覺到什麼

- **戰鬥節奏**：畫出實際施放到命中的時間線，區分冷卻、身體排隊、索敵等待、追身、前搖與收勢。觀察空檔是否有有效行動、重招是否經常放空、移動中的敵人是否真的被接上；「每秒傷害變高」不能單獨證明改善。
- **玩家主導**：說明靠近、撤退、繞怪、聚怪各會改變什麼。自動索敵／追身應支援距離管理；確認玩家想撤退時能撤退，不能用強拉位置或取消敵方威脅來修掉挫折。
- **成長回饋**：分開角色等級、學新招、技能階數與本局選卡。列出本次相關卡牌真正影響的消費端、取整門檻、上限與無效條件；核對多段／多目標是否真的增加有效命中。特別比較第一張、幾張與成形配裝，不能只在滿階、最高數量才有差異。技能升階可以改變節奏、覆蓋或連動，不必硬設每人相同階數斷點。
- **技能關係**：說清楚普攻、主招、召喚／獨立演員、防禦與變身誰能並存、誰讓出身體、誰給下一招機會。已存在的連動要先驗證；不能把重新提議同一功能當成新改善。
- **遭遇差異**：至少覆蓋任務相關的清怪、近身壓力、移動強敵／首領與障礙情境。記錄失敗原因與本次強化如何影響各情境，避免只測靜止密集敵群就宣稱角色全面好玩；不為滿足制式平衡表而強行保留弱點。

## 改動有因果、結果可判斷

先交付有程式／畫面依據的缺口、要改善的可觀察行為、改動範圍和驗收方式，再交給實作 agent。改動的強度要符合使用者目標，驗證則拆成能辨認因果的行為；不要把小 diff 誤當成必須保守調整。提高傷害、擴大範圍、增加真實連段可一起服務於力量幻想，但應說清楚它們如何改變場面及本局投資，不能只改數字就宣稱好玩。

波次、幾何、形態與數量上限由同一份角色能力資料或查詢函式供戰鬥、卡牌收益預覽與說明使用；不能讓企劃表、預覽公式與實際命中各存一套數字。多段／協戰／殘響需定清楚事件歸屬、一次性觸發與是否可再觸發，讓獨立演員或後續波次真的延續玩法，而非重複展示同一筆命中。

比較前後時固定入口版本、永久能力、選卡成本、已學技能、技能階數與遭遇條件；配對使用相同 seed，並保留必要的正常成長遊玩。直接設成 20 級不等於完成 19 次合法選卡；靜止靶場不能代替走位與首領戰。只改演出也要檢查是否拖慢身體排隊、降低命中或遮住敵方威脅。

將主張標成「程式確認」「本次實玩觀察」「待驗假設」。當次測試可證明命中、節奏、連動與性能；主觀爽感保留給玩家實玩回饋，不能用自評分數或自動化通過替代。

設計時就列出足以交付的相關證據及停止條件，整合驗證一次收齊；只有新變更、失敗或未解風險才擴大／重跑，避免反覆跑相同全套測試拖延交付。實作與驗證後段不臨時擴成另一套養成或更多技能；新要求納入當次範圍，非必要想法留待下一輪。回報以完成的招牌循環、成長差異與證據缺口為主，不用大量檢查紀錄掩蓋體感尚待玩家確認。

企劃交給美術的是距離、方向、階段、真實命中事件與高潮時刻；交給動漫 agent 核對能力與版本，不能為連動憑空新增原作能力。收到反例後修正方案，不以原作忠實度或測試全綠迴避手感問題。
