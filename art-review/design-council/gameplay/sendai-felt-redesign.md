# 三角色：玩家可感受的技能重設計

狀態：2026-11-05，企劃靜態診斷與待實作方案。這份文件沒有宣稱新玩法已實玩通過。動漫 agent 的動畫能力盤點尚在進行；下列不鎖定最終技能數、不憑空新增原作能力。工程正確、效果可辨與玩家喜歡分開驗收。

## 最值得先處理的兩個問題

### 1. 「別動」沒有真正阻止威脅，也在角色成形後讓出場機會

程式事實：`.omx/jjk-yuta.js` 的 `lease()` 對普通敵人設 factor=0，強敵=.65；檔尾 `Enemy.prototype.update` wrapper 先完成原生 update，再回縮位置。敵人的思考、射擊、攻擊倒數均已執行。`js/systems/combat.js` 接觸段只排除小李綁定／君麻呂抓取，沒有咒言豁免。它不是完整的停止行動。

第二個缺口是時機：`canCast()` 在 `duetActive(s)` 時拒絕非里香招式；`C.tick()` 次序是顯現→里香→咒言→刀。顯現高拳數時咒言不能在包圍壓力出現時救場。僅延長控制秒數仍會讓玩家感受不到。

提案：將別動做成有獨立反應時鐘的「喝停敵潮」窗口。既有刀／里香連段繼續，咒言不重置連拳、不多生里香、不強迫本體移動。聲紋由嘴部一次爆開，命中的敵人有清楚的定身符號／僵停姿勢，頭上顯示剩餘控制進度；效果停止即移除，不能只畫乙骨周圍的圈。

下列數值為本作待驗起始假設，不是動畫規定：

| 契約 | 普通敵人 | 首領／精英等強敵 |
| --- | --- | --- |
| 移動 | 停止2秒，三階2.4秒、五階2.8秒 | 停止0.7秒，三階0.85秒、五階1秒；不設永久鎖死 |
| 普攻／射擊／施法 | 控制期間不開始新行動；待發起手停住，結束後至少保留短讀招，不瞬間補完所有欠下攻擊 | 一次短暫喝停；正在讀招的攻擊延後，仍可在結束後讀招再發，不能靠每幀重設永久取消 |
| 接觸傷害 | 控制期間不造成主動接觸傷害，讓玩家真能穿過停住的敵潮撤退 | 同樣在短控制期間停用接觸傷害，結束後恢復 |
| 已發射敵彈 | 保持運作；不借咒言變成全場消彈。UI明示「已射出的敵彈仍危險」 | 同左 |
| 外部狀態／DOT | 燃燒、中毒、外部慢速與其他控制時鐘保持原契約，不覆寫；不能藉跳過整個update把DOT也凍住 | 同左 |

第一階範圍建議由160提高到240，三階280、五階320，仍真實檢查牆和範圍。範圍成長必須讓第一個範圍投資多抓到一圈真敵人。控制秒數不隨數量卡無限加，沒有消費端就不聲稱該卡能強化咒言。

觸發：附近敵人正構成近身威脅或至少三人包圍時使用；里香正在連打也可以發動。保留8秒起始冷卻作待驗值，不以縮CD代替功能。停住後，既有里香追擊和刀斬自然兌現窗口；先不新增免費終拳或多一套傷害buff，以免無法分辨「停住」本身是否有效。

動畫邊界：本案只使用已存在的咒言身份。反應通道、控制秒數、群體範圍和UI是本作改編；後續由動漫agent核對動作及版本。真正控制要接入敵方行動／接觸管線，不能繼續以回縮位置冒充。

### 2. 烏鷺防禦招在「沒有敵彈」時整招消失

程式事實：`.omx/jjk-uro.js` 的 `threatened()` 只檢查敵彈；`canCast(uro-screen)` 要求 threatened。反射後獨立反擊、逐波裂面與固定殘響都已存在，不能重新提議為新功能。現行描述也明說不擋近戰，因此現在不算程式bug；但學會一個防禦技能後，在近身敵潮中沒有可感受收益，是完整循環的設計缺口。

提案候選：待動漫盤點核對天空操術對近身攻擊的實際用法，將「折面卸開近身來襲」列為獨立用途，而不是只把天空幕改成透明護盾。若動畫證實，可在有容量的空面上對真正接近的單次敵方攻擊折向／卸開，沿用有限容量；事件必須由實際威脅觸發，不能每幀免費AOE。若來源仍不足，本輪先不實作近身能力，維持明確說明並以射手遭遇驗證反射的可感受性。不要用牽強補一個普通護盾填槽。

## 現有每招移除對照

以下為程式確認的用途及待實玩假設；沒有把所有差異都宣稱玩家已感受到。

| 角色／技能 | 現在移除後真正少了什麼 | 缺口判斷與本輪處置 |
| --- | --- | --- |
| 乙骨刀斬 | 近身本體攻擊、三階接力標記；顯現連拳的本體刀來源 | 已有獨立用途，保留。要驗證本體走位仍能把刀落在有效敵人，不能因遠端里香命中就宣稱刀也中了。 |
| 里香協擊 | 唯一常駐夥伴、遠端連打及擊殺轉火 | 先前已實作，保留。回歸少量卡4→5拳，不能把轉火再當新設計。 |
| 咒言別動 | 現在只少短位移限制與小額傷害 | 主要重設計；需讓進攻中的敵潮真的停住，且成形配裝也能及時用出。 |
| 完全顯現 | 實體巨大化、雙來源刀拳、更密連打、輸出窗口 | 已有招牌，保留。需要修正它與咒言的互斥，不能以整套連打更強掩蓋控制招失去出場。 |
| 協戰共鳴 | 末拳命中後本體寬範圍收束 | 已有連動但末拳被遠端里香打中時，本體周圍可能無敵人；應檢查有效收束發生率。不得將共鳴搬到里香位置變假本體遠端拳；若無有效目標可短暫保留就緒機會，再由本體接近使用，不免費追整張地圖。優先級次於咒言。 |
| 石流普通砲 | 穿線、普攻節拍、蓄能與精英優先 | 真正骨幹，保留。 |
| 散射咒力砲 | 近距廣角飛行彈、不同目標清理、一次蓄能 | 已有真正不同幾何與新增蓄能，先驗第一張數量卡新增砲道有真受益，不再只加彈數上限。 |
| 咒力爆破 | 可達密集群預告後固定圓形爆點、一次蓄能 | 敵群可離開爆點；有無此招對照須看移動群怪清除／巨砲兌現，不能只測靜止群靶。先保留，不憑空加吸怪。 |
| 全力咒力砲 | 三格後巨大主砲＋真實多輪連轟 | 已有明顯高潮。不能把同一巨砲加亮當整個角色重新設計。動畫盤點若有確定遺漏能力再決定完整組合。 |
| 烏鷺掌擊 | 近身前扇推退、基本節拍及末擊殘響來源 | 已有用途；強敵不被搬動應看本體移動是否保有安全空間。 |
| 宇守羅彈 | 隨本體移動、逐波轉面的寬幅連續碎面 | 已有真實成長與轉火，保留；別重提成新機制。 |
| 天空幕 | 有限實際攔彈、首次反射的獨立反擊 | 射手遭遇用途明確，近身遭遇沒有收益；等動畫考據決定是否補近身折面。 |
| 空面震落 | 可離手的固定巨裂場，本體可繼續下一招 | 與隨身扇波有模型差異；需要讓玩家看懂「放下固定裂區後能走開」，不能只更大同色圖。 |
| 裂面殘響 | 末波真命中後留下固定追加攻擊 | 被動收益可能被本體多波淹沒，測「離開後仍殺敵」可辨性。保留位置，不強制追蹤，避免與宇守羅彈同質化。 |

## 完整循環與少量投入

乙骨：起始用刀保持近身接觸；Lv.3里香讓本體可邊走位邊遠端協戰，第一張數量卡4→5拳；學別動後，包圍中的敵潮真停，玩家能穿過缺口或留在近身讓刀拳接力；顯現後同一里香巨大化、本體逐拳接刀，別動仍可在壓力時出現；共鳴收束而不是讓連段結束後空放。動畫確證的反轉／模倣能力另待整合，不以現有五招為上限。

石流：起始穿線與距離管理；散射處理前方多方向，爆破找密集群，兩者已能各蓄一格；第一張數量卡增加真飛行砲道／巨砲追加輪；成形看到三種施放命中推進蓄能，巨大主砲帶真連轟清出長走廊。避免以自動瞬間滿能量替代這條可見因果。

烏鷺：掌擊保近身距離；宇守羅彈沿走位轉面壓住新敵潮，第一張卡4→5真波；天空幕在射手來襲時實際反射並發動獨立反擊；震落將固定巨裂放在群聚點後玩家可走離；成形以末波固定殘響維持離手地區。缺少動畫技能的部分由盤點補齊，尤其天空操術的近身語意。

## 足以改變判斷的驗收

固定同seed、相同學招與卡牌成本、永久能力、敵人分布與攻擊意圖，比較有／無單項技能；錄正常入口原生短片，顯示階數／卡數，桌機與390px手機。不是只看受控高配DPS。

1. 別動：三名近戰接近＋一名準備發射的射手，先拍無技能的威脅，再拍有技能的定身、停止新射擊、接觸安全與控制結束讀招恢復。已在途的彈仍造成威脅，不能全場刪除。範圍外／牆後不受控。
2. 別動＋成形：完全顯現24拳中出現近身壓力，咒言能發動；里香castId／strikeIndex不重置，只有一個里香。普通／強敵各測控制到期，沒有攻擊補發潮。外部DOT及慢速仍正常。
3. 別動成長：第一個範圍／三階／五階投資在同一分布圈能多停住真敵人或擴大可撤退窗口；若只看到說明增加數字，判不通過。
4. 石流：移動群怪有／無散射及爆破，記錄每種真命中、失誤與巨砲到達時間，同時看玩家能否指出哪招改變局面；不用壓低普攻造假收益。
5. 烏鷺：射手遭遇有／無天空幕的敵彈實際折返與原射手受擊；近戰遭遇另拍用途差距。固定震落／殘響要在玩家走離後仍留下可辨的清怪後果。
6. 控制需查暫停、死亡、換場、退學、分身、多來源與同波回呼取消。機制測試過關後只證明機制，不宣稱玩家已認可；使用者再回報無感時回到此對照找原因。

## 本lane交付界線

只新增本企劃文件，未改runtime、未提交或發布。羈絆／精通使用者報錯由獨立debug lane排查，不用新玩法掩蓋卡牌流程故障。建議先實作咒言完整控制與反應出場，再依動漫盤點決定剩餘技能組，最後才凍結打包。
