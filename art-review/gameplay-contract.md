# 完整動作內測

目前預設使用九張同一風格的重新繪製圖集，涵蓋三角色與一尾、八門形態，共 216 個實體影格。參考 Ninja Council 3 的比例、描邊及動作語意，沒有把其角色精靈圖直接用作現版。來源、提示詞與雜湊見 [redrawn/provenance.json](redrawn/provenance.json)；關閉「自繪動作」才會進入舊版比較模式。

入口：<http://127.0.0.1:8004/art-review/playtest.html>。本頁嵌入這個分支的實際遊戲，不是分鏡播放器。選鳴人、佐助或小李即可開始；新版完整動作預設開啟，取消勾選可對照原版。

使用 WASD、方向鍵或觸控搖桿走位。遊戲自動索敵、自動施放目前技能，1–5、Q／E 或技能選單切招。「升一等」會開啟正常升級選卡；「解鎖本角色所有招式」只改本局技能槽與已學招式，不改傷害、冷卻或存檔。寫輪眼與八門遁甲是被動，學會後自動生效，並非需要反覆主動施放。

共通圖按實際 alpha 人物輪廓裁切，不假定等分格線就是人物邊界。技能圖使用人工檢視的裁切與腳底座標，排除跨格特效與重複人物。姿勢依模擬時間播放，暫停不推進；斜向選最近的四個正方向，不宣稱八方向獨立美術。側面技能以鏡射表現左右，上下攻擊沿用側面姿勢。

九項技能都有對應的新繪施術、推掌、投擲或拔刀動作，飛行忍具與被動效果沿用原戰鬥層。普通角色具正面、背面、側面動作；側面向左鏡射。一尾與招式圖是側面圖，上下移動／瞄準沿用側面，不宣稱獨立八方向美術。鳴人分身也使用同套新圖；螺旋丸已畫入手部時，不再重複畫舊分身光球。

原本傷害、冷卻、碰撞、控制與目標規則沿用遊戲。投擲銜接實驗保留出手前切招取消、手部原點跨牆取消的待審行為；出手後切招不移除已投武器。千鳥與豪火球以實際技能階段決定姿勢，走路圖不覆蓋施術。

角色與技能設定沿用 `.omx/naruto/sources.json` 與技能資料中的直接來源；鳴人與佐助沿用既有數值，小李招式另見下節。[官方鳴人招式介紹](https://naruto-official.com/en/news/01_1423)與[官方佐助奪還篇回顧](https://naruto-official.com/en/news/01_1296)提供分身、螺旋丸、螺旋手裏劍、千鳥與豪火球的原作／特定遊戲脈絡；本遊戲的數值、少年造型可學後期招式與姿勢組合屬改編。

使用者已於 2026-10-20 核准本版合併至 `feat/digimon-sandbox`。正常遊戲入口會等待重繪圖集完成載入再啟動；審稿頁保留獨立操作與舊版對照，之後的新候選不因這次核准自動採用。

## 小李

正常入口可直接選小李，招式於 Lv1／3／6／9 解鎖。

| 技能 | 實際戰鬥與演出 |
| --- | --- |
| 木葉旋風 | 近身扇形範圍攻擊，專用旋踢影格 |
| 表蓮華 | 實際接近、預備、挑空至高度 40、空中抱持／旋摔、平滑下降及落地，固定兩次命中；基傷 110（挑空 20%、重摔 80%）。接觸後設計 1.66 秒（固定步進約 1.68 秒），落地完整外圈對齊基準半徑 60，再畫內圈爆發 |
| 八門遁甲（被動） | Lv.6 起可學，共五階；永久攻擊增加 30／35／40／45／50%；自帶每秒最大生命 1／2／3／4／5% 回復；回血量與移速均增加（10 × 技能階級 + 角色等級）%，不佔主動槽、不需施放、不會疲勞；待機、移動、受傷、倒下及技能全部切換專用紅臉、白眼、豎髮圖集，第三階起氣場增強 |
| 裏蓮華 | 實際接近、預備 0.28 秒、高挑空 0.48 秒（基礎挑空高度 60，之後每次計畫空中踢擊再升高 8）、空中連段 D = 1.65／[1＋0.025 ×（C－5）] 秒（五階零數量加成時為 5／7／9／11／13 段，另加數量卡段數）、平滑下降 0.32 秒、重摔 0.24 秒及收勢 0.28 秒；含預備、重摔與收勢接觸後共 1.6＋D 秒，零數量加成時主目標五階總命中為 7／9／11／13／15 次；空中次數 C = 5＋2 ×（技能等級－1）＋Q，Q 每點增加一段。落地基準半徑五階為 100／120／140／160／180，每升階 +20；完整外圈標示實際邊界，內圈擴散爆發 |

蓮華有碰撞、距離及目標存活檢查。裏蓮華 lift／combo／descent 無敵，亦阻擋天氣／生命寶珠直接扣血；approach／windup／slam／recovery 與表蓮華維持可受傷，取消或結束不殘留無敵。兩招挑空前主目標死亡都取消，挑空後主目標死亡都完成下降與落地震擊。次要目標各僅受一次 35% 基礎傷害，主目標不重複吃範圍；角色死亡、換場、牆或距離中止規則仍保留。兩招冷卻分別維持 3／5 秒，冷卻期間的近身普攻保留；浮空演出使用獨立高度，不會改寫敵人的跳躍狀態。設計來源及取捨見 [lee-skill-design.md](lee-skill-design.md)，桌面與手機驗證腳本為 `tools/test_rock_lee.py`。

八門視覺參考使用者指定的 [Sprite Database 小李圖集](https://spritedatabase.net/files/ds/55/Sprite/RockLee.png)：Ura Renge 段落使用紅臉的獨立動作。本作五階共用重新繪製的完整開門形態；第一、第二階即紅臉及永久增益屬遊戲改編，不宣稱原作每一門都如此。

裏蓮華每次技能升階增加兩段空中連擊及限定空中階段無敵，皆為本作玩法改編；數量卡每點增加一次空中命中，地面範圍仍只在落地結算一次。

裏蓮華起手快照技能等級與數量加成 Q，中途拿卡或升階不改當次連段。第 n 次空中命中的基傷係數為 0.12 × 1.10^n，第一下乘 1.10、第二下乘 1.21，每次施放從第一下重設；挑空 0.10、重摔 0.30、次要目標落地 0.35 不乘此指數，最大生命百分比額外傷害也維持原比例。總主目標基傷倍率為 0.4＋0.12 × Σ(n=1..C) 1.10^n。既有數量卡最多 20，技能第五階、Q=20 時空中 33 次、總命中 35 次，空中連段依新公式縮短至約 0.970588 秒。這些數量與傷害遞增皆為本作改編。

八門自帶自然回復：每秒回復量 =（既有自然回復＋目前最大生命 × 技能階級 × 0.01）× [1＋（10 × 技能階級＋角色等級）／100]。自帶基礎回復五階分別為最大生命 1／2／3／4／5%／秒；例如第五階、角色 Lv.30，僅自帶部分即 5% × 1.8 = 最大生命 9%／秒，其他自然回復再另併計。回血倍率只乘一次，回復上限為目前最大生命；最大生命、技能階級、角色等級均動態更新。整合既有 Game 更新流程，暫停不推進；死亡、未學八門或非小李角色不取得此自帶回復，不使用第二個計時器。這是本作被動改編。

兩招均以可辨識的上踢、空中抱持／連擊、下降與落地姿勢表現較長連段。表蓮華設計 1.66 秒、裏蓮華設計 1.6＋D 秒（均不含接近）；表蓮華固定時間步進約 1.68 秒，裏蓮華依本次快照段數而變。表蓮華全程可受傷，裏蓮華仍僅 lift／combo／descent 無敵。冷卻各為 3／5 秒、起手時計算；冷卻期間補近身普攻，連段中不插普攻。兩招挑空後主目標死亡都完整落地；挑空前死亡、角色死亡、換場、牆與距離檢查仍可取消。提高基傷、延長動作及挑空後保留落地皆為本作改編。

裏蓮華逐踢升高與加速：起始挑空高度 60 世界像素，每次計畫空中踢擊再升高 8，峰值 H = 60＋8 × C；C=5／15／33 時峰值為 100／180／324。各踢擊時間間隔按 0.90 等比遞減，正規化後總空中連段時間 D = 1.65／[1＋0.025 ×（C－5）] 秒；上述 C 的 D 分別為 1.65／1.32／約 0.970588 秒，接觸後總長 1.6＋D，即 3.25／2.92／約 2.570588 秒（不含接近，固定步進可能稍有取整差異）。掉幀須補齊跨過的計畫踢擊；主目標死亡後仍按計畫升高並落地，但不補發對死者的命中或傷害。下降 0.32 秒從實際峰值開始。

高度僅用於演出，不搬動角色或敵人的地面座標，也不改寫原生跳躍高度。鏡頭隨超出的升高量向上追蹤，讓角色頭部保持在 HUD 下方；落地、清理或失去有效角色／世界時還原地面鏡頭。敵人傷害數字與命中特效跟隨蓮華視覺高度。逐踢升高、遞減間隔及高段數縮短等待是本作改編，原傷害、空中無敵及落地範圍規則不變。
