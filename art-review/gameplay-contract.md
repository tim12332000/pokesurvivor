# 完整動作內測

目前素材登記為 11 張重新繪製圖集，涵蓋鳴人、佐助、小李、我愛羅與一尾、八門形態，共 264 個實體影格、46 組動畫序列。實體影格數與不同序列重用的影格參照數分開計算。參考 Ninja Council 3 的比例、描邊及動作語意，沒有把其角色精靈圖直接用作現版。來源、提示詞與雜湊見 [redrawn/provenance.json](redrawn/provenance.json)；關閉「自繪動作」才會進入舊版比較模式。素材登記不等於全部功能驗收通過，以下我愛羅項目以專屬驗收報告為依據。

入口：<http://127.0.0.1:8004/.omx/digimon.html?lang=zh-TW>；審稿內測為 <http://127.0.0.1:8004/art-review/playtest.html>。內測頁嵌入這個分支的實際遊戲，不是分鏡播放器。角色範圍包含鳴人、佐助、小李與我愛羅；完整動作預設開啟，審稿頁取消勾選可對照原版。

使用 WASD、方向鍵或觸控搖桿走位。遊戲自動索敵、自動施放目前技能，1–5、Q／E 或技能選單切招。「升一等」會開啟正常升級選卡；「解鎖本角色所有招式」只改本局技能槽與已學招式，不改傷害、冷卻或存檔。寫輪眼與八門遁甲是被動，學會後自動生效，並非需要反覆主動施放。

左上「倍速」在單人遊戲循環 ×1／×2／×3，整體戰鬥加速且保留正常模擬步長；「自動選卡」開啟後，在升級時隨機選取當次提供的一張卡，不消耗重抽、不自動選道具或融合，也不定時切換技能。學到新招時保留原先選中的槽（該槽仍存在時）。暫停期間不選卡；新局回到 ×1、自動選卡關閉。

八門自帶自然回復：每秒回復量 =（既有自然回復＋目前最大生命 × 技能階級 × 0.01）× [1＋（10 × 技能階級＋角色等級）／100]。自帶基礎回復五階分別為最大生命 1／2／3／4／5%／秒；例如第五階、角色 Lv.30，僅自帶部分即 5% × 1.8 = 最大生命 9%／秒，其他自然回復再另併計。回血倍率只乘一次，回復上限為目前最大生命；最大生命、技能階級、角色等級均動態更新。整合既有 Game 更新流程，暫停不推進；死亡、未學八門或非小李角色不取得此自帶回復，不使用第二個計時器。這是本作被動改編。

兩招均以可辨識的上踢、空中抱持／連擊、下降與落地姿勢表現較長連段。表蓮華設計 1.66 秒、裏蓮華從起手含接近全程 A＋1.6＋D ≤ 3.3 秒；表蓮華 1.66 秒仍不含接近；表蓮華固定時間步進約 1.68 秒，裏蓮華依本次快照段數而變。表蓮華全程可受傷，裏蓮華仍僅 lift／combo／descent 無敵。兩招基礎冷卻均為 5 秒，技能升階不變，冷卻縮減卡有效，起手時計算；冷卻期間補近身普攻，連段中不插普攻。表蓮華挑空後目標死亡仍完整落地；裏蓮華真實致命傷目標保留 1 HP 到最後重摔，連擊不中斷；挑空前死亡、角色死亡、換場、牆與距離檢查仍可取消。提高基傷、延長動作及挑空後保留落地皆為本作改編。

裏蓮華逐踢升高與加速：起始挑空高度 60 世界像素，每次計畫空中踢擊再升高 8，峰值 H = 60＋8 × C；C=5／15／33 時峰值為 100／180／324。各踢擊時間間隔按 0.90 等比遞減，正規化後總空中連段時間 D = B／[1＋0.025 ×（C－5）]，B = min（1.65，3.3－A－1.6） 秒；若接近耗時 A ≤ 0.05 秒，上述 C 的 D 分別為 1.65／1.32／約 0.970588 秒，接觸後總長 1.6＋D 為 3.25／2.92／約 2.570588 秒；較長接近會先壓縮 B，整招從起手到收勢均不超過 3.3 秒。掉幀須補齊跨過的計畫踢擊；裏蓮華真實致命傷目標保留 1 HP，仍按計畫升高並接受全部後續命中；若外部直接設為 dead，則僅延續升高與落地演出，不對已 dead 目標補發傷害或觸發效果。下降 0.32 秒從實際峰值開始。

高度僅用於演出，不搬動角色或敵人的地面座標，也不改寫原生跳躍高度。鏡頭隨超出的升高量向上追蹤，讓角色頭部保持在 HUD 下方；落地、清理或失去有效角色／世界時還原地面鏡頭。敵人傷害數字與命中特效跟隨蓮華視覺高度。逐踢升高、遞減間隔及高段數縮短等待是本作改編，原傷害、空中無敵及落地範圍規則不變。

八門生命上限加成：額外生命上限 B = 角色等級 LV × 技能階級 N，獨立計算並替換舊的八門加成，不累乘、不因每次更新或清理而重複增加。B 增加時目前生命只補正新增差額，不再乘回血倍率；其他固定生命與百分比成長仍各計一次。例如既有生命上限 260、LV30、N5 時變為 410；再獲得 1% 成長增加 4.1，變成 414.1；升至 LV31 後八門差額增加 5，變成 419.1。死亡仍保留已學八門帶來的生命容量供復活使用；新角色／新局使用自己的基礎生命重新建立加成。此生命上限機制屬本作改編。

裏蓮華全程上限：A 為起手至進入預備階段的實際接近耗時；在進入預備時固定 B = min（1.65，3.3－A－1.6），並令 D = B／[1＋0.025 ×（C－5）]。整招含接近、預備、挑空、連擊、下降、重摔與收勢滿足 A＋1.6＋D ≤ 3.3 秒。將原本正規化到 1.65 秒的逐踢等比時點一次乘 B／1.65；階段更新精確切到邊界，不靠提前中止、不刪除命中。即使 C=5 從最遠可達距離接近較慢，也會壓縮連擊時間；C=33 依然更密更快，連擊數、逐擊傷害、每踢升高 8、限定空中無敵與落地範圍皆不變。

## 裏蓮華終結擊倒與累積傷害

僅本機裏蓮華綁定的主目標：原生傷害流程造成致命傷時，先保留 1 HP 並標記待擊倒，暫不死亡、不發經驗或掉落；待擊倒目標的 AI 凍結並保持錨定。後續每次計畫踢擊仍走正常傷害、暴擊、最大生命額外傷害與吸血流程，顯示真實傷害數字，不用假數字覆蓋、不重複記帳。最後重摔完成主目標與落地範圍傷害後，才結算一次實際死亡與獎勵；未達致命傷的敵人照常存活。

連段 HUD 顯示本次實際命中數及已顯示整數傷害的累積總和；自然結束後短暫保留約 1 秒，暫停凍結，清場或換世界立即隱藏。同世界取消或清理會釋放一次待擊倒；舊世界或新角色不把待擊倒獎勵帶到新世界。表蓮華不使用此保留機制，遠端角色也不適用；外部直接設定 dead 的目標仍不產生後續假命中。連段全程 3.3 秒上限、逐踢升高與加速、數量與傷害公式、限定空中無敵及落地範圍不變。延後擊倒及累積顯示皆為本作玩法改編。
