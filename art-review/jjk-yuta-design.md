# 乙骨憂太：仙台結界可玩版本

版本界線是動畫第三季第59話。以刀術、獨立里香、模仿咒言及限時完全顯現組成近戰協同角色，不新增未公開的領域效果。

- [動畫官方第三季影片目錄](https://jujutsukaisen.jp/movie/index_3rd.php)與[仙台結界PV](https://www.youtube.com/watch?v=DKNM-3LpfZE)：版本與官方影像參考入口。

- 已實際檢視 [官方圖像研究聯絡表](jjk-research-v2/contact-sheet.jpg)，來源逐檔列於 [sources.json](jjk-research-v2/sources.json)。第59話圖01是抬手到面前、戒指位置集中青光；圖05為里香單眼與層疊象牙色外殼；角色全身設定是白色高領寬袖、深色直褲及白鞋。據此移除泛用腳底光環，改以戒指局部光點、完整里香的存在及協同打擊辨識角色。
- 刀術、里香協同、模仿咒言及完全顯現是角色能力取材；以下學習等級、距離、冷卻、傷害、控場時間與6秒爆發，全部為本遊戲改編，不宣稱原作數值。官方網頁的文字摘要並未完整列出每項術式，招式表須以第59話演出為版本參照。
- 此處的里香採仙台篇「リカ」之版本，不將前傳祈本里香的靈魂當成復活。Lv.6 先學咒言、Lv.9 再學完全顯現是遊戲學習簡化，不宣稱是原作使用條件或時間順序。

四招學會後自動施放，不占手動切換欄。每招五階，登記層提供傷害升階值；刀術與範圍成長由 move.range／radius 優先決定。數量卡不複製里香，不影響咒言與完全顯現，避免多個重疊召喚與無限控制。

## 實作限制與驗收

- 每次斬擊使用真正扇形判定；里香與咒言使用圓形判定，包含邊界碰撞半徑並逐目標檢查遮蔽物。
- 刀術與里香在沒有可達敵人時改鎖定最近可達的可破壞物，因此清怪後仍能打開寶箱、破壞岩石。咒言與完全顯現不因只有場景物件而啟動。
- 里香是獨立模擬演員，目的地在發動時固定，分段移動檢查牆與障礙，不直接在遠端敵人腳下生成傷害。
- 爆發傷害於每次施放快照，不每幀修改玩家 atk。里香追加攻擊只在打擊時仍完全顯現期間發生。
- 咒言以獨立、角色持有的控制租約限制敵人更新後的水平位移，不覆寫 slow、slowT 或 jumpLift；解除、死亡、換場、重開不改掉外部控制狀態。
- 每個狀態記錄 owner、World 物件與 Game.st 局次；暫停凍結時鐘，死亡、離開、清場或新局移除動作、里香、爆發與控制。
- API：G.JujutsuYuta.inspect(owner)、stateFor、pose、formFor、renderStates、cast、update、clear。測試應至少驗證3個範圍內敵人和1個範圍外敵人的HP，以及爆發結束、障礙阻擋與控制解除。
- 檔案中的 drawRika 呼叫由共用新素材模組提供；缺少素材時不回退到別的角色圖。

## 第二輪：先保護行為，再改善表現

修改前已記錄問題：刀術只有單一姿勢與弧線，準備／接觸／收刀難以分辨；里香只用粗略 travel／strike／return 動作；六秒完全顯現除了一圈泛用地面環，沒有持續存在的里香；咒言只有字與圓，嘴部準備及放出節奏不清楚。

修改前正常入口回歸：三角色情境的桌機與手機完整測試通過、無瀏覽器錯誤或404，紀錄於 `.omx/state/jujutsu-v2/baseline/report.json`。乙骨的原生20秒及全技能自動施放 BEFORE 畫面已保存於 `.omx/state/jujutsu-v2/before/` 後才改程式。

本輪保留全部技能 ID、基傷、冷卻、範圍、形狀、數值快照與真正命中時間。以下是遊戲的可讀動作編排，並非宣稱動畫逐格還原：

| 招式 | 動作節奏 | 真正命中 |
| --- | --- | --- |
| 刀術 | windup 0–.14；slash .14–.24；recovery .24–.48 | .14秒，原扇形判定 |
| 咒言 | windup 0–.24；release .24–.34；recovery .34–.48 | .24秒，原圓形判定 |
| 完全顯現 | 抬手0–.3；戒指亮起.3–.5；收勢.5–.65 | 沒有新增傷害 |
| 里香 | 到位後 windup 0–.22；smash .22–.30；recoil；顯現中第二輪再抬手、接觸及收勢 | .22秒；顯現中可追加.48秒；接觸影格不提前 |

- `action.visualPhase/phaseProgress/frameName` 提供專用刀術、嘴部及戒指姿勢選格；`rika.visualPhase/phaseProgress/contactProgress/frameName/impactPulse` 提供打擊對齊。
- `state.companion` 為獨立的純呈現物件，完全顯現期間且沒有出擊中的里香時，在主人側後方保持可見。沒有碰撞、索敵與傷害，不重複疊兩隻里香。到期、失去技能、死亡、換場、新局一起清理。
- 咒言嘴邊用小型印記，命中時保留真實範圍的淡輪廓，兩道較小的聲紋不超出該範圍。里香撞擊用五道固定裂紋，刀術用窄亮掃痕；沒有每幀建立 canvas、隨機全螢幕粒子或加大數字冒充改善。
- 確切戒指／嘴部位置在缺少逐格錨點時，依身體高度與朝向估算。這是呈現限制，不能當成官方手部座標。

第二輪初次整合畫面修正：`initial-v2/yuta-level9-3s.png` 顯示空中層里香完全遮住乙骨，視覺審查82分需修正。里香因此移入原生角色深度排序：`G.JujutsuYuta.drawables(camera)` 每個狀態僅保留兩個可重用的 drawable 包裝，出擊與常駐最多顯示其一；排序高度為 `min(里香實際y, 乙骨y-.01)`，實際繪製／命中座標不變。常駐位置改為主人左／右40、後方18，身高112，讓乙骨最後繪出而保持可辨識。空中技能層只留特效，不再重複畫里香。清場後舊 drawable 也會拒絕繼續繪出。
