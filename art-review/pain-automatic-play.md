# 沛恩六道：移動即可的自動協戰

日期：2026-10-23。依使用者最新確認，取代初版「五招選中式主動」操作。當前遊戲規則以本文件與實作為準。

五道耐久、站位、出生保護與低血恢復，已進一步更新為 [支援生存規則](pain-survival-upgrade.md)。

地獄道也能依 [玩家復活規則](pain-player-revival.md) 救回倒下的天道。

玩家控制天道移動；已學會的六道技能自動判斷目標、施放並進入各自冷卻，不需要裝進主動槽、按攻擊或切招。底部保留已學技能欄，顯示圖示、等級、冷卻與施放狀態；點擊查看招名，不切換技能、不影響自動施放。狀態列保留六道頭像與血量，天道標示「你」並有金框。

| 演員 | 自動工作 |
| --- | --- |
| 天道 | 黑棒普攻；80 內有敵人時優先神羅天征。其他時候，地爆天星只對可見三名以上聚集敵人或特殊強敵施放，否則使用引斥。天道本人一次施展一個力量。 |
| 修羅道 | 找到有效目標且冷卻完成時發射飛彈。 |
| 畜生道 | 找到有效目標且冷卻完成時召出犀牛。 |
| 人間道 | 找到可達目標時接近並抓取，實際抓到才開始技能冷卻。 |
| 餓鬼道 | 吸收實際碰到雙掌的合格能量彈。 |
| 地獄道 | 同伴倒下後才開始修復等待，然後修復一位。 |

修羅、畜生、人間與天道採獨立施術排程，可以同時行動；同一道仍只有一具身體、一次只做一項施術。支援道倒下只暫停該道能力，不阻止其他道出招；復歸後繼續自動作戰。

一般成長仍沿用 Lv.1 黑棒、Lv.3 引斥、Lv.6 飛彈／吸收、Lv.9 通靈、Lv.12 抓取／修復、Lv.15 地爆的學習卡。尚未學會的能力不會自動出現。內測預設「直接試全部招式」，開局已學全八招；其他玩法收在選單的折疊區。

原有存檔／執行個體若仍含 Pain 主動群組，安排技能或檢查學習池時會將 Pain 技能移出主動槽並移除其按鍵綁定，保留技能等級、實例與冷卻。其他角色不套用這個規則。

傷害、射程、數量卡、飛行物上限、16 秒復歸、修復等待、牆體阻擋、特殊敵人抗性與死亡／換場清除仍沿用既有規格。五道耐久與安全復歸另依支援生存更新；未學習、沒有目標或施術道倒下時不空耗冷卻，暫停凍結自動排程。地爆後家族引斥的共用恢復仍保留。

驗證入口為 `python tools/test_pain_auto.py`，證據輸出 `.omx/state/pain-auto/`；原生桌機／手機操作、並行施術、實際群傷、冷卻、死亡與復歸、場景清理、分身唯一性、升級學習及畫面均依自動模式驗收。初版選中式測試只代表歷史機制，不能用於宣稱目前自動協戰已通過。
