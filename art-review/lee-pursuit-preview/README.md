# 小李：疾速追身

本機預覽：<http://127.0.0.1:8004/art-review/lee-pursuit-preview/>。

## 補強目標

兩種蓮華目前均為基礎10秒冷卻。新增早期可學的常駐體術輸出，填補主招冷卻期間的攻擊空檔，並提供有路徑檢查的短距離切入。「疾速追身」是本作改編名稱；[官方小李專欄](https://naruto-official.com/en/news/01_1652)支持其卸重後的高速體術，數值與自動連打機制為本作設計。

- 角色Lv.2解鎖、不占主動槽。數量卡使連打數乘1.25、累乘取整，最多12擊。
- 冷卻縮減有效，最低0.5秒；末擊擊退55、其他擊8，攻擊弧2.8弧度。
- 最近可達目標優先。移動輸入期間不強制追身；停住時可自動衝至近身範圍，逐段檢查牆與障礙，衝刺期間短暫護身。
- 蓮華與旋風優先，中斷常駐連段。目標死亡後向近敵接續剩餘拳數，不重設整組冷卻。
- 重用現有真正跑步／拳擊圖格，包含八門版本；沒有新增變身或虛構分身。固定鏡頭並保持既有靜止架勢。

## 原生傷害比較

同樣的35單位距離、固定正常屬性首領目標，分別使用新一局玩家，主動蓮華維持冷卻，先相同暖機一秒，再測量20秒。保留原生玩家、冷卻、命中、敵人HP與傷害處理；首領不受擊退，無位置變化。

既有冷卻空檔普攻造成2444HP，學會Lv.1疾速追身後4478HP，約增加83%；同條件Lv.5為14312HP，約5.86倍。這是刻意隔離主動爆發後的「冷卻空檔持續輸出」比較，不代表所有敵人、裝備或完整實戰均固定提升同一比例。
