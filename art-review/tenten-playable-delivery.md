# 天天可玩版本驗收紀錄

日期：2026-10-23。正常入口：`http://127.0.0.1:8004/.omx/digimon.html?lang=zh-TW`，選角選「天天」，角色 ID 30009。原有角色 ID 不變。

## 本次成品

- 忍具連投：常駐自動基本攻擊，不占主動槽。
- Lv.3 風魔迴刃：大型手裏劍實際飛出、折返，每個敵人每程最多一次命中。
- Lv.6 忍具精通：常駐穿透與忍具速度被動，不占槽，分身完整繼承。
- Lv.9 起爆卷・散華：附札苦無落地，0.65 秒後一次爆炸；接觸不額外扣血。
- Lv.12 雙昇龍：雙卷軸四批、110° 前方實體忍具，可走位，演出不增加等待或無敵。
- 五階技能、首次到等級的單次學習保證、獨立 ICON、HUD 實際忍具數／回收／貫穿數。
- 32 幀共通動作、16 幀技能動作；選角、本體與分身實際使用新圖。常用方向為正面、背面、右側，左向鏡射；技能上／下方向以側向動作替代，並非獨立八方向。

完整傷害與成長草案見 `tenten-skill-design.md`；實際正式數值以 `naruto-skills.js` 註冊資料為準。原創素材來源、生成提示與 SHA 見 `tenten-production-provenance.json`，官方年代與命名界線見 `tenten-research.md`。

## 已建立的驗收

`tools/test_tenten.py` 驗證正常選角／開局、桌機四方向鍵盤與手機觸控、真實敵人血量、四招物理飛行、五階與數量 0／4／20、爆符三內一外、牆壁、精通、生命剝奪對 Boss 的既有 10% 效果、吸血只計一次，以及兩分身實際 1/3 傷害、獨立清理、裂縫保留與新局重設。

同一測試也核對真實繪圖來源、HUD、四方向與巨人倍率共 32 組手部出口，以及正常繪製／不繪製／停用新角色繪圖三種情況的戰鬥結果一致。視覺資料與全景截圖位於 `.omx/state/tenten/`。

`tools/test_tenten_art.py` 核對實際 32＋16 幀的透明範圍、腳底／手部錨點、固定比例、非舊角色複製、10 組動作註冊及 PNG 原創來源 SHA。

## 製作邊界

獨立設計頁 `tenten-preview.html` 仍保留作前期方案對照，正式可玩版本使用正常遊戲入口。桌面瀏覽器的手機尺寸／觸控驗收不等於實體手機效能測量；極高數量與多分身的同主機負載另記於 `.omx/state/tenten/runtime-performance.json`。本次未自動提交、推送或部署。

壓測使用 20 張數量卡、本體加兩個分身、135 個敵人與 5 倍速；最高同時存在 5,089 個忍具，每個 actor 實際發射 8,231 枚，沒有截斷數量。只計戰鬥更新與技能繪製的平均耗時約 18.72 ms，P95 約 67.5 ms，不包含地圖、敵人與 HUD 全畫面；此極端情況仍可能卡頓，不能宣稱全裝置穩定 60 FPS。
