# 沛恩六道：協同作戰角色設計稿

日期：2026-10-23。狀態：已依本稿接入原生可玩內測，實際交付與驗證見 [內測紀錄](pain-playable-delivery.md)。本文數值是第一輪調校起點，不能視為已完成正式平衡或實體手機效能驗收。外型與分鏡見 [製作規格](pain-production-design.md)，亦保留 [概念預覽](pain-preview.html)。

## 核心玩法

**玩家操控天道，另外五道以不同職責協同作戰。** 版本採疾風傳襲擊木葉時期，畜生道採女性身體；長門是操縱者背景，不另放一個長門跟著跑。

定位是多單位協同與引斥控場。六個身體必須有不同輪廓、動作和任務，玩家需要保持陣形、保護支援道，利用聚怪接群攻。普通攻擊與已學會的被動自動執行；五種主動招沿用目前選招、自動施放與手機操作，不增加指揮按鍵或查克拉資源。

初始生命建議 120、移速 108；低於小李的近戰續戰與天天的移動能力，以控場和分工補足。這些是新角色提案，不覆寫其他角色。

## 六道分工與身體規則

| 身體 | 常態行為 | 專屬能力與視覺辨識 |
| --- | --- | --- |
| 天道 | 玩家本體，黑棒投射普攻 | 橘色短刺髮、面部黑釘；伸掌牽引、張掌斥力、雙手升起黑核。 |
| 修羅道 | 前側護衛，近身短擊 | 壯碩輪廓；手臂實際展開機械構造發射飛彈，不用手心光球替代。 |
| 畜生道 | 後側跟隨，近身短擊 | 女性橘髮造型；伏手通靈，召喚獸有自己的身體與衝撞路線。 |
| 人間道 | 側翼近戰，優先不同目標 | 長髮清瘦輪廓；貼近抓取，抽魂以短暫淡色輪廓表現，避免大片鬼火。 |
| 餓鬼道 | 後側近身短擊；學會吸收後優先防禦 | 厚重體型；雙掌張開接觸來彈，吸收只在實際碰撞點發生。 |
| 地獄道 | 後方跟隨，近身自衛 | 獨立髮型與面部釘；學會修復後召出閻王處理倒下的支援身體。 |

六道編隊是角色固有特性，開局天道＋五道都在場；五道普通短擊每次基傷 4，週期 1.8 秒、接觸距離 34，不帶額外暈眩。特殊技能須個別學會，六個身體不各自複製一整套天道技能。

五道各有生命，建議上限為玩家最大生命的 30%；最大生命變更只同步容量差額，不能每幀重補。遵守原生牆體碰撞，不能擋住玩家走位，也不提供無限實體擋彈。敵方攻擊沿用可傷害友方演員的既有規則，不能把本來只打玩家的傷害額外複製五次。

支援道倒下後停用其攻擊與專屬效果，16 秒後於主人附近合法位置復歸，取得完整身體耐久；這是本作維持角色可玩性的復歸規則。天道死亡直接結束，不由其他道復活。尚在場的其他道照常行動，不全隊連帶停擺。

五道分散站位，距主人以 80～180 為正常區域，追擊上限 300；找不到可達目標時回隊。長距離失散超過 640 才可脫戰重定位到主人附近合法地面，禁止藉重定位命中、回血或重設冷卻。索敵分散，僅剩單一首領時允許集中。

## 技能進程與第一階調校起點

學習等級代表首次保證展示的學習機會，不自動贈送；只有固有編隊和起始普攻開局具備。被動學會即生效、不占主動槽；主動共五招，只有目前選中的主動自動施放。

| 學習等級 | 技能／類型 | 具體效果與限制 |
| --- | --- | --- |
| Lv.1 | 黑棒連射・常駐普攻 | 天道每 1.2 秒投出兩根黑棒，每根基傷 10、射程 280、速度 440；碰到第一個敵人或牆消失。黑棒是投射物，不是必中鎖血。 |
| Lv.3 | 萬象天引・神羅天征・主動 | 80 內有可達敵人時立即斥開；否則優先索取 240 內可達精英，再選最近敵人。0.35 秒內將普通目標朝天道拉最多 110，停在距本體至少 90 處。隨後以天道目前位置為中心施放半徑 150 的斥力，基傷 70、普通敵人擊退最多 80。CD 5 秒，拉動無傷害，無接觸無敵；特殊敵人僅受普通拉推的 25%，不保證拉進圈。 |
| Lv.6 | 修羅道・飛彈齊射・主動 | 修羅道向不同敵人發出 3 枚追蹤飛彈，每枚爆炸基傷 22、半徑 48、射程 320，CD 4 秒；觸牆於接觸點爆炸，隔牆敵人不吃爆炸。修羅道倒下不能發射。 |
| Lv.6 | 餓鬼道・封術吸印・被動 | 餓鬼道在天道 110 內優先守衛；對實際接觸雙掌半徑 36 的可吸收敵方忍術彈執行攔截。每次吸一顆，基礎恢復 2.5 秒；無回血、反傷或無敵。物理忍具、近戰、地面技、雷射及未標記的攻擊不吸收。 |
| Lv.9 | 畜生道・通靈衝陣・主動 | 召出一隻犀牛沿起手方向衝 300、通道寬 90，每敵人一次基傷 90，CD 6 秒；碰牆停止，身體與命中通道同步。最多一隻，畜生道倒下不能召出。 |
| Lv.12 | 人間道・魂魄牽引・主動 | 人間道索敵距離 180，正常走近至 36 內抓取，0.6 秒後基傷 140，CD 5 秒。普通敵人抓取期減速 70%，特殊敵人僅減速 20%。不瞬移接近、不即死、不按最大生命扣血；失去接觸或隔牆取消傷害。 |
| Lv.12 | 地獄道・閻王修復・被動 | 地獄道存活且有其他支援道倒下時，每基礎 10 秒修復一位，優先修羅→畜生→人間→餓鬼；演出 0.8 秒後復歸。地獄道不能修復自己或天道。無倒下者時不儲存多次額度；與 16 秒自動復歸競爭，先完成者生效一次。 |
| Lv.15 | 天道・地爆天星・主動 | 對 320 內可見敵群位置生成固定黑核；半徑 160、牽引 1.5 秒，每 .5 秒基傷 15 共三次，崩落基傷 120 一次，CD 12 秒。普通敵人牽引速度最高 100；特殊敵人只受 25% 牽引，不硬定身、不改原生跳躍高度。最多一顆黑核。 |

上述五個主動分別提供近身解圍、分散爆炸、直線掃群、單體爆發與聚怪大範圍技。萬象天引不與神羅拆成兩個槽，避免兩個操作和兩份冷卻破壞自動連動。

## 五階、卡片與連動

- 傷害倍率統一暫定為 1／1.2／1.4／1.7／2；不另外隱藏疊乘整輪傷害。範圍、CD 不隨階數偷偷變動。
- 黑棒基礎根數 2／2／3／3／4，飛彈 3／3／4／4／5；各自沿用 `G.Quantity` 的施放快照，數量卡按 `floor(基數 × 1.25^張數)` 計算一次，最多 20 張。初步實體上限黑棒 40、飛彈 30，多出的數量不補成隱藏傷害。
- 唯一六道、犀牛、黑核、吸收掌與閻王不吃數量卡；不能因數量增加生成多個相同修羅道或多條復活鏈。這是明示的唯一實體限制，HUD 與卡片適用說明須一致。
- 吸收五階恢復週期 2.5／2.3／2.1／1.9／1.7 秒；閻王修復五階基礎週期 10／9.5／9／8.5／8 秒。冷卻卡有效，不同時又按傷害倍率縮短。
- 所有傷害沿用既有攻擊與傷害修正一次；支援道不再另算一次主人的攻擊倍率。五道短擊不因學習某招變成五份該招。
- 同時只有一個主動選中，不承諾黑核持續期間再切飛彈或犀牛仍保留黑核。有效連動是「已發射飛彈→切地爆，利用在途飛彈命中聚怪區」，或聚怪時由常駐黑棒與支援短擊補攻；犀牛作另一種清群選擇。沒有額外隱藏增傷，首領保留位移抗性。
- 地爆天星施放後使家族全部天道引斥主動進入至少 5 秒的共用恢復期，與該招已有冷卻取較長者，不相加；地爆自己的 12 秒 CD 照常。其他道可繼續普通攻擊，玩家可以走位；不新增施術僵直或無敵，分身不能繞過共用恢復期。

## 動畫、圖集與 HUD

角色延續現用我愛羅／小李的頭身比、深色輪廓、有限色盤和像素密度。六道共用曉袍色盤，但必須個別繪製頭髮、體型、黑釘與施術姿勢，不能把天道縮放或換色五次。

| 素材 | 必需動作 |
| --- | --- |
| 天道共通與施術 | 正／背／右側待機與移動、受傷、倒下、黑棒出手、天引收掌、天征外推、地爆結印／托核／收勢。左側可鏡射並明示。 |
| 五道獨立演員 | 各自待機、移動、短擊、受傷、倒下、復歸；另外製作機械開臂、伏地通靈、伸手抓取、雙掌吸收、閻王施術。 |
| 獨立技能物件 | 黑棒、機械飛彈與爆煙、犀牛起步／奔跑／消散、閻王與修復口部、黑核與聚石／崩落。 |
| 圖示 | 黑棒、外推掌＋內收箭頭、機械飛彈、犀牛、抓握魂影、吸收雙掌、閻王、黑核聚石，各有不同剪影。 |

圖集數量與影格數在實際動作草稿驗收後決定，不先承諾固定張數。人物與巨大特效分離，飛彈必須從展開機械手臂出發，犀牛由通靈煙顯現；黑核在空中但牽引以地面投影計算，石塊不遮掉整片敵人。

HUD 用六枚小肖像顯示身體存活／倒下與復歸剩餘時間，主體血量維持原介面。吸收與修復各占一格被動；固有編隊在角色資訊說明，不偽裝成一張額外可學被動。選中主動顯示其真實 CD 與所需身體是否倒下，禁止倒下後仍顯示「可施放」。

## 接線與生命週期契約

- 現有 roster 到天天 `30009`；提案預留下一個 `30010`、slug `pain`，實作時重新查重，不重排舊角色 ID。起始技預留 `naruto-pain`；各技能使用 `naruto-pain-*` 前綴，限定本角色技能池。
- 編隊需要獨立的「支援道」演員身分，沿用共用傷害、碰撞、目標查詢與清理介面；不能直接借鳴人分身生成器製造五個天道。
- 通用自身分身仍繼承本體已學能力與被動；每名分身各有自己的冷卻及投射物，既有 1/3 傷害只套一次。六道編隊為主人家族共用的唯一集合，分身不遞迴再生五道；所需道的技能由同一道排隊執行，保留施法者與傷害歸屬，不能同一幀複製多個身體。
- 支援道本人不再觸發自身分身、不抽升級卡、不撿經驗、不寫入存檔。吸收與修復以家族一份管理，分身繼承其防護資格而非生成額外攔截／復活額度。
- 選中主動的起手與持續狀態歸屬施法者；切走取消尚未發出的批次、人間道抓取、通靈衝陣與黑核及其控制。已發射黑棒／飛彈可完成一次正常碰撞；不能切招補發延遲傷害。
- 專屬施術道中途倒下取消該道尚未完成的施術；已飛出的黑棒／飛彈不因發射者倒下消失。天道死亡、主人失效、換角色、換世界、新局與清場，立即清除家族全部演員、投射物、修復預約、黑核與自有控制。
- 暫停／選卡凍結全部模擬時間。相同倒下事件以唯一序號處理，閻王與自動復歸不得各復活一次；修復中地獄道倒下取消修復演出，保留目標原本自動復歸進度。
- 引力和推力分開累積自有位移，不改外部 `slow` 或原生 `jumpLift`；移動採原生碰撞、小步上限及距離容差，不能穿牆或因浮點誤差卡死。
- 正式接入需同步角色／技能池、訓練選卡、正常動畫 runtime、素材登記、產生器與打包清單；來源與 provenance 分別記錄，未生成的圖不能先登記成可用素材。

## 驗收與仍待調校事項

1. 正常入口能選新角色、初始只有起始能力；各學習等級首次保證展示一次，拒選後不每級強塞；滿主動槽仍可學被動。
2. 同場確實只有天道與五個不同支援道；數量卡、通用分身與重開不複製唯一身體。多個分身請求同一道時有公平排隊與過期取消，不能無限累積。
3. 神羅、飛彈、犀牛與地爆各以至少三個範圍內＋一個範圍外敵人記錄前後 HP；包含障礙、邊界、死亡目標和同一首領，確認各段單次命中。
4. 人間道接近／抓取／傷害順序正確；越距、隔牆、施術道倒下、切招取消；首領無硬拉、無百分比傷害或即死。
5. 可吸收彈必須真正碰到雙掌才消失；不吸物理忍具、雷射或地面技，不事後救回已命中的傷害。找不到標記時預設不吸收，不能猜攻擊屬性。
6. 支援道耐久、16 秒復歸與閻王修復競態、地獄道自身倒下、升級容量差額與暫停均有機制案例；天道死亡絕不被救活。
7. 桌機／手機尺寸比較同一影格，檢查六道剪影、玩家辨識、腳底、機械發射口與地爆遮擋；視覺迭代保存 visual-verdict，實作前不標成通過。
8. 效能壓測使用最大既有通用分身數、20 張數量卡與密集敵群；共用空間查詢、10 Hz 決策與逐幀局部碰撞。記錄 actor／飛彈／特效峰值、幀耗時與裝置；手機視窗不冒充實體手機結果。
9. 與現有角色相同波次比較清怪、生存及首領擊殺時間；特別量測六道普通攻擊總傷、地爆聚怪接飛彈的重疊傷害、攔截覆蓋率與修復帶來的續戰。未完成這些測量前不宣稱平衡完成。
