## 必須成立的動作鏈

1. **扇風／大鐮鼬**：持扇準備 → 人物可繼續移動 → 從當次真釋放位置出風 → 風前緣實際碰到敵人 → 受擊／推離 → 收勢。釋放後波前與已結算痕跡固定於其世界位置，不能被後續移動拖走。
2. **颱風**：扇子起手 → 真釋放位置形成風眼 → 風流掃過並接觸 → 合法後續切擊有對應訊號 → 最後接觸者完成自身的完整窗口 → 風眼收束。不能把整個後續傷害期間改畫成新的全屏攻擊，也不能用永續圈線暗示仍在抓人。
3. **鐮多利**：獨立遊走 → 接敵追身 → 準備 → 每一刀從實體附近接觸 → 收勢 → 返回／遊走。主人切換主動技能不應讓協戰者重新出生或突然消失。
4. **返風**：敵方遠程攻擊進入 → 風壁真接觸 → 實際反向攻擊 → 接觸短光收束；近戰及環境威脅仍需可辨。

主動技能未選中也恢復冷卻，是本輪的遊戲節奏改良，不是原作設定。只選中當下招式施放、切換不重設剩餘冷卻，可維持玩家準備解圍與轉入颱風的意圖。
