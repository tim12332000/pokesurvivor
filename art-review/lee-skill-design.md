# 少年小李：四招體術設計與驗收

設計日期：2026-10-20。角色為中忍考試時期小李，既有角色 ID `30006`。此文件是技能設計規格；測試通過與實作完成須以交付報告為準，不能由本文件推定。

## 參考依據與改編界線

- **原作依據**：少年小李以體術補足忍術、幻術的不足；卸下負重後提高速度；表蓮華與開至第四、第五門的裏蓮華有不同強度及身體負擔。[官方生日專欄](https://naruto-official.com/en/news/01_1652)。不給少年小李朝孔雀、晝虎或夜凱。
- **原作代價**：表蓮華後有破綻，裏蓮華是更危險的禁術；本作保留收勢，但依被動玩法取消開門疲勞，不還原長時間完全不能操作。[官方第 49 集簡介](https://naruto-official.com/en/anime/naruto1/list/01_273)。
- **其他遊戲的實際參考**：《NARUTO TO BORUTO: SHINOBI STRIKER》開發者信第 12 期介紹小李主題武器 Youth at Full Power：強攻可開傷門，提高攻擊與速度並使用裏蓮華。採用「強化窗口接體術終結」的關係；不照搬其操作、數值或素材。[官方開發者信](https://naruto-official.com/en/news/01_2541)。
- **另一款遊戲的設計對照**：Naruto Arena Classic 自家平衡公告讓小李的近戰標記與後續近戰產生連動，並把旋風設計成連續壓力。採納技能應各有分工、連動可讀的原則；回合制查克拉成本、永久標記與治療不移植到本作。[遊戲作者平衡公告 1.2.4](https://www.naruto-arena.site/balance-changes/new-characters-major-balance-124)。

### 表蓮華與裏蓮華不能只是換名字

裏蓮華實際冷卻固定 5 秒，從起手時計算；技能升級與冷卻縮減不縮短此間隔。

基準表蓮華：貼近 → 0.24 秒預備 → 0.36 秒挑空（高度 40）→ 0.42 秒空中抱持／旋摔 → 0.22 秒平滑下降 → 0.20 秒重摔 → 0.22 秒收勢，接觸後設計共 1.66 秒，固定時間步進實測約 1.68 秒。

基準裏蓮華：貼近 → 0.28 秒預備 → 0.48 秒挑空（基礎挑空高度 60，之後每次計畫空中踢擊再升高 8）→ D = B／[1＋0.025 ×（C－5）]，B = min（1.65，3.3－A－1.6） 秒空中連擊（次數取決於起手快照的技能與數量）→ 0.32 秒平滑下降 → 0.24 秒重摔 → 0.28 秒收勢，接觸後設計共 1.6＋D 秒；從起手含接近總長 A＋1.6＋D ≤ 3.3 秒，各段間隔按 0.90 等比遞減並正規化至 D，段數越多總連擊時間越短；5 秒冷卻從成功起手開始計。

**建議的有限改善**：裏蓮華在可達範圍內優先選菁英／首領，再選目前或最近目標；表蓮華維持目前／最近目標。這項是待實作確認的建議，沒有測試證據時不能聲稱已實現。即使未加優先級，兩招的時間承諾、傷害分配與命中次數也必須明顯不同。

## 命中、操作與中止規則

1. 只有選中的攻擊招自動索敵；無存活且可達目標不開始貼近、不空耗成功施放冷卻。八門是學會即常駐的被動，不參與自動施放。
2. 貼近使用實際角色位置與碰撞，最大速度基準 480 單位／秒、最多 0.6 秒。不能穿牆、傳送到敵人座標，亦不能因目標逃走無限追擊。
3. 連段只可同時一條；按切招不生成第二條連段。允許既有連段自然收完再由新選中技能起手，並立即更新選中 UI。
4. 視覺浮空只用於一般敵人；首領、菁英等受控角色維持接地與正常碰撞。裏蓮華挑空、空中連擊及下降階段具有無敵，傷害仍沿用正常計算，不改成百分比斬殺。
5. 傷害只在真實接觸或清楚的落地震擊發生。每次命中重新確認距離、目標存活與遮擋；畫面可浮起，邏輯地面位置不可偷偷搬動。
6. 兩招挑空前主目標已死亡都中止。表蓮華挑空後目標死亡仍完成下降與落地，不對死者補發連擊；裏蓮華綁定目標受真實致命傷時保留 1 HP、延後擊倒，後續連擊與傷害正常結算，到最後重摔再死亡一次，不自動換目標。離開接觸範圍、路徑遭牆阻擋、玩家死亡、換角色、清場或重新開局仍中止，已造成傷害不退回。
7. 裏蓮華只在 lift／combo／descent 無敵，阻擋一般 hurt 傷害與直接扣血的天氣、生命寶珠傷害；approach／windup／slam／recovery 及表蓮華不受此保護。取消、死亡或結束不能留下無敵。其他傷害與硬直規則沿用既有行為。
8. 暫停凍結所有招式與演出計時；掉幀須按模擬時間補齊應有命中，不可漏掉依技能等級增加的空中連段或每個畫面重複落摔。

## 開門連動與卡片語意

- 開門使用現有加成 getter／效果狀態，不能直接永久改寫攻擊和移速；其他裝備、升級與增益仍須保留。切招後強化持續，維持常駐被動語意。
- 攻擊起手時快照當下攻擊倍率。表／裏蓮華整段保持快照，不因被動升階突然變傷害；之後起手採新階倍率。不得雙乘開門倍率。
- **數量卡**：表蓮華仍固定兩次命中；裏蓮華空中次數 C = 5＋2 ×（技能等級－1）＋Q，Q 是本局數量加成（施放時透過 G.Quantity 取得）。技能及 Q 均於起手快照，連段途中升階或拿卡不改當次命中。既有數量卡上限為 20；第五階、Q=20 時空中 33 次，含挑空與重摔共 35 次，不產生多個小李或疊加開門。
- **最大生命傷害卡**的實際契約是「每次命中額外造成目標最大生命的 1%」，見 `.omx/percent-health-damage.js`。保留契約：表蓮華兩次命中可觸發兩次，裏蓮華依技能與數量快照得到的 C＋2 次實際命中各觸發一次；次要目標只在最後震擊各觸發一次。不能偷偷除以連段數、不能讓殘影額外觸發。這使裏蓮華有明確的命中構築價值，也有對首領的平衡風險；先維持固定冷卻與單目標限制，再用實玩數據調數值。
- **吸血**沿用 `onDealt`：基傷由技能記一次，生命剝奪額外傷害由既有 wrapper 記一次；不得再補記整筆造成雙重吸血。沒有命中、被取消的段數、殘影和灰塵不觸發吸血。多目標真實傷害照現有規則各別計入；八門自帶的每秒生命回復是獨立的被動回復來源，不是吸血，沒有命中時仍可正常生效。
- **範圍與傷害卡**沿用既有快照；主目標不重複吃次要震擊。若擴大半徑，特效外緣應跟隨，不能畫得小、實際打到畫面外。

## 必須收集的測試證據

- 正常遊戲入口可選小李，起手只有旋風；Lv.3／9 學主動技，Lv.6 起可學五階被動，滿主動槽仍可學被動。
- 同一次旋風：前方至少三名敵人受傷，背後與半徑外敵人不受傷；穿牆目標不受傷。
- 無暴擊／屬性／天氣加成時：表蓮華主目標總基傷 110；裏蓮華核對當階基傷 × [0.4＋0.12 × Σ(n=1..C) 1.10^n]。一階 Q=0、基傷 210 時約 253.233372；第五階 Q=0、基傷 315 時約 1145.654371；第五階 Q=20 時空中 33 次、主目標共 35 次，約 9367.219208，尚未乘攻擊／屬性等倍率。次要目標僅一次 35% 當階基傷（不乘段數指數），主目標不重複吃範圍，外圍不受傷；允許引擎既有取整容差。
- 表蓮華和裏蓮華錄影／分段截圖能看到真實接近及不同連擊動作；首領不浮空。
- 八門五階倍率、隨角色升級立即更新的回血量與移速、滿主動槽學習、切招後持續、長時間無衰退與疲勞皆驗證；升階替換倍率，不疊乘，重開局不殘留。
- 生命剝奪 1% 對高血測試敵人：表蓮華兩次、裏蓮華按本次技能與數量快照觸發 C＋2 次；次要震擊一次；吸血與傷害統計不重複。
- 裏蓮華數量加成 Q=0／1／3／20 與技能五階皆須核對 C 與 C+2 命中數；每次空中基傷依序乘 1.10^n，第一下 1.10、第二下 1.21，每次施放重設。暴擊、吸血及最大生命百分比傷害逐次且只結算一次；最大生命百分比額外傷害維持原比例，不乘此指數。掉幀補齊本次快照命中數，空中連段採 D 公式縮短，後一次踢擊間隔嚴格小於前一次。
- 裏蓮華 lift／combo／descent 無敵，其他階段與表蓮華可受傷；天氣與生命寶珠直接扣血同樣被空中無敵阻擋，結束或取消立即恢復正常受傷。
- 兩招挑空前已死亡須取消；表蓮華挑空後死亡只完成演出與落地。裏蓮華真實致命傷須保留 1 HP、完成所有計畫命中後重摔擊倒，死亡、經驗與掉落只能各結算一次；外部強設 dead 不補假命中。逃離、隔牆、玩家死亡、場景切換或重新開局均正確清理；暫停凍結演出。
- 裏蓮華技能五階實際半徑 100／120／140／160／180，圈內多名次要目標各中一次、圈外不受傷、主目標不重複吃震擊；完整外圈精確等於傷害半徑，內圈擴散；各空中階段及 1.6＋D 秒接觸總時長逐段驗證。
- 桌機鍵盤與手機觸控：移動、切招、升級選卡、受傷、倒下，以及每招至少一次實際自動命中；記錄圖集 `drawImage` 來源以證明不是測到舊素材。

## 本次不擴大的範圍

八門已為永久被動，卸負重不另加速度技能；醉拳需要獨立閃避／反擊行為與另一組動作，放到後續版本。此次先完成四招，避免以更多名字掩蓋同一個近戰範圍模板。

## 本次八門調整與素材參考

使用者指定 [Ninja Council 3 素材站](https://spritedatabase.net/game/55) 的 [Rock Lee 圖集](https://spritedatabase.net/files/ds/55/Sprite/RockLee.png)，Ura Renge 段落使用紅臉的獨立動作。現版採兩張原創開門圖集（32 格共通、16 格技能），與普通形態分開裁切定位。前兩階即紅臉、五階共用造型及永久增益皆屬遊戲改編。八門新增每秒最大生命 × 技能階級 × 1% 的自然回復，先與既有自然回復相加，再由同一回血倍率放大一次；治療、吸血、拾取與場景治療亦沿用既有倍率。角色等級、技能階級或最大生命變動立即反映，不另開重複計時器。

裏蓮華每次技能升階增加兩段空中連擊及限定空中階段無敵，皆為本作玩法改編；數量卡每點增加一次空中命中，地面範圍仍只在落地結算一次。

裏蓮華起手快照技能等級與數量加成 Q，中途拿卡或升階不改當次連段。第 n 次空中命中的基傷係數為 0.12 × 1.10^n，第一下乘 1.10、第二下乘 1.21，每次施放從第一下重設；挑空 0.10、重摔 0.30、次要目標落地 0.35 不乘此指數，最大生命百分比額外傷害也維持原比例。總主目標基傷倍率為 0.4＋0.12 × Σ(n=1..C) 1.10^n。既有數量卡最多 20，技能第五階、Q=20 時空中 33 次、總命中 35 次，空中連段依公式縮短至最多約 0.970588 秒，接近耗時較長時會再壓縮。這些數量與傷害遞增皆為本作改編。

八門自帶自然回復：每秒回復量 =（既有自然回復＋目前最大生命 × 技能階級 × 0.01）× [1＋（10 × 技能階級＋角色等級）／100]。自帶基礎回復五階分別為最大生命 1／2／3／4／5%／秒；例如第五階、角色 Lv.30，僅自帶部分即 5% × 1.8 = 最大生命 9%／秒，其他自然回復再另併計。回血倍率只乘一次，回復上限為目前最大生命；最大生命、技能階級、角色等級均動態更新。整合既有 Game 更新流程，暫停不推進；死亡、未學八門或非小李角色不取得此自帶回復，不使用第二個計時器。這是本作被動改編。

驗收須核對五階自帶回復與回血倍率只乘一次，並涵蓋最大生命變動、角色升級、技能升階、滿血上限、暫停、死亡、未學及換角色；空揮或殘影不產生吸血，但八門被動自然回復仍依時間運作。

兩招均以可辨識的上踢、空中抱持／連擊、下降與落地姿勢表現較長連段。表蓮華設計 1.66 秒、裏蓮華從起手含接近全程 A＋1.6＋D ≤ 3.3 秒；表蓮華 1.66 秒仍不含接近；表蓮華固定時間步進約 1.68 秒，裏蓮華依本次快照段數而變。表蓮華全程可受傷，裏蓮華仍僅 lift／combo／descent 無敵。冷卻各為 3／5 秒、起手時計算；冷卻期間補近身普攻，連段中不插普攻。表蓮華挑空後目標死亡仍完整落地；裏蓮華真實致命傷目標保留 1 HP 到最後重摔，連擊不中斷；挑空前死亡、角色死亡、換場、牆與距離檢查仍可取消。提高基傷、延長動作及挑空後保留落地皆為本作改編。

裏蓮華逐踢升高與加速：起始挑空高度 60 世界像素，每次計畫空中踢擊再升高 8，峰值 H = 60＋8 × C；C=5／15／33 時峰值為 100／180／324。各踢擊時間間隔按 0.90 等比遞減，正規化後總空中連段時間 D = B／[1＋0.025 ×（C－5）]，B = min（1.65，3.3－A－1.6） 秒；若接近耗時 A ≤ 0.05 秒，上述 C 的 D 分別為 1.65／1.32／約 0.970588 秒，接觸後總長 1.6＋D 為 3.25／2.92／約 2.570588 秒；較長接近會先壓縮 B，整招從起手到收勢均不超過 3.3 秒。掉幀須補齊跨過的計畫踢擊；裏蓮華真實致命傷目標保留 1 HP，仍按計畫升高並接受全部後續命中；若外部直接設為 dead，則僅延續升高與落地演出，不對已 dead 目標補發傷害或觸發效果。下降 0.32 秒從實際峰值開始。

高度僅用於演出，不搬動角色或敵人的地面座標，也不改寫原生跳躍高度。鏡頭隨超出的升高量向上追蹤，讓角色頭部保持在 HUD 下方；落地、清理或失去有效角色／世界時還原地面鏡頭。敵人傷害數字與命中特效跟隨蓮華視覺高度。逐踢升高、遞減間隔及高段數縮短等待是本作改編，原傷害、空中無敵及落地範圍規則不變。

八門生命上限加成：額外生命上限 B = 角色等級 LV × 技能階級 N，獨立計算並替換舊的八門加成，不累乘、不因每次更新或清理而重複增加。B 增加時目前生命只補正新增差額，不再乘回血倍率；其他固定生命與百分比成長仍各計一次。例如既有生命上限 260、LV30、N5 時變為 410；再獲得 1% 成長增加 4.1，變成 414.1；升至 LV31 後八門差額增加 5，變成 419.1。死亡仍保留已學八門帶來的生命容量供復活使用；新角色／新局使用自己的基礎生命重新建立加成。此生命上限機制屬本作改編。

裏蓮華全程上限：A 為起手至進入預備階段的實際接近耗時；在進入預備時固定 B = min（1.65，3.3－A－1.6），並令 D = B／[1＋0.025 ×（C－5）]。整招含接近、預備、挑空、連擊、下降、重摔與收勢滿足 A＋1.6＋D ≤ 3.3 秒。將原本正規化到 1.65 秒的逐踢等比時點一次乘 B／1.65；階段更新精確切到邊界，不靠提前中止、不刪除命中。即使 C=5 從最遠可達距離接近較慢，也會壓縮連擊時間；C=33 依然更密更快，連擊數、逐擊傷害、每踢升高 8、限定空中無敵與落地範圍皆不變。

## 裏蓮華終結擊倒與累積傷害

僅本機裏蓮華綁定的主目標：原生傷害流程造成致命傷時，先保留 1 HP 並標記待擊倒，暫不死亡、不發經驗或掉落；待擊倒目標的 AI 凍結並保持錨定。後續每次計畫踢擊仍走正常傷害、暴擊、最大生命額外傷害與吸血流程，顯示真實傷害數字，不用假數字覆蓋、不重複記帳。最後重摔完成主目標與落地範圍傷害後，才結算一次實際死亡與獎勵；未達致命傷的敵人照常存活。

連段 HUD 顯示本次實際命中數及已顯示整數傷害的累積總和；自然結束後短暫保留約 1 秒，暫停凍結，清場或換世界立即隱藏。同世界取消或清理會釋放一次待擊倒；舊世界或新角色不把待擊倒獎勵帶到新世界。表蓮華不使用此保留機制，遠端角色也不適用；外部直接設定 dead 的目標仍不產生後續假命中。連段全程 3.3 秒上限、逐踢升高與加速、數量與傷害公式、限定空中無敵及落地範圍不變。延後擊倒及累積顯示皆為本作玩法改編。
