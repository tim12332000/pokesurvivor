# 君麻呂：五個自動技能、四個主動招式

2026-10-28。使用者Lv12選不到早蕨，畫面證明主動四格已滿，舊學招邏輯因此藏掉後續新招。使用者提出部分技能改被動，本次採此方向，沒有加入另一套替換選單，也不要求先取得羈絆。

## 現行分工

| 學會後自動使用，不占主動欄 | 解鎖 |
| --- | --- |
| 柳之舞 | Lv1起始 |
| 十指穿彈 | Lv3，需選卡學會；近身沒有敵人時射擊中遠目標 |
| 唐松之舞 | Lv6，需學會；近敵時自動展骨防護 |
| 鐵線花・蔓 | Lv6，需學會；中距普通怪拉近，協助柳接斬 |
| 地之咒印 | Lv15，需學會；原有周期與變身規則 |

四個需要選擇的主動招式為椿之舞（Lv3）、鐵線花・花（Lv9）、鬼百合（Lv9）、早蕨之舞（Lv12）。剛好符合原有四格主動容量；達等級只是加入候選，仍須花正常學招選擇。

學過蔓、目前選中的組內有花且兩招都就緒時，可自動接蔓→花，不需要把蔓放進羈絆組。未選花不會偷放骨鑽；傷害、命中段落及兩招獨立冷卻保持原值。

所有出手共用同一人物動作與公平排程。自動招式不會互相疊滿人物姿勢；近身柳與唐松、中遠穿彈和拉近的蔓按有效目標決定是否就緒。取消、死亡、場景與退出的清理維持原規則。

## 學招與舊配置處理

舊配置內已學穿彈、唐松、蔓會移出主動格，保留招式物件、技能階級及冷卻，其他主動組與快捷鍵不被重建。首次解鎖卡片優先較高學習等級，因此Lv12的早蕨不會被更早等級的未學招排擠。

HUD沿用原有多技能列，與六道共用同一套排列及縮放，沒有君麻呂專用的額外「自動」面板。四個主動組與五個自動技能都可顯示；點主動圖示切換，點自動圖示只顯示資訊，不會切換技能。顯示格數與主動組容量是兩件事。

程式更新需重新整理載入；已開著、尚未重載的舊戰局不會自動下載新JavaScript。重新整理會依遊戲既有規則重開戰局，不宣稱保留瀏覽器記憶體中的舊局。
