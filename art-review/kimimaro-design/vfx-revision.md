# 技能質感修訂：亂骨林與固定素材預算

2026-10-27。使用者指出技能有廉價感，早蕨之舞應更雜亂無章，且要求兼顧素材大小與效果，不能無限增加成本。本次只更新獨立設計預覽，沒有接入正式遊戲。

## 視覺調整

早蕨移除等距三圈骨柱、放射直線及預設常駐圓框。保留原本三波傷害時點與真圓判定，外觀改為固定種子的非規則群簇；骨柱使用八個新繪變體，粗細、高低、曲折、斜角與分叉不同。根部帶破土碎石，生長時有受限的揚塵／骨屑；前後分層及局部遮擋處理保留人物與敵人可讀性。範圍圓只在開啟「範圍」時顯示。

其他技能共用同一圖集與材質：花改用實體骨質素材沿同一手臂延伸，骨鞭加椎骨突起，斬痕改為收尖短帶，唐松改為連著身體的不等長骨肋，指骨彈與骨劍補硬面與節理。沒有新增角色圖、技能、全屏光效或額外傷害。

## 硬上限

| 項目 | 預算／實際 |
| --- | --- |
| 新增執行圖集 | 一張，12格，共用於骨林、鑽與碎屑 |
| 執行尺寸 | 640×480 |
| PNG傳輸大小 | 205,748 bytes，約201KiB；上限256KiB |
| 解碼RGBA記憶體 | 1,228,800 bytes，約1.17MiB；上限1.75MiB |
| 骨柱 | 固定最多36組，少於前版41根幾何柱 |
| 碎屑／揚塵等次要粒子 | 共用最多20個，不按每柱各生一整組 |
| 佈局 | 種子固定、快取並排序；暫停／重播不閃動重抽 |

原始生成圖 [effects-bones-v1.png](effects-bones-v1.png) 為1,324,298 bytes，只作來源留存；頁面載入 [effects-bones-runtime.png](effects-bones-runtime.png)。執行圖比原始圖小約84.5%，不以提高原圖解析度或增加柱數解決質感問題。

技術處理由 [build-effects.py](build-effects.py) 做等比降採樣、有限色編碼與索引；原始素材不重畫。來源、完整提示詞、參考及輸出見 [provenance-vfx.json](provenance-vfx.json)，執行矩形、錨點與預算見 [effects.json](effects.json)。

## 驗證範圍

瀏覽器驗證新增實際圖集載入、傳輸與解碼大小、36／20上限、固定佈局、變化的半徑／斜角／尺寸、桌機與手機的分段截圖。原本八招雙形態、命中、AOE、首領、取消、控制及骨鑽接觸檢查仍須通過，再重錄短片與更新設計包。

這些是可核對的預覽成本上限，不等於正式遊戲在大量敵人與多角色同時施術時的效能保證。正式接線需沿用此預算，再量測目標裝置；不靠持續加素材、加粒子來取得效果。

最終結果：[修改前](evidence/vfx-before.png)／[修改後](evidence/vfx-after.png)、[更新影片](evidence/kimimaro-motion-reel.webm)、[驗證報告](evidence/verification.json)。三種視窗、八招雙形態與骨鑽接觸等原檢查仍通過；新檢查確認36種半徑、八種形狀、重播一致、粒子峰值20，且原始大圖未被請求。這是材質與佈局改善，不改招式基傷或命中規則。
