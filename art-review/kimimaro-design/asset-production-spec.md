# 君麻呂：視覺與聲音製作規格

2026-10-27。此檔定義本次設計預覽及後續正式製作的界線，與 [最終主規格](final-spec.md) 配套。獨立預覽不是正式遊戲角色登記，也沒有更新原遊戲素材清單。

## 共同比例、造型與配色

少年活人君麻呂為角色基準，普通形態三頭身左右、銀白中長髮、綠眼、額頭兩個紅點、淺灰開襟上衣、紫色粗繩背結、深色短褲與露趾鞋。骨質比衣服偏暖，灰紫陰影令武器與白衣能分開。普通與二階沿用相同頭部尺寸和四肢尺度。

| 用途 | 基準色 | 製作要求 |
| --- | --- | --- |
| 外輪廓 | 深海軍藍 `#202131` | 同顯示尺寸下保持一致粗細，避免人物攻擊時變成另一套密度 |
| 髮色 | 銀白 `#e8e4de` | 暗部偏灰紫，側髮保留狹長輪廓 |
| 上衣 | 淺灰 `#d9d6dc` | 與骨刃暖色區分；咒印紋路長在皮膚，不把整件衣服染黑 |
| 腰繩 | 紫 `#76618d` | 粗繩結固定在背後，跑步與扭腰跟隨身體 |
| 骨質 | 象牙白 `#f0e5ce` | 兩階硬邊陰影，鑽與鞭用形狀而非強光區分 |
| 咒印二皮膚／尾 | 灰褐 `#95887e` | 有肉身體積，背部骨棘白色；尾巴不可畫成純白脊椎鞭 |
| 輕量特效 | 淡象牙／灰紫 | 短尾跡與骨屑，不常駐高亮白圈 |

色票是設計目標，生成關鍵姿勢可能有差異，不能以檔名宣稱每格已精確遵守色碼。預覽與正式圖集需分開標記驗收。

## 本次預覽關鍵姿勢

普通與二階各一張4×4透明圖，每套16姿勢。以原始圖中真實alpha輪廓取得rect與腳底anchor，站姿決定共同比例；不將每個蹲姿各自放大成站姿總高度。曲折尾巴的矩形可能含鄰格透明空隙內的其他姿勢，因此索引另記 `clipRuns`，渲染時只顯示本格的連通alpha輪廓；原始PNG不重畫、不抹除。錨點由雙腳範圍取中點，不只取最低一隻鞋，避免跑步和出招跳位。

## 分層與動作連續性

目前美術統一版使用單張640×480、145,972 bytes的冷白／灰紫骨質圖集，8根主柱＋28組短骨群，次要粒子共用20上限。原始1448×1086圖只留來源，不載入預覽；根部泥土與骨質材質分開。場景重用原遊戲精靈與樹石草共23,692 bytes，地面用快取的2世界像素畫法。準則與來源見 [共同美術](art-direction.md)，前次亂骨林修訂保留為歷史。

背景地面→裂口與範圍邊界→後景骨柱→敵人與玩家（按腳底深度）→前景骨柱／骨鞭→短命中碎骨。前景遮到主角或敵人提示時降低透明度；骨柱上端伸高不代表地面範圍更大。

骨鞭的根部隨握手、鑽頭隨前臂、骨彈由指尖發出，不能從角色中心或地面出生。蔓花接續只用同一人物的雙手過渡，不疊兩個半透明立繪。咒印二尾巴是身體，不拿長骨鞭的繪圖函式直接當尾巴。

預覽使用關鍵姿勢與插值呈現節奏，不把剪輯的姿勢切換叫作逐幀原畫完成。正式製作每個命中節點要有可辨識的接觸姿態；骨林和周身掃鞭的實際覆蓋須與碰撞同步。

## 聲音設計

| 招式 | 節奏／材質 | 層次 |
| --- | --- | --- |
| 柳 | 短骨刃擦切 | 後段加速、末擊稍低沉，避免每刀同一音高 |
| 椿 | 三次短刺破風 | 前兩下輕，第三下有明確重刺 |
| 穿彈 | 清脆細骨連射 | 五個出手拍，高數量同拍多彈合併音量，不疊成爆音 |
| 唐松 | 骨節展開、短硬反掃 | 受擊側點綴一次，沒有每敵重播整段 |
| 蔓 | 骨節輕碰→短繃緊 | 接觸成立才播繃緊音，不在空招時假命中 |
| 花 | 骨片層疊→低沉刺擊 | 命中有最重一拍，空招只留破風 |
| 早蕨 | 地裂、三波骨柱拔高 | 由小到大，最後短收；不以連續低頻蓋住其他危險 |
| 鬼百合 | 兩次寬幅破風、骨節碰撞 | 順掃與反掃的聲音區分，音量受限 |
| 咒印 | 短低頻張力與骨棘展開 | 一次轉形提示，變身期間不永久循環轟鳴 |

獨立預覽可用Web Audio合成試聽，需使用者點擊啟用聲音；它是自製程序聲音草模，沒有聲稱取得原作音效或聲優台詞。正式音檔另依上述材質製作，提供獨立音量與最大片段疊加限制。

## 驗收尺度

桌機與手機使用同一套角色比例與同一時間點比對。主要人物在預覽約56–64世界像素高，查看縮小後的臉部、白衣／骨質、鞭節與手部來源。每招至少核對準備、出手、命中、收勢，以及普通／二階各一次；咒印轉形和恢復不得殘留第二份背骨或武器。

本次以獨立預覽的實際截圖、播放／拖曳檢查和素材來源追蹤作設計證據。正式遊戲入口、存檔、學招、共用吸血／暴擊與戰鬥效能的驗收屬後續實作，不由本次設計測試代替。
