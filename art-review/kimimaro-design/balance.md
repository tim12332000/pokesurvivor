## DPS計算

正規化條件：攻擊A=1、cdMul=1、無數量卡／擴散／暴擊／屬性／天氣；完整命中且始終可施放，CD從起手計。表是穩態上限，未計接近、受傷打斷、其他演出占用。三敵皆在技能幾何範圍，柳仍只攻擊一名，唐松兩輪完整命中，早蕨三敵均接觸新生骨刺。

單體DPS=D/CD；三敵柳仍D/CD，椿／唐松／早蕨為3D/CD；鐵線花為(D＋0.4D＋0.4D)/CD。

|椿|24 / 28.8 / 33.6 / 40.8 / 48|72 / 86.4 / 100.8 / 122.4 / 144|
|唐松|16 / 19.2 / 22.4 / 27.2 / 32|48 / 57.6 / 67.2 / 81.6 / 96|
|鐵線花|30 / 36 / 42 / 51 / 60|54 / 64.8 / 75.6 / 91.8 / 108|
|早蕨|25 / 30 / 35 / 42.5 / 50|75 / 90 / 105 / 127.5 / 150|

正常攻擊A=1.32時乘1.32：一階柳44，鐵線花39.6，早蕨三敵99。唐松以較低傷害交換短減傷及推退。

柳與鐵線花連續近似：每8秒鐵線花占身體1.4秒，240/8＋(1−1.4/8)×30/.9=57.5，乘1.32=75.9；這是持續近身近似，逐刀排程與死亡目標會降低實值。

## 加成與防重複

公式：每段傷害＝當階D×段比例×施放時owner.atk×共用傷害倍率×屬性×天氣×暴擊。共用倍率只套一次；君麻呂不額外加角色等級L。階級、數量、攻擊均於施放快照。

- 柳固定兩刀，數量卡只提高每刀不同目標上限：min(3,floor(1×1.25^q))；q=0/1/2/3/4/5時為1/1/1/1/2/3，每名目標每刀D/2。單體永遠不因此加傷，無卡三敵DPS表仍為單體值；最多三名且須同在實際扇區。
- 椿固定三段，數量卡提高每刺不同目標上限：min(12,floor(4×1.25^q))；同一目標三段仍合計D。無卡四敵上限不影響三敵表。
- 唐松／鐵線花／早蕨不吃數量；裝飾骨刺數不能變成額外命中。鐵線花固定一名主目標，最多三名次要目標。
- 有效間隔至少max(基礎CD×cdMul,演出總時間)。五舞演出下限為0.44/0.74/0.70/1.40/1.48秒，避免縮CD造成重疊身體演出。
- 現有10張冷卻卡：0.92^10=0.434388；未觸演出下限時DPS增為2.302087倍。極高數量＋縮CD仍須實測。
- 切走取消未出手傷段及骨林後續擴張，已結算傷害保留；重選不立即重放，未選中時凍結該招CD。柳只在身體演出空檔攻擊。
- 命中鍵為castId＋phaseId＋enemyId。柳各刀、椿三刺、唐松兩輪、鐵線花鞭／鑽各自分phase；早蕨三環共用phase，所以同敵只中一次。重疊骨柱或hurtbox不重算。
- 首領不拉動／定身／強制浮空，不改原生jumpLift。鞭、鑽、骨林不穿牆；碰撞用腳底。死亡／換場／重開取消傷段與減傷，暫停凍結。

## 可選咒印二：Lv15第六個成長選項

消耗一次升級選擇，不占主動槽；咒印一只作變身過渡，咒印二才是戰鬥狀態。建議有效8秒、起手起30秒週期，五階期間傷害倍率1.15/1.175/1.20/1.225/1.25，移速＋10%。不疊另一份咒印一buff、不重置五舞CD、不加骨林命中數、沒有全程無敵。

觸發提案：學會後可在角色機制欄啟閉「自動咒印」；開啟時，恢復完成、220範圍內有可見敵人、當前沒有五舞演出且HP高於最大HP8%＋1才起手。變身1秒結束後開始8秒有效期，30秒從變身起手計；關閉自動只停止下次觸發。此選項涉及生命代價，所以需在學習卡明示付血，不在學會當下無條件扣血。

期間每秒支付最大HP1%，不受減傷／回血倍率修正；若下一次支付會低於1HP，立即提前解除且不支付該次。正常敵傷仍可致死。沒有自帶回血。30秒週期不吃冷卻卡，避免常駐；提前解除不重置恢復週期，也不立即再開。

五階理想長期平均倍率1＋.25×8/30=1.066667，只增加6.67%；完整一次消耗最大HP8%，外加升級機會。技能按施放時快照計既定威力，即使後續收勢時變身結束，該次已開始的招式仍用原倍率；變身結束後新起手技能用普通倍率，骨林不延長不重生。血量付費是本作設計，非原作疾病模擬。

## 驗證界線

本稿僅紙面算術與程式對照，不宣稱實戰平衡。未來需驗證三圈內＋一圈外AOE、早蕨跨環仍只命中一次D、晚進再進不補傷、數量上限、極高縮CD、首領抗性、飛行跳躍、隔牆、死亡與切招取消、主動演出期間普攻停火。用30／60／120秒固定波次比較擊殺數、承傷與命中率後再調D或CD。
