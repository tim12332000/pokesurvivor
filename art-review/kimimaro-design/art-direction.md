# 美術統一修訂：森林中的屍骨脈

本次處理使用者「技能特效太隨便、缺少遊戲美感」的批評。前版功能測試通過及自評分數不代表美術已完成，舊評分不作本次品質依據。保持只做設計與獨立預覽的範圍。

## 視覺主軸

**明亮森林空地、冷白象牙骨、灰紫硬陰影、深藍輪廓，力量集中在短暫命中一拍。**

實際遊戲的地圖是16px藝術格、2世界像素一畫素、明亮森林綠與褐土。參考本工作樹正常Gaara遊戲截圖 `.omx/state/kimimaro-art/game-reference.png`，沒有清除地形或更換成測試演員。現用Naruto渲染64世界像素，約兩個地面tile高，不再把48px製作參考當現行顯示高度。

前版深青空場、幾何假人、帶木紋的細骨柱彼此不一致。此次共用實際遊戲的森林色票、重用三種既有寶可夢圖，骨面使用少量大色塊。褐色只留在泥土與根部碎石，骨頭不用枯枝裂紋表達材質。

## 每招的形狀與節奏

| 招式 | 美術重點 |
| --- | --- |
| 柳 | 不對稱短斬帶，末擊短白芯；前段留白，不圍一個發光圈 |
| 椿 | 三次細刺瞬時出現，前輕後重，收掉長時間懸著的白線 |
| 穿彈 | 小梭形、灰紫下緣、五拍停頓，高數量仍是短尾跡 |
| 唐松 | 由肩肋伸出的5～6支不等長骨，不畫規則星芒 |
| 蔓 | 有側突的椎骨鞭，從鬆曲轉為繃緊，突出鞭尖重量 |
| 花 | 同一個螺旋鑽由短粗長成長錐；不在命中換成鋸齒樹枝 |
| 鬼百合 | 突出運動中的鞭尖與極短殘影，刪持續呼啦圈式灰弧 |
| 早蕨 | 8根主柱加28組短骨群，群簇、留白與歪斜，根部破土 |
| 咒印 | 紋路、背骨與尾巴完成形體，一次低頻提示；不罩大光圈 |

人物和目標先可辨識，命中才有最強一拍，消退迅速交還視野。預設不畫判定圓、定位半圓、圈外文字或底部技術統計；範圍檢視才提供診斷資訊。跳字小且錯開，不蓋住骨鑽或被擊位置。

## 觀看尺度

一般演出使用一致的戰鬥觀看尺度。早蕨外緣可以自然出畫，保留主角腳底與附近危險；只有開啟範圍檢視時才拉開到完整圓。這是展示方式調整，實際範圍、敵人HP、命中規則及時間不變。

## 成本不擴張

替換既有特效圖集，仍只有一張640×480，實際145,972 bytes（約143KiB）、PNG≤256KiB、解碼RGBA≤1.75MiB。保留最多36組骨柱、20個共用次要粒子。既有敵人三種共六張Idle／Hurt加上原遊戲三張樹石草道具，重用合計23,692 bytes（≤24KiB）；背景用快取的像素地面繪製，不新增背景圖片或相依套件。這組特效與場景重用素材合計169,664 bytes，比前版特效圖單張205,748 bytes更小。

新材質、人物比例、鏡頭、地面、敵人及命中節奏應在同一張實際畫面裡驗收。先看準備、命中、消退三個節點，再跑既有功能和預算檢查；不能只拿圖集放大圖或綠色測試結果作美感證明。
