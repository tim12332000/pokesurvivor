# 君麻呂 v3：八招與咒印的演出規格

2026-10-27。靜態分鏡與動作製作規格，尚未製成動畫、圖集或遊戲功能。所有秒數是本作提案，並非從原片量得。數值以 [v3數值稿](balance-v3.md) 為準；新招的分工、傷害段落與本文件必須一起驗收。

八招是可學候選池，不是八招同時播放。柳常駐，其餘按現有主動槽與最多四招羈絆選組；同一人物始終只有一條身體動畫。

本輪首要目標是「玩起來爽、帥氣、好看」：連斬越打越快，骨鞭甩開有寬度，骨鑽命中有重量，骨林生長有節奏。這些都要能在移動怪群與手機小畫面讀到；不靠長站樁、全場停頓或不可見判定換取強度。

鬼百合借鏡 [手游咒印君麻呂資料](research-mobile-games.md) 的骨鞭語意；本作改成學會後普通形態也可使用的可選招，避免僅在8秒咒印窗口能施放。這是本作改編，不宣稱少年原作有一套同名固定八招。咒印二改專用姿勢與尾巴平衡，不免費另加命中。

## 1．柳之舞：.64秒短連斬

0–.12秒沉肩、前臂骨刃伸出；基礎四擊由右臂斜切、左臂交叉回斬、轉腰肘骨短切、前臂收尾組成，首擊.12、末擊.60秒，中間逐漸加速。最後.04秒回位。普攻全程可走位，不能每輪替玩家強制往怪群跨一步。

數量增加到5–8連時，真實接觸仍落於.12–.60秒，相鄰間隔按.85等比縮短，再正規化讓總間隔為.48秒；越到末段越密，不像固定節拍器。身體以不同骨刃部位與短回斬接上。每擊轉向並重查近身目標，死目標不補傷到遠處。斬弧只連著實際骨刃、短暫停留；不將八次命中畫成一個持續白圈。

聲音是輕、短骨刃擦切，末擊略重。人物身高與腳底穩定，不藉每擊放大立繪表達力量。

## 2．椿之舞：.74秒細劍三刺

0–.16秒骨劍成形並收在身側，.16–.30秒首刺，.30–.43秒回肘再刺，.43–.57秒腰背一起送出末刺，.57–.74秒收劍。傷害節點.30／.43／.57，各25%／25%／50%。

首刺前更新方向一次，之後方向固定；玩家仍可移動，出手原點跟人走。骨劍細、長，尖端突出手掌，三條短殘影有間隔。末擊的音高更低，可只停人物攻擊姿態數幀，不凍結怪物、鏡頭或輸入。

## 3．十指穿彈：.60秒射擊，保留走位

| 時段 | 本體與武器 | 發射／命中規則 |
| --- | --- | --- |
| 0–.12 | 身體先轉向首個合法目標、雙手抬到胸肩間，手掌可辨 | 準備最多三名的逐彈輪流瞄準；每枚發射前仍須同步朝向 |
| .12–.16 | 手指張開，指尖骨質短暫前伸 | 沒有流血特寫、巨型能量蓄力球 |
| .16–.44 | 五個出手拍，雙手交替、指尖依序輕彈、手腕小幅後坐 | 基礎5枚於.16／.23／.30／.37／.44秒發射 |
| .44–.60 | 收手回移動姿勢，指尖恢復 | 只結束本體演出，不回收已飛出的骨彈 |

以上是**發射時間，不是命中時間**。命中依骨彈真實飛行與碰撞；沒有在.16秒遠端直接扣血。小骨彈具尖頭、短陰影與方向，暖象牙色和地面區分，只留極短細尾跡。五拍音效比柳更輕、更銳，不加槍械火光。

數量卡若增至最多15枚，仍維持五個清楚出手拍，每拍分配1–3枚。當前可見、可達目標按最近順序取最多三名，逐彈輪流瞄準；只有一名時全部可朝他發射。肩、手腕、指尖與實際彈道同步轉向，高數量同拍分彈以雙手與手指偏移讀出方向，不是在固定扇面裡隨機散射。總枚數以數值稿為準，不能每個手指都自動複製整輪；多枚骨彈同時碰到一人時，依數值稿的單彈規則計算。禁止生成後再無聲轉彎追蹤同一目標。

全程可正常移動；每枚在指尖離手前確認合法目標與朝向，離手後方向固定，不做飛行中追蹤。輪到的目標死亡／離開射程時，發射前可重選合法目標，無合法目標就不補發。切招取消尚未發射的骨彈，但已射出的獨立骨彈繼續按碰撞規則飛行；死亡／換場／重開清除其所有權。這與切走就取消尚未長出的骨林不同，兩者在說明中需清楚。

## 4．唐松之舞：.70秒本體、.88秒防護收完

0–.18秒低身收肩；.18–.30秒胸肋與肩骨向外展開，.30秒第一輪命中；.30–.52秒扭腰反掃，.52秒第二輪命中；.52–.70秒人物回防，骨刺防護VFX到.88秒完全縮回。兩輪各半傷，短防禦是.18–.88秒。

骨刺必須連在身體，骨尖長度與實際近身範圍一致。受擊只在接觸側閃一小塊骨質亮點，沒有每敵觸發一輪新動畫。普通怪推退是第二輪作用，首領留原位；不加旋轉吸入或彈幕反彈。

## 5．鐵線花・蔓：.70秒，鞭就是完整一招

| 時段 | 演出 | 判定／移動 |
| --- | --- | --- |
| 0–.20 | 手伸至背後取脊骨鞭，骨節由握端依序展開 | 玩家可走；不做背部撕裂血腥特寫 |
| .20–.42 | 收肩甩出長鞭，鞭尖沿可見弧線抵達目標 | .42秒鞭接觸，實際鞭路徑與障礙均需檢查 |
| .42–.62 | 骨節依序繃直，普通怪被短拉至身前安全位置 | 僅這.20秒固定腳底；首領／精英等不搬動 |
| .62–.70 | 鞭鬆開、由尖端往手掌回收 | 恢復走位；單獨使用就結束，沒有免費鑽擊 |

單獨蔓的攻擊範圍、是否可掃到次要敵以數值稿為準；每個骨節不是一個傷害物件。同一目標不因鞭彎折經過多次而額外受傷。主目標死亡、鞭路被擋就自然鬆鞭收勢，不把剩餘拉動改套另一名敵人。

聲音先是骨節輕碰，再有短促繃緊聲；真正接觸處出少量骨屑，禁止整條鞭持續發白光。

## 6．鐵線花・花：.86秒，獨立蓄鑽重刺

0–.12秒手臂收在身側、身體微壓低；.12–.30秒骨質從手腕開始層疊向前長成錐狀；.30–.46秒蓄勢、肩背對準鑽線；.46–.58秒一次向前重刺，**.58秒命中**；.58–.86秒抽回、骨鑽縮回前臂。

花不憑空送玩家到目標面前，不自帶鞭拉。單獨使用只在有效鑽線內有目標時起手；玩家0–.46秒可移動，.46–.58秒固定腳底以確保刺擊接觸位置可讀，命中後恢復走位。起手先瞄準，.30秒完成最後一次方向更新，之後鎖方向直到刺出。

花的骨鑽包覆整條前臂，體積、蓄勢和低沉聲音比椿明顯；不能把椿第三刺放大就當新招。只在真實尖端／鑽體碰到敵人的幀結算。命中出短碎骨、末端短硬停；沒有鑽頭旋轉數圈就每圈再扣一次D。

花是本套最重的接觸：成功命中時，本體攻擊姿態與鑽尖局部停.045秒，包含在原.86秒演出內，不另加鎖腳、不停世界、不吞搖桿輸入。碎骨先向前噴散、再迅速落淡；普通敵人短受擊姿態讓刺入感可見，首領只閃傷／受擊表現，不強制後退。沒有命中就沒有假爆炸和重擊音。

## 蔓→花羈絆：總長1.40秒，不送第三段傷害

這是同組中兩招連續施放的動畫銜接，不是新增第九招。只有蔓與花皆已學會、同在目前選中組、花已就緒、沒有其他更早等待招式時，才可預定這次銜接。預約只保留蔓這次接觸的原目標；預定不先扣花CD，花真正起手才扣。到.54秒接入時再次核對其他等待招式，不能為維持帥氣演出跳過更早等待者；若公平順序不允許，就釋放預約並讓兩招走獨立排程。

| 全局時間 | 蔓／花狀態 |
| --- | --- |
| 0–.42 | 蔓正常起手，.42秒鞭中 |
| .42–.54 | 普通怪開始短拉，另一手收向腰側準備骨鑽 |
| .54 | 花開始自己的.86秒施放；此時才消耗花CD與快照。蔓的待結算傷害沒有複製 |
| .54–.62 | 一隻手維持骨鞭張力，另一隻手骨鑽生長；是專用雙手過渡姿勢，不疊播兩張全身動畫 |
| .62–1.00 | 專用銜接讓鞭維持普通怪在安全站位，花繼續蓄鑽；控制上限計入這套演出的代價，首領不受控 |
| 1.00–1.12 | 花最後刺擊，短固定腳底，1.12秒鑽中 |
| 1.12–1.40 | 抽鑽收勢，可走位，回一般排程 |

羈絆銜接時，普通怪可從鞭中.42秒保留至骨鑽命中1.12秒，最長.70秒，鞭仍需清楚連在雙方之間；不另延長、不得把這段控制套給首領。獨立蔓仍在.62秒鬆開，不能未學花也獲得整段束縛。

若拉動未成功、原目標死亡或花起手.54秒時鑽線不可達，取消這次銜接，不默默改抓另一人；尚未起手的花不花CD，之後可按正常獨立排程重新尋敵。花已起手後原目標失效，後續只依真實鑽線判斷，不轉為追蹤補傷，已花CD不退。玩家在非鎖腳段移動可能改變鑽線，控制不是保證必中；不能免費瞬移或遠端補鑽。

骨鞭命中只給蔓本身傷害，骨鑽只給花本身傷害；不再另外套v2整套鐵線花D240或一次「連動爆炸」。蔓與花的各自等級獨立決定傷害，不要求同階。切招取消尚未出的花，已起手花CD不退；尚未真正起手花則沒有花CD費用。

蔓花依同組技能ID辨識，不要求相鄰或加入順序。兩招公平排程允許接續時才預約；一招已就緒、另一招剩餘CD≤.54秒、目標合法且無更早合法主動等待時，可短等到兩招皆就緒。等待可走位、不扣CD，不起手會跨過預約時點的柳；其他情況獨立出招。8.54秒周期以此短等政策為前提。

蔓的安全落點須在玩家與怪物接觸半徑和之外另留8單位，並盡量在柳射程；不把怪疊在玩家腳底。單蔓先以短拉接斬的可見回報驗證學習價值。

## 7．早蕨之舞：1.48秒骨林，按地僅.30秒

0–.30秒低身按地、腳底固定；.30–.48秒地面裂紋與真圓預告，此時可走位；.48／.68／.90秒骨林依次長到R/3、2R/3、R；.90–1.18秒骨柱短停，1.18–1.48秒碎裂沉回。

三波判定為擴大完整圓盤，整個cast每敵最多一次；不是每柱一次、每圈各D或殘留DOT。晚進內圈可在下一波吃到一次傷害。boss不因地形用flying旗標免傷，真正跳起仍跳過該次；首領不強制浮空。傷害規則以數值稿和共用可傷害管線為準。

鏡頭固定，不特寫骨中現身追殺；地面外界是真圓，骨柱本身往上延伸。低柱先出、高柱後拔，前景遮到敵人或玩家時降透明度，保留腳底與敵方攻擊預告。碎裂聲按三波加重，沒有全場連續震屏。

最後.90秒大波命中時，角色按地殘勢與主要骨柱頂端可局部停.035秒，包含在原1.48秒演出內；世界、怪物更新與玩家輸入不停止，且不讓整片畫面閃白。前兩波保持清楚生長節奏，最後一波用更厚的骨裂聲與少量向外骨屑形成高潮，不追加一次傷害。

## 8．鬼百合：.90秒兩次柔性周身掃鞭

0–.14秒拉開手臂、脊骨鞭向側後展開；.14–.32秒腳底小幅轉向、完整順時針掃過周身，**.32秒第一輪命中**；.32–.44秒身體換重心；.44–.62秒反向完整掃一圈，**.62秒第二輪命中**；.62–.90秒鞭逐節收回、回移動姿勢。兩輪各D/2。

每輪都是完整360度掃掠，不是互斥前後半圓各D/2，否則靜止圈內敵人只會吃半筆總傷。各輪分別去重，所有鞭節共用同一輪命中記錄。正式原型須用連續掃掠或明確覆蓋整圈的接觸影格對齊，不用一根細鞭朝右時直接判左側傷害。

五階半徑120／120／135／135／150，沒有內圈死區，較唐松遠，但沒有防護、吸附、浮空或推退；全程允許正常移動，以玩家當下腳底為圓心，不能甩完後留下固定白圈繼續打。鞭根至鞭尖的弧形掃掠都要看得見，讓玩家貼身也有清怪回饋；承壓時仍需走位或改唐松。鞭不連到螢幕邊界，也不把首領拉到玩家身上。

咒印二的尾巴可作反向旋轉時的配重，不代替骨鞭，也不多一筆掃尾傷害。音效是兩次寬而清晰的破風與骨節碰撞，避免和唐松的短硬展骨聲混淆。

## 咒印與共同取消規則

咒印沿用v2：1秒轉形、有效8秒、30秒周期、無自動付血和新增開關。0–.20秒收肩；.20–.45秒咒紋沿皮膚擴散；.45–.75秒灰褐膚、背骨與肉身長尾成形；.75–1秒進入二階低重心待機。全程允許移動，不加無敵。咒印就緒有一次排隊優先，但不打斷正在施放的招式。

普通與咒印二都需要八招的專用身體輪廓。尾巴、背骨、衣物跟著動作變形，不能普通圖染灰；手臂已有骨鑽時不再疊第二個完整鑽頭。普通態也可使用鬼百合是本作技能池改編，必須在來源說明中保留，不稱為原作正常形態招式紀錄。

切招立即取消未發射／未結算傷段、普通怪拉動與後續骨林波，立即恢復移動，最多.10秒退出姿勢後新組才能起手；不給取消無敵或返還已花CD。持續推搖桿不視為取消。十指已發射骨彈繼續飛行，其餘尚未生效的身體攻擊不在背景補完。死亡、換場、換角色或新局清理全部角色所有權、控制和獨立飛行物。

後續正式素材先做48邏輯像素等尺寸的少量關鍵姿勢，核對張指／骨彈來源、鞭節、骨鑽與鬼百合整圈掃掠的可讀性，再決定圖集格數。蔓花雙手過渡、咒印二專用八招、四連加速及真圓地面提示需要按本稿進行逐格製作；不把未做的轉接影格算進本輪靜態圖交付。

聲音目前只是方向，未製音檔；不得把文字音效描述列成可用授權資產。正式動畫驗收需實際手機橫直向、怪群遮擋、骨彈飛行、羈絆轉接、取消和咒印到期測試，不能只看高解析概念板。
