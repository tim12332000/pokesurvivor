# 多分身效能修正

使用者回報：須佐軍團版選自身分身卡後，人數增加造成效能問題。

## 保留的行為

自身分身仍有各自的木分身軍團、實際火牆與須佐接觸；不以刪除演員、縮傷害範圍、漏掉合法攻擊或限制卡牌來製造效能數字。保持移動、牆阻擋、傷害歸屬和取消／死亡／換場清理。

## 修正前計畫

1. 鎖定舊模組565d6e82，以相同配置實際召喚自身分身，分開量測模擬、繪製、原生畫面間隔與搜尋／路徑呼叫；受控靜靶明確標示。
2. 優先消除每次空間查詢重建全敵人Set、線性會員查找及有效目標仍全場重選的成本，沿用EnemyMgr.get的真實身分查詢，避免快取在傷害回呼後失效。
3. 最近合法目標以距離預篩後檢查真路徑／武器幾何，維持現有攻擊接觸及排序語意。沒有目標時短週期重查，連續移動和已釋放攻擊照常逐步更新。
4. 先跑新回歸，再量測相同場景；只有證據顯示仍有關鍵負載才擴大改動。
5. 重建同一本機試玩包，核對實際bytes與新版回歸，讓使用者重載遊玩。
