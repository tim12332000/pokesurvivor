# 跨界角色製作與手感優化

適用於含 `.omx/naruto.js` 的 PokéSurvivor 專案；保留既有skill名稱供舊呼叫沿用。先確認專案根目錄、分支和角色版本，程式路徑均相對該根目錄，不相對skill安裝位置。

## 按任務讀取

- 完整新增／生成／整體重做角色：必讀 [完整角色 SOP](references/new-character-sop.md)，預設自動啟動總監與原生多 agent 分工、內部退回修正，做到完整候選，不等使用者再次提醒。這是端到端交付流程，不是保證第一張生成圖就無需返工。
- 單招設計或手感改善：讀 [角色品質準則](references/character-quality.md)，只跑相關範圍；不把小改一律升級成完整角色流程。
- 素材、動畫、圖集或角色接線：讀 [製作流程](references/character-workflow.md)。單一已知問題只讀相關段落，不強制重跑完整角色流程。
- 專案有 `art-review/design-council/charter.md` 時，由該入口載入現有企劃、美術、動漫指引。完整角色依SOP預設總監與多角色分工；單點任務適合並行才分配獨立範圍，不改通用模型設定來冒充品質改善。

## 決策基準

使用者調好的**現行火影實作**是手感參照。以當前程式、載入覆寫和正常入口為準，歷史企劃／固定數值／舊通過報告只作線索。不得把舊版八門、砂盾或角色／圖集數量寫回新實作。

本專案要求誇張力量幻想：少量卡有可見收益，成形後有大片清怪與招牌高潮。規模落在真實段數、幾何、協戰或連動；只修命中、縮CD、換色或加粒子不代表完成。不預設保留舊傷害／範圍／CD或硬加弱點，也不套用案例輪數上限。

先設計起始→少量投資→成形的完整循環，再決定招數、學習等級和有用的新被動，不湊固定四招／五招。保留使用者已調好的既有角色，不削弱它們讓新角色達標。

## 身份與素材

- 核對角色時期及官方來源，分開原作和本作改編。原作約束力量來源／動作語意，不替遊戲規定數值上限；不借未核對的他人／後期能力湊招式。
- 有可靠依據的AOE轉成真範圍命中，不用單體追蹤球或名稱冒充。數值、卡牌和自動施放明示為本作改編。
- 先查現用圖集與分派，能沿用姿勢／程序效果時不重畫。新點陣圖用imagegen skill，保存提示詞、輸入、原始輸出與SHA256，不標成官方擷取。
- 火影像素研究入口 `https://spritedatabase.net/game/55` 用於比例／描邊／動作；其他作品選相關來源，不機械套火影圖。正常尺寸核對輪廓、腳底、鏡射、像素密度，圖集／方向數按需要決定。

## 實作與完成

- 戰鬥、卡牌預覽、升階和說明共用能力資料；數量有真受益端與上限。技能池、角色ID和存檔不污染其他角色。
- 身體、夥伴、反應與場域分清時鐘／歸屬，逐段有獨立事件、繪製只讀。雙來源真傷害不去重成一筆，衍生攻擊不遞迴觸發自己。
- 以新角色／行為案例、正常入口桌機／手機、真輸入與完整多段影像驗收；查範圍內外、牆、移動、同波兩目標回呼取消、暫停／死亡／換場／局次／分身，方法見品質準則。
- 新技能同步圖示、HUD、選角列、門檻、生成器與打包，不硬編舊四角／十一圖集等數量。小尺寸看真可見性／邊界；高配實錄和自然養成證據分開。
- 預先定足夠的交付證據，通過後僅因新改動、失敗或未解風險重測。視覺分數不代表真人好玩，手機視窗短測不代表實機長局。
- 交付可玩連結、改動、證據與未驗部分。只有有效授權涵蓋發布才提交推送／部署，此skill不自動授權外部操作。

## 維護此skill時

專案有 `art-review/design-council/character-quality.md`／`new-character-sop.md` 時，以它們為對應準則來源，同步本包reference與已安裝的同名skill，並驗證連結／內容一致。這是修改指引時的維護工作，不是每次新增角色都先重寫規則。
