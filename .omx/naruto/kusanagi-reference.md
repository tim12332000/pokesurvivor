# 草薙劍・環繞

佐助 Lv.1 即可學，使用第五招式欄，保留雷切、豪火球、寫輪眼與風魔手裏劍。滿永久強化的開局雙招可直接攜帶雷切與草薙劍。學會本身不啟動，也不切換當前攻擊。切換至草薙劍技能、由正常自動施放開啟後，永久環繞；之後切換別招仍保留，不需重放。死亡、失去技能或換局後要重新開啟。

官方劍術參考：[宇智波流劍術](https://naruto-official.com/en/news/01_1710)。官方說明佐助劍術與雷遁包覆劍刃；自動浮空環繞、多劍與數值為本版生存遊戲改編，不宣稱原作有自動環繞劍術。

劍的外型參考 [Bandai S.H.Figuarts 官方佐助模型](https://tamashiiweb.com/item/13854/?wovn=en) 的第 03、04 張商品照片：銀色直刃、簡潔黑柄、齊平的小型金屬接環。以程式重新繪製像素圖，不含十字護手或柄上纏帶；照片僅供參考，沒有打包進網站。像素圖快取一次，旋轉時關閉平滑取樣。

- Lv.1：1 把，基礎傷害 28，軌道半徑 58。
- Lv.2：2 把。
- Lv.3：傷害 ×1.30、半徑 ×1.10。
- Lv.4：3 把。
- Lv.5：傷害再 ×1.35、半徑再 ×1.10。
- 視為飛行道具；數量增幅每層額外 1 把，三勾玉寫輪眼的彈道 +1 另加 1 把。升級與選卡會即時更新已開啟的環繞劍，不重複套用施放快照。
- 相同敵人不論同時碰到幾把，每 0.35 秒最多一次有效命中；不同敵人皆可被劍刃範圍命中。
- 使用一般鋼屬性與天氣倍率；每次命中正常歸屬施術者，吸血與生命剝奪各只計一次。
- 死亡、失去招式、換世界或離場清除；每位玩家各自維護軌道與命中間隔。

數值集中於 `.omx/naruto-skills.js` 的 `naruto-kusanagi`，接觸間隔、劍長與角速度在 `.omx/naruto-kusanagi.js` 的 `config`。
