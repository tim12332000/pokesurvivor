# 豪火球之術：外觀參考與調整

佐助、鼬共用技能 `naruto-fireball`。調整位置在 `.omx/naruto-skills.js`，不修改寶可夢或數碼寶貝的共用小火焰。

## 官方參考

- [官方佐助生日專欄（2024-07-23）](https://naruto-official.com/en/news/01_1856)：收錄漫畫第 223 話，佐助結印、從口中吐出大型火團的畫面；本版依其寬大火焰輪廓改畫像素火球。
- [官方動畫「Father and Son: The Broken Crest」](https://naruto-official.com/en/anime/naruto1/list/01_354)：確認佐助使用 Fire Style: Fireball Jutsu。
- [官方曉公仔企劃](https://naruto-official.com/en/news/01_2332)：鼬的豪火球造型參考。

官方漫畫用來核對動作與體積。橙紅配色、亮黃核心、飛行速度、命中爆炸、數值和燃燒效果是本遊戲的像素風改編；沒有把官方圖片打包進遊戲。

## 可調設定

| 位置／欄位 | 目前值 | 用途 |
| --- | --- | --- |
| `SHAPES['naruto-great-fireball']` | 51×43，3 幀 | 圓形主體、後方火舌、邊緣翻動 |
| `vis.projScale` | 1.6 | 成長倍率的基準，實際從 0.32 增至 2.24 |
| `size` | 52 | 成長倍率的基準碰撞半徑，實際從 10.4 增至 72.8 |
| `fireballGrowth.startRatio`／`endRatio`／`distance` | 0.2／1.4／300 | 依實際飛行距離線性放大，300 世界像素達上限 |
| `blastRadius` | 95 | 爆炸實際範圍，沿用原設定 |
| `dmg`／`cd`／`burn` | 49／2.3 秒／0.12 | 本次保持原傷害、冷卻、燃燒 |
| `speed`／`life` | 300／1.4 秒 | 本次保持原飛行速度與存活時間 |
| `PAL['naruto-fireball']` | 深紅、橙、黃、亮黃 | 豪火球專用配色 |
| `SHAPES['naruto-great-fireball-burst']` | 51×51，3 幀 | 命中時的火焰爆裂圖形 |

碰撞半徑擴大會讓火球較早命中側面的敵人或障礙物，這是配合大型火團的實際行為。爆心半徑仍為 95，沒有跟著無限制增大。

數量增幅每層增加一顆火球，每顆保留完整傷害。命中目標取得 20% 直接傷害加 80% 爆炸傷害；其他爆炸範圍內目標取得 80%，不重複完整計算兩次。

## 本地驗證

執行 `python .omx/check_naruto_fireball.py`，使用實際遊戲戰鬥程式驗證：

- 佐助／鼬限定技能池，傷害與冷卻不變。
- 三名分散在有效範圍內的敵人受傷，範圍外敵人不受傷。
- 數量增幅生成多顆完整傷害火球，不改寫已學技能。
- 牆壁阻擋、物件碰撞、傷害歸屬、死亡及場景清理。
- 桌面與 390×844 觸控直向截圖，確認火球從口前小火種成長為大型火團，且不遮住技能按鈕。

截圖輸出 `.omx/naruto-fireball-desktop.png`、`.omx/naruto-fireball-portrait.png`；這些是本地檢查檔，不作為網站素材。


## 佐助專用結印與吐火動作

`.omx/naruto-fireball-cast.js` 獨立處理佐助豪火球，不改鼬或其他忍術共用動畫。參考[官方佐助生日專文／第 223 話](https://naruto-official.com/en/news/01_1856)的口部吐火，重用原始站姿的頭、身體與腳，以程式像素拼接結印、手靠嘴吐火與收勢。手部是本版改編動作，並非新增官方影格。

調整 `config.sealDuration`（0.24 秒）、`breathDuration`（0.16 秒）、`recoveryDuration`（0.14 秒）控制節奏。結印完成才產生原本數量與傷害的火球；施放暫停一般走路，不加無敵。開始時鎖定方向，左右鏡射，火焰細流接到前方球體，避免大球遮住整張臉。死亡、清場、換世界或重新開局均取消未發射火球。

火球中心由 `origin(pl, angle)` 設定：沿目標方向前移 24，投射物座標向上 22，再由既有渲染 `LIFT` 抬高至嘴部附近。前移路徑每 4 像素檢查牆壁與障礙物，避免越牆產彈。命中半徑依實際飛行距離成長，爆炸傷害仍沿用原技能數值。執行 `python .omx/check_naruto_fireball_cast.py` 驗證延遲、單次釋放、快照、取消及桌機／直向手機畫面。

## 隨距離成長

火球從嘴前的小火種開始，按實際行進距離同步放大外觀與碰撞；停著只經過時間不會變大。每顆各自記錄飛行距離，數量增幅不共用狀態。

| 飛行距離 | 碰撞半徑 | 顯示比例 |
| --- | --- | --- |
| 0 | 10.4 | 0.32 |
| 75 | 26 | 0.8 |
| 150 | 41.6 | 1.28 |
| 300 | 72.8 | 2.24 |
| 400 | 72.8 | 2.24（封頂） |

傷害、冷卻與爆炸半徑不隨火球成長提高，仍為 49、2.3 秒與 95。數字是遊戲改編，調整 `fireballGrowth` 三個欄位即可更改起始、上限與成長距離。測試另輸出 `.omx/fireball-growth-{near,mid,far,portrait}.png`，均由實際投射物飛行產生。
