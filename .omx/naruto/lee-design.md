# 小李：少年篇體術角色

定位：近身掃群、踏入接觸後集中連擊。美術以現有重繪鳴人／佐助的身材比例、像素尺度、輪廓及腳底錨點製作；Ninja Council 3 只作研究，不直接裁切遊戲圖。

基礎生命 180（原為 130），高於鳴人 120、佐助 108，支撐近身體術走位；永久強化的生命加成另外計算。

學會八門遁甲後，底部技能列顯示圖示、五階等級點及常駐標記；點擊可查看目前門名與等級，仍維持自動生效，不切走正在使用的體術。

開門移動時，身後留下當時姿勢的紅色殘影；第一至第五門的殘影尺寸由 1.04 倍增至 1.48 倍，最多由 3 個增至 7 個，逐漸延長拖尾與淡出時間。殘影沿實際走位／突進位置繪於角色後方，停下後消散、暫停時凍結，死亡與換場清除；不產生額外傷害。

選擇表蓮華或裏蓮華後，技能冷卻期間會自動使用近身體術普攻，沿用既有基礎近戰的傷害、攻速、範圍與命中流程，使用小李拳擊圖格。蓮華就緒時優先施放，完整連段期間不插入普攻；不切換目前技能、不新增技能槽，也不重複扣減蓮華冷卻。

表／裏蓮華落地對其他附近目標造成基礎傷害的 35%，這是生存遊戲改編。裏蓮華可獨立施放，與開門攻擊加成相容；獨立施放及所有數值皆為本作機制，不作原作設定聲明。少年小李不使用朝孔雀、夜凱或成年高階八門。

表蓮華流程：approach → windup → lift → slam → recovery。裏蓮華流程：approach → windup → lift → combo → descent → slam → recovery；貼近後預備 0.18 秒、挑空 0.36 秒（高度 52）、五連段 1.05 秒、平滑下降 0.22 秒、重摔 0.16 秒與收勢 0.18 秒，共 2.15 秒。角色實際踏入接觸位置，並非畫出遠方分身。接近移動以最多 4 像素步進檢查牆與碰撞，不額外給予無敵。表蓮華目標死亡即中止；裏蓮華挑空前亦如此，但已挑空後主目標途中死亡，仍會完成下降與落地範圍傷害，不轉移主目標或補發其餘主目標命中。遠離接觸範圍、路線封閉、角色死亡、世界切換及 clearFields 仍中止。浮空保存在本招的獨立視覺高度，敵方繪圖透過 liftFor 疊加；完全不修改原生 jumpLift 或跳躍物理。首領不浮空。

## 八門被動與形態

學會即生效，升階替換倍率而非相乘，切換主動技能仍保留。本局增益不代表跨局自動學會。第一至第五階使用專用紅臉、白眼、豎髮形態，包含 32 格共通動作與 16 格技能；第三階起加強綠色氣場。

[使用者指定的 Sprite Database 小李素材](https://spritedatabase.net/files/ds/55/Sprite/RockLee.png) 的 Ura Renge 使用不同紅臉姿勢，作為形態與動作匹配參考。本作重新繪製，沒有直接裁切使用。前兩階即紅臉、五階共用造型與永久增益皆為生存遊戲改編。

裏蓮華落地以完整外圈標示當次實際半徑，再畫內圈擴散與爆發；五階基準半徑 100／120／140／160／180，每升階 +20。主目標傷害分配為 10%＋五次各 12%＋重摔 30%；附近次要目標各僅受一次 35% 基礎傷害，主目標不重複吃範圍傷害。擴大落地範圍與延長空中連段為本作改編。
