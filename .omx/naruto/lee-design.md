# 小李：少年篇體術角色

定位：近身掃群、踏入接觸後集中連擊。美術以現有重繪鳴人／佐助的身材比例、像素尺度、輪廓及腳底錨點製作；Ninja Council 3 只作研究，不直接裁切遊戲圖。

基礎生命 180（原為 130），高於鳴人 120、佐助 108，支撐近身體術走位；永久強化的生命加成另外計算。

學會八門遁甲後，底部技能列顯示圖示、五階等級點及常駐標記；點擊可查看目前門名與等級，仍維持自動生效，不切走正在使用的體術。

開門移動時，身後留下當時姿勢的紅色殘影；第一至第五門的殘影尺寸由 1.04 倍增至 1.48 倍，最多由 3 個增至 7 個，逐漸延長拖尾與淡出時間。殘影沿實際走位／突進位置繪於角色後方，停下後消散、暫停時凍結，死亡與換場清除；不產生額外傷害。

選擇表蓮華或裏蓮華後，技能冷卻期間會自動使用近身體術普攻，沿用既有基礎近戰的傷害、攻速、範圍與命中流程，使用小李拳擊圖格。蓮華就緒時優先施放，完整連段期間不插入普攻；不切換目前技能、不新增技能槽，也不重複扣減蓮華冷卻。

表／裏蓮華落地對其他附近目標造成基礎傷害的 35%，這是生存遊戲改編。裏蓮華可獨立施放，與開門攻擊加成相容；獨立施放及所有數值皆為本作機制，不作原作設定聲明。少年小李不使用朝孔雀、夜凱或成年高階八門。

表蓮華流程：approach → windup → lift → suspend → descent → slam → recovery。裏蓮華流程：approach → windup → lift → combo → descent → slam → recovery；貼近後預備 0.28 秒、挑空 0.48 秒（基礎挑空高度 60，之後每次計畫空中踢擊再升高 8）、空中連段 D = 1.65／[1＋0.025 ×（C－5）] 秒（五階零數量加成時為 5／7／9／11／13 段，另加數量卡段數）、平滑下降 0.32 秒、重摔 0.24 秒與收勢 0.28 秒，共 1.6＋D 秒。角色實際踏入接觸位置，並非畫出遠方分身。接近移動以最多 4 像素步進檢查牆與碰撞，僅裏蓮華 lift／combo／descent 具有無敵，approach／windup／slam／recovery 及整套表蓮華仍可受傷；結束或取消立即移除保護。兩招挑空前主目標死亡即中止；已挑空後主目標途中死亡，兩招都仍完成下降與落地範圍傷害，不轉移主目標或補發其餘主目標命中。遠離接觸範圍、路線封閉、角色死亡、世界切換及 clearFields 仍中止。浮空保存在本招的獨立視覺高度，敵方繪圖透過 liftFor 疊加；完全不修改原生 jumpLift 或跳躍物理。首領不浮空。

## 八門被動與形態

學會即生效，升階替換倍率而非相乘，切換主動技能仍保留。本局增益不代表跨局自動學會。第一至第五階使用專用紅臉、白眼、豎髮形態，包含 32 格共通動作與 16 格技能；第三階起加強綠色氣場。

[使用者指定的 Sprite Database 小李素材](https://spritedatabase.net/files/ds/55/Sprite/RockLee.png) 的 Ura Renge 使用不同紅臉姿勢，作為形態與動作匹配參考。本作重新繪製，沒有直接裁切使用。前兩階即紅臉、五階共用造型與永久增益皆為生存遊戲改編。

裏蓮華落地以完整外圈標示當次實際半徑，再畫內圈擴散與爆發；五階基準半徑 100／120／140／160／180，每升階 +20。主目標傷害分配為挑空 10%＋第 n 次空中連擊 12% × 1.10^n＋重摔 30%；空中次數 C = 5＋2 ×（技能等級－1）＋Q，總傷害倍率為 0.4＋0.12 × Σ(n=1..C) 1.10^n（相對當階基礎傷害）；附近次要目標各僅受一次 35% 基礎傷害，主目標不重複吃範圍傷害。擴大落地範圍與延長空中連段為本作改編。

裏蓮華每次技能升階增加兩段空中連擊及限定空中階段無敵，皆為本作玩法改編；數量卡每點增加一次空中命中，地面範圍仍只在落地結算一次。

裏蓮華起手快照技能等級與數量加成 Q，中途拿卡或升階不改當次連段。第 n 次空中命中的基傷係數為 0.12 × 1.10^n，第一下乘 1.10、第二下乘 1.21，每次施放從第一下重設；挑空 0.10、重摔 0.30、次要目標落地 0.35 不乘此指數，最大生命百分比額外傷害也維持原比例。總主目標基傷倍率為 0.4＋0.12 × Σ(n=1..C) 1.10^n。既有數量卡最多 20，技能第五階、Q=20 時空中 33 次、總命中 35 次，空中連段依新公式縮短至約 0.970588 秒。這些數量與傷害遞增皆為本作改編。

八門自帶自然回復：每秒回復量 =（既有自然回復＋目前最大生命 × 技能階級 × 0.01）× [1＋（10 × 技能階級＋角色等級）／100]。自帶基礎回復五階分別為最大生命 1／2／3／4／5%／秒；例如第五階、角色 Lv.30，僅自帶部分即 5% × 1.8 = 最大生命 9%／秒，其他自然回復再另併計。回血倍率只乘一次，回復上限為目前最大生命；最大生命、技能階級、角色等級均動態更新。整合既有 Game 更新流程，暫停不推進；死亡、未學八門或非小李角色不取得此自帶回復，不使用第二個計時器。這是本作被動改編。

兩招均以可辨識的上踢、空中抱持／連擊、下降與落地姿勢表現較長連段。表蓮華設計 1.66 秒、裏蓮華設計 1.6＋D 秒（均不含接近）；表蓮華固定時間步進約 1.68 秒，裏蓮華依本次快照段數而變。表蓮華全程可受傷，裏蓮華仍僅 lift／combo／descent 無敵。冷卻各為 3／5 秒、起手時計算；冷卻期間補近身普攻，連段中不插普攻。兩招挑空後主目標死亡都完整落地；挑空前死亡、角色死亡、換場、牆與距離檢查仍可取消。提高基傷、延長動作及挑空後保留落地皆為本作改編。

表蓮華階段時間：windup 0.24、lift 0.36（高度 40）、suspend 0.42、descent 0.22、slam 0.20、recovery 0.22 秒；落地完整外圈對齊半徑 60，再播放內圈爆發。基傷 110 分配為挑空 20% 與重摔 80%，次要目標各一次 35% 基傷。

裏蓮華逐踢升高與加速：起始挑空高度 60 世界像素，每次計畫空中踢擊再升高 8，峰值 H = 60＋8 × C；C=5／15／33 時峰值為 100／180／324。各踢擊時間間隔按 0.90 等比遞減，正規化後總空中連段時間 D = 1.65／[1＋0.025 ×（C－5）] 秒；上述 C 的 D 分別為 1.65／1.32／約 0.970588 秒，接觸後總長 1.6＋D，即 3.25／2.92／約 2.570588 秒（不含接近，固定步進可能稍有取整差異）。掉幀須補齊跨過的計畫踢擊；主目標死亡後仍按計畫升高並落地，但不補發對死者的命中或傷害。下降 0.32 秒從實際峰值開始。

高度僅用於演出，不搬動角色或敵人的地面座標，也不改寫原生跳躍高度。鏡頭隨超出的升高量向上追蹤，讓角色頭部保持在 HUD 下方；落地、清理或失去有效角色／世界時還原地面鏡頭。敵人傷害數字與命中特效跟隨蓮華視覺高度。逐踢升高、遞減間隔及高段數縮短等待是本作改編，原傷害、空中無敵及落地範圍規則不變。
